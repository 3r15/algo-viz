## 한눈에

점·선분·다각형을 **좌표로** 다루는 문제들이다. 언뜻 제각각으로 보이지만, 실제로는 **소수의 공통 도구**를
조합해 푼다 — **방향 판정(외적)**, 거리·내적, **정렬과 스위프(sweep)**, 볼록성.

계산 기하의 진짜 난점은 알고리즘이 아니라 **두 가지 함정**이다.

- **수치 오차** — 부동소수점 비교가 방향을 오판한다. 정수 좌표면 정수로 계산해 오차를 없앤다.
- **경계 사례** — 공선점, 겹치는 점, 수직선, 접하는 경우. "일반적 위치(general position)" 가정을
  깨는 입력에서 대부분의 버그가 나온다.

## 언제 쓸 수 있나

문제가 **평면(또는 공간) 위의 위치 관계**로 환원되면 쓴다. 그 관계 대부분은 아래 두 원시 연산으로 판정된다.

### 방향 판정 — 외적

세 점 `O, A, B` 의 꺾임 방향은 **외적** 부호 하나로 결정된다.

```
cross(O,A,B) = (A−O) × (B−O) = (A.x−O.x)(B.y−O.y) − (A.y−O.y)(B.x−O.x)
> 0 좌회전(반시계) · = 0 공선 · < 0 우회전(시계)
```

이 하나로 "왼쪽/오른쪽", "볼록/오목", "선분 교차", "점의 다각형 내부", 삼각형 넓이 부호를 판정한다.

### 거리·내적·정렬

- **내적** `(A−O)·(B−O)` 로 각이 예각/둔각인지, 사영 길이를.
- **정렬 + 스위프라인** — 점/사건을 한 축으로 정렬해 왼→오로 훑으며 활성 집합을 유지하면,
  `O(n²)` 짝 비교가 `O(n log n)` 이 된다(선분 교차, 최근접 점 쌍).

### 성립하지 않는(조심할) 신호

- **각도·나눗셈·제곱근**으로 판정하려 든다 → 오차·느림. 가능하면 외적·제곱거리로 정수화.
- 입력이 **일반 위치가 아니다**(공선·중복·수직) → 부등호(`<` vs `≤`)를 명시적으로 정해야 한다.
- 동적으로 점이 추가·삭제된다 → 정적 전처리로는 부족(동적 구조 필요).

## 구현 골격

대부분의 평면 알고리즘은 **정렬 → 방향 판정으로 훑기** 라는 뼈대를 공유한다.

```
① 좌표를 정수로 다룬다(가능하면). 외적/제곱거리로 비교.
② 한 기준(x, 또는 각도)으로 정렬한다.
③ 정렬 순서로 훑으며 외적 부호로 유지/버림을 결정한다(스택 또는 스위프 활성 집합).
④ 공선·중복·경계 사례를 명시적으로 처리한다.
```

| 문제 | 정렬 기준 | 판정 도구 |
|---|---|---|
| [볼록 껍질](#/algo/convex-hull) | x, 그다음 y | 외적(좌회전만 유지, 스택) |
| 최근접 점 쌍 | x(분할정복) 또는 스위프 | 제곱거리 + 띠(strip) 안 비교 |
| 선분 교차(스위프) | 사건 x | 외적(양끝 방향) + 활성 집합 |
| 점의 다각형 내부 | — | 광선 교차 수 또는 외적 부호 합 |

[볼록 껍질](#/algo/convex-hull)의 모노톤 체인이 이 골격의 교과서다 — 정렬 뒤 외적으로 좌회전만 남긴다.

## 잘 맞는 문제

- **최외곽/경계** — 볼록 껍질, 다각형 지름·너비(회전 캘리퍼스)
- **교차·포함 판정** — 선분 교차, 점의 다각형 내부, 겹침
- **가장 가까운/먼 쌍** — 최근접 점 쌍(분할정복·스위프), 지름(껍질 위)
- **분할·구조** — 들로네 삼각분할, 보로노이 다이어그램(껍질과 쌍대)
- **면적·둘레** — 신발끈 공식(외적 합)

"위치 관계를 여러 번 물어야 하고, 짝을 다 보면 `O(n²)`" 이면 정렬·스위프·껍질 전처리를 의심하라.

## 함정

**부동소수점으로 방향을 잰다.** 오차가 좌회전을 우회전으로 뒤집으면 껍질이 깨진다.
정수 좌표는 정수 외적으로, 나눗셈은 곱으로 옮겨 비교하라.

**오버플로.** 외적은 좌표² 규모. `int` 면 넘친다 — `long long`(또는 큰 정수).

**공선·중복점.** 세 점이 일직선이면 `cross==0`. 이를 유지할지 버릴지(`≤` vs `<`)를 문제마다 정하고
일관되게 쓴다. 중복 좌표는 미리 제거하는 편이 안전하다.

**경계·degenerate.** 점 0/1/2개, 모든 점 공선, 수직 선분, 접점. 일반 코드가 이들에서 조용히 틀린다.

**각도 정렬의 함정.** `atan2` 정렬은 느리고 오차가 있다. 사분면 + 외적으로 비교하면 정수로 정렬된다.
