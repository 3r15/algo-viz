# 해설 문서 규약

알고리즘 하나 = **해설 문서 두 개**. 폴더에 두기만 하면 알고리즘 페이지 맨 아래에
두 층으로 자동 렌더된다(별도 등록 없음 — 폴더 규약).

| 파일 | 페이지 표시 | 독자 | 중심 |
|---|---|---|---|
| `algorithms/<id>/walkthrough.md` | **차근차근** | 처음 보는 사람 | 구체적 예시로 원리를 쌓아 올린다 |
| `algorithms/<id>/notes.md` | **깊이 보기** | 이미 아는 사람 | 불변식·증명·복잡도 |

둘 다 선택이지만, 새 알고리즘에는 **둘 다 쓰는 것이 기본**이다.
두 문서는 항상 함께 DOM 에 있고(탭으로 감추지 않는다), 목차가 층별로 묶여 나온다.

검증: `node scripts/validate-notes.mjs algorithms/<id>/notes.md`
(편집하면 PostToolUse 훅이 자동 실행, CI 도 게이트한다.)

## 섹션 뼈대 — 순서 고정

### 차근차근 (walkthrough.md)

| 섹션 | 필수 | 내용 |
|---|---|---|
| `## 어떤 문제인가` | ✓ | 무엇을 푸는지. 일상 비유나 "단순한 방법은 왜 부족한가"로 연다 |
| `## 손으로 해보기` | ✓ | **작은 예시를 끝까지 따라간다.** 이 문서의 심장 |
| `## 아이디어 쌓기` | ✓ | 1단계 → 2단계 → … 로 알고리즘을 조립한다 |
| `## 코드로 옮기기` | ✓ | 쌓은 단계가 코드의 어느 줄인지 대응시킨다 |
| `## 자주 하는 실수` | | 초보자가 실제로 겪는 것들 |
| `## 스스로 확인하기` | | 플레이어에서 눌러 볼 것들 |

**쓰는 법**
- 예시는 반드시 **기본 입력/기본 그래프**로 — 독자가 플레이어에서 그대로 재생할 수 있어야 한다
- 증명하지 마라. "왜 이렇게 하게 됐는가"만 설명하고, 증명은 깊이 보기로 넘긴다
- 마지막에 깊이 보기로 이어지는 한 문장을 둔다

### 깊이 보기 (notes.md)

| 섹션 | 필수 | 내용 |
|---|---|---|
| `## 한눈에` | ✓ | 3~5줄 요약 + **언제 쓰나 / 언제 안 쓰나**. 특성 불릿(안정성·제자리·복잡도) |
| `## 동작 원리` | ✓ | 핵심 아이디어 한 문장 → 절차 → 작은 실행 예(ASCII 다이어그램 권장) |
| `## 정확성` | ✓ | **불변식 + 귀납**. 종료성. 안정성 같은 부수 성질 |
| `## 복잡도` | ✓ | 시간/공간 표 + **왜 그런지**. 점화식·합·하한 논증 |
| `## 구현 노트` | | 실전 함정, 오버플로, 관례(닫힌/반열린 구간), 더 빠른 변형 코드 |
| `## 변형과 확장` | | 이 알고리즘에서 뻗어 나가는 갈래 |
| `## 함께 보기` | | 사이트 내부 링크 목록 |

- **h1(`#`)을 쓰지 마라** — 페이지 제목이 이미 h1 이다. `##` 부터 시작한다.
- 표준 밖 h2 는 금지(검증기가 막는다). 자유로운 소제목이 필요하면 **h3(`###`)** 를 쓴다.
- h2/h3 만 우측 목차에 잡힌다.

## 무엇을 쓰나 — 섹션별 감각

**한눈에** — 이 문서를 안 읽어도 되는 사람을 걸러 주는 자리다. "무엇을 하는 물건인가"와
"어떤 상황에서 고르는가"를 먼저 준다.

**동작 원리** — 코드를 그대로 옮겨 적지 마라(코드는 이미 페이지 위에 있다).
**왜 이렇게 하면 되는지의 직관**을 주고, 작은 예시로 한 바퀴를 돌린다.

**정확성** — 이 사이트가 다른 알고리즘 사이트와 갈라지는 지점이다. 최소한:
- **불변식**을 인용문(`>`)으로 또박또박 진술한다
- 기저 → 귀납 단계 → 종료 시 결론의 형태로 전개한다
- 증명이 끝나면 `∎` 로 닫는다

**복잡도** — 표로 최선/평균/최악을 주고, **그 숫자가 어디서 나왔는지** 반드시 덧붙인다.
점화식이면 마스터 정리나 재귀 트리로, 합이면 급수로.

## 렌더 가능한 마크다운

`app/markdown.js` 가 처리하는 범위만 쓴다(외부 라이브러리 없음).

```
## 헤딩 (h2~h4)      **강조**   *기울임*   `인라인 코드`
- 불릿 (2칸 들여쓰면 중첩 1단계)      1. 번호 목록
> 인용                                ---  수평선
| 표 | 헤더 |                         ```   코드 펜스
|---|---|
```

**수식은 쓰지 마라.** KaTeX/MathJax 를 싣지 않는다(빌드리스·정적 원칙).
대신 유니코드와 코드 펜스로 쓴다.

```
O(n log n)   2^k   ⌊log₂ n⌋   Θ(n²)   Σ_{i<j}   A ∪ B   α(n)   ∎   ≤ ≥ ≠ ⟺ →
```

여러 줄 식이나 다이어그램은 코드 펜스에 넣으면 등폭 정렬이 유지된다.

```
  i                    i+2^(k-1)              i+2^k
  ├──── 앞 절반 ────────┼──── 뒤 절반 ─────────┤
```

## 내부 링크

다른 알고리즘은 **해시 라우트**로 건다. 검증기가 존재 여부를 확인한다.

```markdown
[세그먼트 트리](#/algo/segment-tree)          ← 알고리즘 페이지
[#/catalog?q=in-place](#/catalog?q=in-place)  ← 태그 검색
```

- 자기 자신으로 링크하면 검증 실패한다.
- `[텍스트](#슬러그)` 형태의 **문서 내부 앵커는 쓰지 마라** — 해시 라우터가 가로챈다.
  섹션 이동은 자동 생성되는 우측 목차가 담당한다.

## 작성 후

```bash
node scripts/validate-notes.mjs algorithms/<id>/notes.md
npm run check          # index 최신성 + 트레이스 + 문서까지 한 번에
```
