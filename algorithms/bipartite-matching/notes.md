## 한눈에

이분 그래프에서 **최대 매칭**(정점을 공유하지 않는 간선의 최대 집합)을 쿤 알고리즘으로 구한다.
왼쪽 정점을 하나씩 보며 **증가 경로**를 DFS 로 찾아, 필요하면 기존 매칭을 밀어내며 매칭을 하나씩 늘린다.

- **시간** `O(V·E)`(왼쪽마다 증가 경로 DFS) · **공간** `O(V+E)`
- **증가 경로 정리** — 증가 경로가 없으면 현재 매칭이 최대(더 못 늘림)
- **단위 용량 [최대 유량](#/algo/max-flow)** 의 조합론적 형태(정수성으로 0/1 유량 = 매칭)
- König 정리로 **최소 정점 커버 = 최대 매칭**(이분 그래프)

**언제 쓰나** — 지원자–직무·학생–프로젝트 배정, 서로 다른 대표 뽑기(SDR), 격자의 도미노 덮기,
최소 경로 덮개(DAG). "이분 + 짝짓기" 면 떠올려라.

**언제 안 쓰나** — 일반(비이분) 그래프 매칭은 블로섬 알고리즘. 가중 매칭은 헝가리안(쿤-먼크레스).
아주 큰 이분 그래프는 홉크로프트-카프(`O(E√V)`).

## 동작 원리

```
for u in 왼쪽:
    visited 초기화
    tryKuhn(u): u 에서 증가 경로를 찾으면 매칭 +1
tryKuhn(u):
    for v in adj[u]:
        if v 미방문:
            visited[v]=true
            if matchR[v]==-1 or tryKuhn(matchR[v]):   # 빈 곳 or 짝을 밀어냄
                matchR[v]=u; return true
    return false
```

### 증가 경로

현재 매칭 `M` 에 대해, **미매칭 간선과 매칭 간선을 번갈아** 밟아 양 끝이 모두 미매칭인 경로.
그 간선들의 매칭 여부를 뒤집으면(대칭차 `M △ P`) 매칭 크기가 정확히 1 는다.
`tryKuhn` 의 재귀가 바로 이 경로를 따라간다.

## 정확성

> **버거의 증가 경로 정리.** 매칭 `M` 이 최대다 ⟺ `M` 에 대한 증가 경로가 없다.

*(⟸ 대우) 증가 경로 `P` 가 있으면* `M △ P` 가 크기 `|M|+1` 인 매칭이라 `M` 은 최대가 아니다.
*(⟹ 대우) `M` 이 최대가 아니면* 더 큰 매칭 `M'` 이 있고, `M △ M'` 은 경로·짝수 사이클로 분해되며
그중 `M'` 간선이 더 많은 성분이 존재 → 그것이 `M` 의 증가 경로. ∎

> **쿤의 정확성.** 각 왼쪽 정점을 한 번씩 처리해, 증가 경로가 있으면 매칭을 늘린다. 모든 정점을
> 처리한 뒤 증가 경로가 없으므로(정리) 매칭이 최대.

한 번 매칭된 오른쪽 정점은 계속 매칭 상태를 유지하고(밀어내도 다른 짝을 얻음), 매칭 크기는 단조 증가.
`visited` 가 한 시도에서 각 오른쪽을 한 번만 방문하게 해 종료를 보장한다. ∎

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 쿤 | `O(V·E)` | `O(V+E)` |
| 홉크로프트-카프 | `O(E√V)` | `O(V+E)` |

왼쪽 정점 `V_L` 개, 각 `tryKuhn` 이 최악 `O(E)`. 총 `O(V·E)`.

### 최대 유량과의 관계

소스 → 왼쪽(용량 1) → 오른쪽(용량 1) → 싱크(용량 1) 네트워크의 최대 유량 = 최대 매칭.
[정수성 정리](#/algo/max-flow)로 유량이 0/1 이라 매칭이 된다. 쿤의 증가 경로 = 그 네트워크의 증가 경로.

### König 정리

이분 그래프에서 **최대 매칭 크기 = 최소 정점 커버 크기**. 매칭에서 최소 커버(그리고 최대 독립집합)를
구성적으로 얻는다.

## 구현 노트

**visited 초기화** — `tryKuhn` 호출마다(왼쪽 정점마다) 오른쪽 `visited` 를 새로 비운다.

**인접은 왼쪽→오른쪽만** — 매칭 간선의 반대 방향은 `matchR`(오른쪽→왼쪽)로 추적.

**정점 순서 휴리스틱** — 왼쪽 정점을 차수 오름차순으로 처리하면 실전에서 빨라질 때가 많다(그리디 초기 매칭도).

**이분 판정** — 입력이 이분인지 2-색칠로 확인(여기 시각화는 좌우 위치로 구분).

## 변형과 확장

### 홉크로프트-카프

BFS 로 여러 증가 경로를 동시에(레벨 그래프), DFS 로 한꺼번에 뒤집어 `O(E√V)`. 큰 이분 그래프의 표준.

### 최소 정점 커버·최대 독립집합 (König)

최대 매칭에서 König 구성으로 최소 정점 커버를, 여집합으로 최대 독립집합을 얻는다(이분 한정).

### 최소 경로 덮개 (DAG)

DAG 의 정점을 최소 개수의 정점 서로소 경로로 덮기 = `V − (분할 이분 그래프의 최대 매칭)`.

### 가중 이분 매칭 — 헝가리안

간선에 비용이 있어 **최소(최대) 비용 완전 매칭**을 원하면 헝가리안(쿤-먼크레스) `O(V³)`,
또는 최소 비용 최대 유량.
