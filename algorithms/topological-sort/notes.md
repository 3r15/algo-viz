## 한눈에

방향 비순환 그래프(DAG)의 정점을 한 줄로 세우되, **모든 간선이 앞에서 뒤로 향하도록** 한다.
"A 를 끝내야 B 를 시작할 수 있다" 같은 선행 관계를 실제 작업 순서로 바꾸는 일이다.

칸(Kahn) 알고리즘의 규칙은 하나다.

> **선행 조건이 남지 않은 정점**(진입 차수 0)을 아무거나 꺼내 순서에 넣는다.
> 그 정점이 걸어 잠그고 있던 조건들을 풀어 준다.

- 시간 O(V+E) · 공간 O(V) · 큐 사용
- **사이클 탐지가 덤으로 따라온다** — 다 꺼내지 못하면 사이클이 있다는 뜻이다
- 위상 순서는 보통 **여러 개**다. 이 알고리즘은 그중 하나를 준다

## 동작 원리

```
1. 모든 정점의 진입 차수(자기를 가리키는 간선 수)를 센다
2. 진입 차수가 0 인 정점을 전부 큐에 넣는다
3. 큐에서 u 를 꺼내 순서에 추가하고, u 가 가리키던 v 들의 진입 차수를 1 줄인다
       0 이 되면 v 도 큐에 넣는다
4. 큐가 빌 때까지 반복
```

시각화의 정점 라벨이 **남은 진입 차수**이고, 순서가 정해지면 `#0`, `#1` 로 바뀐다.
간선을 따라 차수가 하나씩 깎이다가 0 이 되는 순간 큐에 들어가는 흐름을 볼 수 있다.

기본 그래프를 **선수 과목**으로 읽으면 직관적이다. 0 을 들어야 1·2 를 들을 수 있고,
3 은 1 과 2 를 **둘 다** 들어야 열린다(그래서 진입 차수가 2 다).

### DFS 버전

DFS 로도 된다. **종료 시각의 역순**이 곧 위상 순서다.

```cpp
void dfs(int u) {
    visited[u] = true;
    for (int v : adj[u]) if (!visited[v]) dfs(v);
    order.push_back(u);      // 자손을 모두 끝낸 뒤 담는다
}
// 모든 정점에 대해 dfs 호출 후 reverse(order)
```

칸 쪽이 사이클 탐지가 자연스럽고 큐 순서를 조절하기 쉬워 실전에서 더 자주 쓰인다.

## 정확성

### 위상 순서가 존재한다 ⟺ DAG 다

**(⇒)** 위상 순서가 있는데 사이클 `v₁ → v₂ → … → v₁` 이 있다고 하자.
순서상 `v₁ < v₂ < … < v₁` 이 되어 `v₁ < v₁` — 모순이다.

**(⇐)** DAG 라면 진입 차수가 0 인 정점이 **반드시 하나는 있다.**
없다고 하면 모든 정점에 들어오는 간선이 있으니, 아무 정점에서 간선을 거꾸로 계속 따라갈 수 있다.
정점이 유한하므로 언젠가 같은 정점을 두 번 만나고, 그 구간이 사이클이다 — 모순.
그 정점을 떼어 내면 남은 그래프도 DAG 이므로 귀납적으로 계속 뽑을 수 있다. ∎

이 증명이 곧 칸 알고리즘의 **종료 보장**이다.

### 출력이 올바른 위상 순서다

> **불변식**: 정점 `u` 가 큐에 들어가는 시점에는, `u` 로 들어오는 모든 간선의 시작점이
> 이미 순서에 놓여 있다.

`u` 가 큐에 들어가는 조건은 `indeg[u] == 0` 이 되는 것이고, 진입 차수는 오직
"`u` 를 가리키는 정점이 순서에 놓일 때"만 줄어든다. 처음부터 0 이었다면 들어오는 간선이 없다.
어느 쪽이든 `u` 앞의 모든 선행 정점이 이미 배치돼 있다.

따라서 임의의 간선 `(x, y)` 에 대해 `x` 가 `y` 보다 먼저 놓인다. 이것이 위상 순서의 정의다. ∎

### 사이클 탐지

각 정점은 큐에 최대 한 번 들어가고, 들어간 정점만 순서에 담긴다. 따라서

> `order.size() < V` ⟺ 큐에 한 번도 못 들어간 정점이 있다 ⟺ 진입 차수가 끝내 0 이 되지 않았다

그 정점들은 서로를 기다리고 있으므로 사이클을 이룬다(위 (⇐) 논증의 대우).
**남은 정점 집합이 곧 "사이클에 얽힌 부분"** 이라 디버깅에도 쓸모가 있다.

시각화에서 간선 하나를 추가해 사이클을 만들어 보면, 남은 정점들이 그대로 보고된다.

## 복잡도

| | |
|---|---|
| 시간 | **O(V + E)** |
| 공간 | O(V) — 진입 차수 배열 + 큐 |

- 진입 차수 세기: 모든 간선 한 번 → O(E)
- 각 정점은 큐에 한 번 들어가고 한 번 나온다 → O(V)
- 각 간선의 차수 감소는 정확히 한 번 → O(E)

입력에 무관하게 선형이다. 사이클이 있어도 조기에 멈추므로 더 빠르다.

## 구현 노트

**큐를 우선순위 큐로 바꾸면 사전순으로 가장 빠른 위상 순서**를 얻는다.
"가능한 순서 중 사전순 최소" 를 요구하는 문제가 흔하다. 이때 복잡도는 O(V log V + E) 가 된다.

**진입 차수를 미리 다 세라.** 세면서 동시에 큐에 넣으면 아직 안 센 간선 때문에 틀린다.
반드시 2패스다.

**여러 시작점**: 진입 차수 0 인 정점이 여럿이면 전부 처음에 넣는다. 하나만 넣고 시작하면
연결되지 않은 부분이 통째로 빠진다.

**무방향 그래프를 넣으면** 간선 하나가 양방향이라 (정점 2개 이상이면) 항상 사이클이다.
이 페이지에서 방향 옵션이 강제된 이유다 — 위상 정렬은 방향 그래프에서만 정의된다.

## 변형과 확장

### 어디에 쓰이나

- **작업 스케줄링 / 빌드 순서**: `make`, 패키지 의존성 해결이 전부 위상 정렬이다.
- **선수 과목 · 커리큘럼 배치**
- **DAG 위의 DP**: 위상 순서대로 훑으면 "부분 문제가 항상 먼저 계산됨"이 보장된다.
  DAG 최장 경로, DAG 최단 경로가 O(V+E) 로 풀리는 이유다
  ([벨만-포드](#/algo/bellman-ford)의 O(VE) 가 필요 없다).
- **사이클 판정**: 순서를 다 못 만들면 사이클. 데드락 탐지의 기본형이다.

### 갈래

- **DAG 최단/최장 경로**: 위상 순서대로 한 번만 완화하면 끝난다. 음수 가중치도 문제없다.
- **위상 순서의 개수 세기**: 일반적으로 #P-완전이라 어렵다. 정점이 20개 남짓이면
  비트마스크 DP 로 센다.
- **유일성 판정**: 매 단계에서 큐 크기가 항상 1 이면 위상 순서가 유일하다.
  (해밀턴 경로가 존재한다는 뜻이기도 하다.)
- **[SCC](#/algo/tarjan-scc) 축약 후 위상 정렬**: 사이클이 있는 그래프도 SCC 로 묶으면 DAG 가 되고,
  그 위에서 위상 정렬이 가능해진다. 2-SAT 이 이 조합으로 풀린다.
