## 한눈에

절마다 리터럴이 둘인 논리식(2-CNF)의 **충족 가능성**을, **함의 그래프**의 강한 연결 요소(SCC)로
`O(V+E)` 에 판정하고 배정까지 구성한다. 일반 SAT 는 NP-완전이지만, 리터럴이 둘이면 선형 시간.

- **시간** `Θ(n + m)`(변수 n, 절 m) · **공간** `Θ(n + m)`
- 절 `(a∨b)` ⟺ 함의 `¬a→b` ∧ `¬b→a`. 리터럴 `2n`개가 정점
- **판정** — 어떤 변수의 `x`, `¬x` 가 같은 SCC 면 UNSAT, 없으면 SAT
- **배정** — 위상적으로 뒤에 오는 리터럴을 참으로(SCC 축약 DAG 의 역순)

**언제 쓰나** — "각 선택이 이진이고 제약이 '둘 중 하나' 로 쓰이는" 문제: 구간/좌표 겹침 회피,
그래프 2-색 제약, 스케줄 충돌, 기하 배치. 많은 문제가 2-SAT 로 환원된다.

**언제 안 쓰나** — 절에 리터럴이 셋 이상(3-SAT 이상)이면 일반 SAT(NP-완전). 최적화(MAX-2-SAT)도 NP-난해.

## 동작 원리

```
addClause(a, b):  edge(¬a → b),  edge(¬b → a)      # (a∨b)
twoSat:
    comp = SCC(함의 그래프)                          # 코사라주/타잔
    각 변수 v: comp[x_v] == comp[¬x_v] 이면 return UNSAT
    각 변수 v: x_v = (comp[x_v] > comp[¬x_v])         # 위상 뒤 = 참
    return SAT
```

### 함의 그래프

리터럴 `ℓ` 마다 정점을 두고, 절 `(a∨b)` 는 `¬a→b`, `¬b→a`. 간선 `A→B` 의 뜻은 **"A 가 참이면 B 도 참"**.
정점은 `2n`개(변수당 참·거짓), 간선은 `2m`개.

### 대칭성

함의 그래프는 **스큐 대칭**이다: `A→B` 가 있으면 `¬B→¬A` 도 있다(대우). 그래서 SCC 도 짝을 이뤄
대칭적으로 나타난다.

## 정확성

> **정리 1(판정).** 2-CNF 가 충족 가능 ⟺ 어떤 변수도 `x` 와 `¬x` 가 같은 SCC 에 있지 않다.

*(⟹) 충족 가능한데* `x`, `¬x` 가 같은 SCC 라 하자. 그러면 `x→…→¬x` 와 `¬x→…→x` 경로가 있어,
함의를 따라가면 "x 참이면 ¬x 참", "¬x 참이면 x 참" — 어느 값이든 모순. 따라서 충족 불가(대우).
*(⟸) 어떤 변수도 같은 SCC 가 아니면*, 아래 배정이 실제로 모든 절을 만족한다(정리 2). ∎

> **정리 2(배정).** `x`·`¬x` 가 다른 SCC 일 때, `comp[x] > comp[¬x]`(축약 DAG 의 위상 뒤)인 리터럴을
> 참으로 배정하면 모든 함의가 만족된다.

*증명 스케치.* 축약 DAG 의 위상 순서를 매긴다. 함의 `A→B` 가 참인데 B 가 거짓이려면 A 참·B 거짓,
즉 A 는 위상 뒤, ¬B 도 위상 뒤여야 한다. 스큐 대칭 `A→B ⟹ ¬B→¬A` 와 위상 순서의 성질을 쓰면
그런 상황이 안 생김을 보일 수 있다(같은 SCC 가 아니라는 전제하에 A 와 B 의 위상 관계가 일관됨). ∎

SCC 계산이 정확하면(코사라주/타잔), 두 정리로 판정·배정이 모두 옳다.

## 복잡도

| 단계 | 시간 |
|---|---|
| 함의 그래프 구성 | `O(n + m)` |
| SCC | `O(V + E) = O(n + m)` |
| 판정·배정 | `O(n)` |
| **전체** | `Θ(n + m)` |

정점 `2n`, 간선 `2m` 이라 SCC 가 선형. 2-SAT 이 다항(사실상 선형)인 반면 3-SAT 이 NP-완전인 대비가 유명하다.

## 구현 노트

**리터럴 인코딩** — 변수 `v`(0-based)의 참 정점 `2v`, 거짓 정점 `2v+1`. `neg(x)=x^1`(최하위 비트 뒤집기).

**두 함의 모두** — `(a∨b)` 는 `¬a→b` **와** `¬b→a`. 한쪽만 넣으면 오답.

**배정 부등호** — SCC 번호 규약에 맞춘다. 코사라주는 SCC 를 **역위상 순서**로 번호 매기므로
`comp[x] > comp[¬x]` 를 참으로(더 나중에 번호 = 위상 앞). 헷갈리면 배정 후 전 절 검사로 확인.

**함의(단독 참) 표현** — "x 는 반드시 참" 은 절 `(x∨x)` 로. `¬x→x` 간선이 생겨 x 가 강제된다.

## 변형과 확장

### 제약의 2-SAT 환원

"두 구간이 겹치지 않게 좌/우 배치", "각 정점을 두 색 중 하나로 두되 인접 제약" 등 **이진 선택 + '둘 중 하나'
제약** 문제는 2-SAT 으로 환원된다. 모델링이 핵심.

### 강제·함의 추가

`a→b`(a면 b) 같은 단방향 함의도 간선 하나로 직접 추가한다(절 형태가 아니어도 됨).

### SCC 알고리즘 선택

[코사라주](#/algo/kosaraju-scc)(두 번 DFS, 개념 명료)나 [타잔](#/algo/tarjan-scc)(한 번 DFS, low-link).
어느 쪽이든 `O(V+E)`. 타잔은 SCC 를 **위상 역순**으로 바로 내므로 배정에 편리.

### MAX-2-SAT

만족하는 절 수를 **최대화**하는 문제는 NP-난해다(판정은 쉬워도 최적화는 어렵다) — 근사·정수계획으로.
