## 한눈에

평면 위 점 집합을 모두 포함하는 **가장 작은 볼록 다각형**(볼록 껍질)을 구한다.
앤드루의 **모노톤 체인**은 점을 정렬한 뒤, 외적의 부호로 "좌회전만 남기며" 아래·위 경계를 각각
스택으로 쌓는다. 정렬이 지배해 `Θ(n log n)`.

- **시간** `Θ(n log n)`(정렬) + 껍질 쌓기 `Θ(n)` · **공간** `Θ(n)`
- **방향 판정 = 외적 부호** 하나. 정수 좌표면 전 과정을 정수로(오차 없음)
- 결과는 꼭짓점을 **반시계 순**으로. 변 위의 공선점 포함 여부는 부등호로 조절
- 출력 크기 `h`(껍질 꼭짓점 수)에 민감한 문제는 `O(n log h)`(찬 알고리즘)도 있다

**언제 쓰나** — 최외곽 경계, 충돌 판정의 대략 형태, 지름(가장 먼 두 점)·너비, 점들의 "바깥 모양".
많은 기하 알고리즘의 **첫 전처리**로 쓰인다.

**언제 안 쓰나** — 오목 경계(concave/alpha shape)가 필요하거나, 점이 동적으로 추가·삭제될 때
(동적 볼록 껍질은 별도 구조). 1차원이면 그냥 min·max.

## 동작 원리

핵심 도구는 **외적(cross product)** 이다. 세 점 `O, A, B` 에 대해

```
cross(O,A,B) = (A−O) × (B−O) = (A.x−O.x)(B.y−O.y) − (A.y−O.y)(B.x−O.x)
```

부호가 방향을 준다: `>0` 좌회전(반시계), `=0` 공선, `<0` 우회전(시계).
크기는 삼각형 `OAB` 넓이의 두 배(부호 있음)다.

### 모노톤 체인

```
① 점을 (x, 그다음 y) 로 정렬
② 아래 껍질: 왼→오. 스택 top 둘 + 새 점이 좌회전이 아니면(≤0) pop, 그 뒤 push
③ 위 껍질:  오→왼. 같은 규칙(아래 껍질 크기+1 을 하한으로)
④ 두 사슬을 잇고 중복되는 양 끝점 하나 제거
```

아래 껍질은 점들의 **하단 경계**, 위 껍질은 **상단 경계**를 이룬다. 이어 붙이면 닫힌 볼록 다각형.

## 정확성

> **외적의 방향 의미.** `cross(O,A,B) > 0` ⟺ `B` 가 유향 직선 `O→A` 의 **왼쪽**에 있다.

이는 외적이 부호 있는 평행사변형 넓이라는 정의에서 곧바로 나온다. 따라서 "좌회전 유지" 는
"경계가 항상 같은 방향으로 감긴다 = 볼록" 과 동치다.

> **정리(아래 껍질).** 알고리즘이 유지하는 스택은 항상 정렬된 접두사 점들의 **하단 볼록 사슬**이다.

*불변식.* 스택에 든 연속 세 점은 모두 좌회전(반시계). 새 점 `p` 를 넣기 전, top 둘 `a,b` 와 `p` 가
`cross(a,b,p) ≤ 0` 이면 `b` 는 볼록성을 깨는(또는 공선) 점이므로 제거해야 한다 — 제거해도
**하단 경계**는 바뀌지 않는다(`b` 가 `a`–`p` 아래가 아니라 위/선상에 있으니 하단 껍질의 꼭짓점이 될 수 없다).
`cross > 0` 이 될 때까지 pop 하면 불변식이 회복된다. 정렬 순서 덕에 `p` 는 항상 사슬의 오른쪽 끝에 붙는다. ∎

위 껍질도 대칭으로 상단 경계를 준다. 두 사슬의 합집합이 모든 점을 포함하는 볼록 다각형이고,
어떤 점도 그 바깥에 없으므로(각 점은 두 경계 사이) **최소** 볼록 포함 다각형이다.

> **완전성.** 껍질의 실제 꼭짓점은 결코 pop 되지 않는다. 꼭짓점에서는 이웃 변이 좌회전을 이루므로
> `cross > 0` 이고, pop 조건 `≤ 0` 에 걸리지 않는다.

## 복잡도

| 단계 | 시간 |
|---|---|
| 정렬 | `Θ(n log n)` |
| 아래+위 껍질 | `Θ(n)` |
| 전체 | `Θ(n log n)` |

공간 `Θ(n)`.

### 껍질 쌓기가 왜 `Θ(n)` 인가

각 점은 **정확히 한 번 push** 된다. pop 되면 스택에서 영영 사라져 다시 검사되지 않는다.
따라서 `while` 의 총 pop 횟수 ≤ 총 push 횟수 = `n`. 분할상환으로 두 루프 합쳐 `O(n)`.
껍질 쌓기는 **단조 스택**과 같은 논증이다 — top 을 조건에 맞을 때까지 걷어낸다.

### 하한

비교/정렬 기반 볼록 껍질은 `Ω(n log n)` 이 하한이다(정렬로 환원 가능 — 껍질을 알면 정렬을 복원).
출력 민감 알고리즘(찬)은 `O(n log h)` 로, 꼭짓점이 적을 때 유리하다.

## 구현 노트

**정수 좌표는 정수로** — 외적을 `long long` 정수로 계산하면 부동소수점 오판이 사라진다.
곱이 좌표² 규모라 오버플로에 주의(`long long`).

**공선점 처리** — pop 조건을 `≤ 0` 으로 하면 변 위 점을 **제외**(꼭짓점만), `< 0` 으로 하면
**포함**. 여기 구현은 `≤ 0`(꼭짓점만).

**중복·동일 좌표** — 미리 중복 점을 제거하는 편이 안전하다(여기 생성기도 제거).

**위 껍질 하한** — 위 껍질을 쌓을 때 `k >= t`(t = 아래 껍질 크기 + 1)를 지켜 아래 사슬을 침범하지 않게.

**degenerate** — 점이 0/1/2개, 모두 공선인 경우를 따로 처리(껍질이 선분/점).

## 변형과 확장

### 그레이엄 스캔 (Graham scan)

정렬 기준이 다르다 — 최하단 점을 기준으로 **각도** 정렬한 뒤 한 번의 스캔으로 껍질을 만든다.
모노톤 체인은 좌표 정렬이라 각도 계산·수치 문제가 없어 구현이 더 담백하다.

### 선물 포장 (gift wrapping / Jarvis march)

가장 왼쪽 점에서 시작해 "가장 바깥으로 꺾이는 다음 점" 을 반복해 고른다. `O(n·h)` —
꼭짓점 `h` 가 아주 작으면 유리, 많으면 불리.

### 회전하는 캘리퍼스 (rotating calipers)

껍질을 얻은 뒤, 두 평행선을 굴리며 **지름(가장 먼 두 점)**·**너비**·**최소 외접 사각형**을
`O(n)` 에 구한다. 껍질이 이들 문제의 전처리다.

### 3차원 볼록 껍질

점이 3D 면 껍질은 다면체다. 증분법·분할정복으로 `O(n log n)`. 들로네 삼각분할·보로노이 다이어그램과
쌍대로 이어진다.
