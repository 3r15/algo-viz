## 어떤 문제인가

평면에 점이 여럿 흩어져 있다. 이 점들을 **모두 감싸는 가장 작은 볼록 다각형**을 구하고 싶다.

> 못을 여러 개 박아 두고 **고무줄을 크게 벌려 놓았다가 놓으면**, 바깥 점들에 딱 걸려
> 팽팽한 다각형이 된다. 그 다각형이 볼록 껍질이다.

"볼록(convex)" 은 안쪽으로 파인 곳이 없다는 뜻 — 다각형의 모든 꼭짓점에서 같은 방향으로만 꺾인다.
안쪽에 있는 점들은 껍질에 안 들어간다. 어떻게 **바깥 점만** 골라낼까?

## 손으로 해보기

기본 입력 `(1,2) (4,6) (7,2) (5,4) (3,7) (8,6)` 여섯 점으로 가 보자.

### 방향 판정 — 외적 하나로

세 점 `O → A → B` 가 어느 쪽으로 꺾이는지는 **외적(cross product)** 부호로 안다.

```
cross(O,A,B) = (A.x−O.x)(B.y−O.y) − (A.y−O.y)(B.x−O.x)

> 0  →  좌회전(반시계)   ↰
= 0  →  일직선
< 0  →  우회전(시계)     ↱
```

볼록 껍질(반시계)은 **좌회전만** 있어야 한다. 우회전이 생기면 방금 찍은 점이 "안으로 파인" 것이니 **버린다.**

### ① 정렬

점을 x(같으면 y) 순으로 세운다.

```
(1,2) (3,7) (4,6) (5,4) (7,2) (8,6)
```

### ② 아래 껍질 — 왼쪽부터 쌓는다

왼쪽부터 하나씩 넣되, **마지막 두 점 + 새 점이 좌회전이 아니면** 마지막 점을 버린다.

```
(1,2) 넣기            [ (1,2) ]
(3,7) 넣기            [ (1,2) (3,7) ]
(4,6): (1,2)(3,7)(4,6) 우회전 → (3,7) 버림 → [ (1,2) ] → (4,6) 넣기  [ (1,2) (4,6) ]
(5,4): (1,2)(4,6)(5,4) 우회전 → (4,6) 버림 → [ (1,2) ] → (5,4) 넣기  [ (1,2) (5,4) ]
(7,2): (1,2)(5,4)(7,2) 우회전 → (5,4) 버림 → [ (1,2) ] → (7,2) 넣기  [ (1,2) (7,2) ]
(8,6): 좌회전 → 유지 → 넣기                                          [ (1,2) (7,2) (8,6) ]
```

아래쪽 경계 `(1,2) → (7,2) → (8,6)` 가 나왔다.

### ③ 위 껍질 — 오른쪽부터 같은 방식

이번엔 오른쪽에서 두 번째 점부터 왼쪽으로 훑으며 같은 규칙을 적용한다.

```
(7,2) … (3,7) 을 거치며 위쪽 경계 (8,6) → (3,7) → (1,2) 가 나온다
```

### 합치면

아래 껍질 + 위 껍질 = **`(1,2) → (7,2) → (8,6) → (3,7)`**. `(4,6)`, `(5,4)` 는 안쪽이라 빠졌다.
못에 고무줄을 건 그 다각형이다.

### 비용

```
정렬:        O(n log n)
껍질 쌓기:   각 점을 딱 한 번 넣고, 버려지면 다시는 안 본다 → O(n)
합계:  O(n log n)   (정렬이 지배)
```

## 아이디어 쌓기

### 1단계 — 방향을 외적으로 판정

세 점의 꺾임 방향을 외적 부호 하나로 안다. 좌회전만 볼록.

### 2단계 — 정렬로 순서를 준다

x 순으로 세우면 "왼쪽 아래부터 시계 반대로 감싼다" 는 순서가 생긴다.

### 3단계 — 아래·위 두 경계를 따로

아래 경계(왼→오)와 위 경계(오→왼)를 각각 스택으로 쌓고 이어 붙인다.

### 4단계 — 우회전이면 버린다(스택)

새 점이 우회전을 만들면 스택 위를 계속 pop. 각 점은 한 번 push, 최대 한 번 pop → O(n).

## 코드로 옮기기

```cpp
long long cross(P O, P A, P B) {              // >0: 좌회전(반시계)
    return (A.x-O.x)*(B.y-O.y) - (A.y-O.y)*(B.x-O.x);
}
vector<P> convexHull(vector<P> p) {
    sort(p.begin(), p.end());                 // x, 그다음 y
    int n = p.size(), k = 0;
    vector<P> h(2*n);
    for (int i = 0; i < n; i++) {             // 아래 껍질
        while (k >= 2 && cross(h[k-2], h[k-1], p[i]) <= 0) k--;
        h[k++] = p[i];
    }
    for (int i = n-2, t = k+1; i >= 0; i--) { // 위 껍질
        while (k >= t && cross(h[k-2], h[k-1], p[i]) <= 0) k--;
        h[k++] = p[i];
    }
    h.resize(k-1);                            // 마지막은 시작점과 겹침
    return h;
}
```

`h` 를 스택처럼 쓴다(`k` 가 스택 크기). `while` 이 우회전을 만드는 점을 걷어낸다.

## 자주 하는 실수

**부동소수점으로 외적을 잰다.** 좌표가 정수면 외적도 정수 — **정수(가급적 `long long`)** 로 계산해
오차와 오판을 피한다. 곱이 커지니 오버플로도 주의.

**일직선(cross==0)을 어떻게 할지 안 정한다.** `≤ 0` 으로 버리면 변 위의 점을 제외(꼭짓점만),
`< 0` 으로 버리면 변 위의 점도 포함한다. 문제 정의에 맞춰 하나로 고정하자.

**위 껍질의 시작 크기를 안 지킨다.** 위 껍질을 쌓을 때 아래 껍질을 침범하지 않도록
`k >= t`(아래 껍질 크기 + 1)라는 하한을 둔다. 안 그러면 아래 경계를 갉아먹는다.

**마지막 중복 점을 안 뺀다.** 두 껍질을 이으면 시작점이 끝에 한 번 더 들어간다. `resize(k-1)`.

## 스스로 확인하기

1. **정렬 스텝**에서 점들이 x 순으로 재배열되는 것을 보자.
2. **아래 껍질**에서 `(3,7)`·`(4,6)`·`(5,4)` 가 우회전으로 **버려지는(빨강)** 순간을 보자.
3. **판정 변(점선)** 과 대상 점이 이루는 꺾임 방향을 설명의 `cross` 값과 맞춰 보자.
4. **위 껍질**이 오른쪽부터 반대로 쌓이는 것을 보자.
5. **마지막 닫힌 다각형**이 안쪽 점 둘을 빼고 네 꼭짓점만 감싸는 것을 확인하자.
6. 점을 `2 2 2 8 8 8 8 2 5 5` 로 바꿔 보자 — 정사각형 네 꼭짓점만 남고 가운데 `(5,5)` 는 빠진다.

아래 **깊이 보기**에서는 외적이 왜 방향을 주는지, 껍질 쌓기가 왜 O(n) 인지(각 점 한 번 push/pop)를
증명하고, 그레이엄 스캔·선물 포장·3차원 확장을 다룬다.
