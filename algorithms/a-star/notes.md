## 한눈에

목표 정점이 **하나로 정해져 있을 때**의 최단 경로 탐색이다.
[다익스트라](#/algo/dijkstra)가 "시작점에서 가까운 순"으로 넓히는 반면, A\* 는

```
f(v) = g(v) + h(v)
       ↑      ↑
   실제 비용   목표까지 남은 비용의 추정
```

`f` 가 작은 것부터 꺼낸다. 그래서 **목표 반대편은 덜 파헤친다.**

- `h ≡ 0` 으로 두면 정확히 다익스트라가 된다 — A\* 는 다익스트라의 일반화다
- `h` 가 **허용 가능(admissible)** 하면 찾은 경로가 최적임이 보장된다
- 시간·공간은 최악에 다익스트라와 같다. 이득은 "보통의 경우"에 나온다

## 동작 원리

다익스트라와 코드가 거의 같고, 딱 두 군데가 다르다.

| | 다익스트라 | A\* |
|---|---|---|
| 우선순위 | `g(v)` | `g(v) + h(v)` |
| 종료 | PQ 가 빌 때까지 | **목표를 꺼내는 순간** |

`g(v)` 는 완화로 갱신되는 실제 비용이라 다익스트라의 `dist` 와 같은 것이고,
`h(v)` 는 정점마다 미리 정해진 상수다. 시각화의 정점 라벨 `3+5.4` 가 `g+h` 이고,
그 합이 PQ 에 들어가는 `f` 다.

### 이 페이지의 휴리스틱

정점에 화면 좌표가 있으므로 **목표까지의 직선 거리**를 쓴다. 다만 좌표 거리와 간선 가중치는
단위가 다르므로, 그대로 쓰면 `h` 가 실제 비용을 넘어설 수 있다. 그래서 축척을 하나 곱한다.

```
scale = min ( 간선 가중치 / 그 간선의 직선 길이 )       ← 모든 간선에 대해
h(v)  = (v 에서 목표까지의 직선 거리) × scale
```

`scale` 은 "직선 길이 1 만큼 이동하는 데 드는 최소 비용"이다. 이 정의 덕분에 `h` 가 절대
과대평가하지 않는다(다음 절에서 증명).

> 기본 그래프의 가중치를 화면상 길이에 대략 비례시켜 둔 이유가 여기 있다.
> 길이에 비해 유난히 싼 간선이 하나라도 있으면 `scale` 이 그쪽에 끌려 내려가고,
> `h` 가 전체적으로 약해져 A\* 가 다익스트라에 가까워진다.

## 정확성

### 허용 가능(admissible) 하다

> `h(v) ≤ (v 에서 목표까지의 진짜 최단 비용)` 이면 `h` 를 **허용 가능**하다고 한다.

위 `h` 가 그렇다. `v` 에서 목표까지의 임의의 경로 `v = x₀ → x₁ → … → x_m = goal` 을 잡으면,
`scale` 의 정의에서 각 간선이 `w(xᵢ, xᵢ₊₁) ≥ scale × |xᵢ xᵢ₊₁|` 이므로

```
경로 비용 = Σ w(xᵢ, xᵢ₊₁) ≥ scale × Σ |xᵢ xᵢ₊₁| ≥ scale × |v goal| = h(v)
                                     └ 삼각부등식 ┘
```

모든 경로가 `h(v)` 이상이니 최단 경로도 `h(v)` 이상이다. ∎

### 허용 가능하면 답이 최적이다

> **주장**: 목표 `t` 를 PQ 에서 꺼내는 순간의 `g(t)` 는 최적이다.

`t` 를 꺼낼 때 `f(t) = g(t) + h(t) = g(t)` 다(`h(t) = 0`). 최적 비용을 `C*` 라 하고
`g(t) > C*` 라고 가정하자.

최적 경로 위에서 **아직 PQ 에 남아 있는 정점** `y` 를 하나 잡을 수 있다(시작점은 이미
꺼냈고 `t` 는 아직이므로, 경계에 그런 정점이 반드시 있다). 최적 경로의 앞부분은 이미 완화됐으므로
`g(y) ≤ (최적 경로에서 y 까지의 비용)` 이고, 따라서

```
f(y) = g(y) + h(y)
     ≤ (최적 경로의 y 까지 비용) + (y 에서 t 까지의 진짜 최단 비용)     ← 허용 가능성
     = C*
     < g(t) = f(t)
```

`f(y) < f(t)` 인데 우리는 `f` 가 최소인 것을 꺼냈으므로 `t` 가 아니라 `y` 를 꺼냈어야 한다.
모순이다. ∎

### 일관성(consistency)과 재방문

더 강한 조건이 있다.

> 모든 간선 `(u,v)` 에 대해 `h(u) ≤ w(u,v) + h(v)` 이면 `h` 를 **일관적(consistent)** 이라 한다.

이 페이지의 `h` 는 일관적이기도 하다. `scale` 의 정의에서 `w(u,v) ≥ scale × |uv|` 이고,
삼각부등식에서 `|u goal| ≤ |uv| + |v goal|` 이므로

```
h(u) = scale × |u goal| ≤ scale × |uv| + scale × |v goal| ≤ w(u,v) + h(v)
```

일관적이면 `f` 값이 경로를 따라 **비감소**하므로, 한 번 닫힌(확정된) 정점은 다시 열릴 일이 없다.
허용 가능하지만 일관적이지 않은 `h` 를 쓰면 이미 닫은 정점을 다시 열어야 할 수 있고
(re-opening), 최악에는 지수적으로 느려진다.

## 복잡도

| | |
|---|---|
| 시간(최악) | O((V + E) log V) — `h ≡ 0` 이면 다익스트라와 동일 |
| 시간(실제) | 확장한 정점 수에 비례. 좋은 `h` 일수록 훨씬 적다 |
| 공간 | O(V) |

**최악은 나아지지 않는다.** `h` 가 아무 정보도 주지 못하면(예: `h ≡ 0`) 다익스트라와 똑같이
전부 훑는다. A\* 의 가치는 최악이 아니라 전형적인 경우에 있다.

기본 그래프에서 직접 비교해 보자.

| | 확장한 정점 수 |
|---|---|
| 다익스트라 | 8 / 8 |
| A\* | **5 / 8** |

정점 6 은 시작점에서 가장 싼 간선(가중치 3)으로 이어져 있어 다익스트라는 일찌감치 확장한다.
하지만 목표 반대편이라 `h` 가 커서, A\* 의 `f` 순서에서는 뒤로 밀려 **끝내 확장되지 않는다.**

### 휴리스틱의 세기

`h₁ ≤ h₂ ≤ (진짜 비용)` 이면 `h₂` 가 `h₁` 을 **지배(dominate)** 한다고 하고,
`h₂` 로 확장하는 정점은 항상 `h₁` 의 부분집합이다. 즉 **허용 가능성을 유지하는 선에서
`h` 는 클수록 좋다.** `h = 진짜 비용`이면 최단 경로만 따라가고, `h ≡ 0`이면 다익스트라다.

## 구현 노트

**목표를 꺼낼 때 끝내라 — 넣을 때가 아니라.** `open.push` 하는 시점에 종료하면
아직 더 짧은 경로가 발견될 수 있어 최적성이 깨진다. 위 증명이 성립하는 건 **pop 시점**이다.

**부동소수 비교**: `h` 가 실수면 `f > g[u] + h(u)` 같은 비교에 오차가 낀다.
낡은 항목 판정에 `+1e-9` 같은 여유를 두거나, 정수 스케일로 바꿔 계산한다.

**격자(그리드)에서**: 상하좌우만 이동하면 맨해튼 거리 `|dx| + |dy|`,
대각선도 되면 체비쇼프 거리 `max(|dx|, |dy|)` 가 표준 휴리스틱이다.
**유클리드 거리를 상하좌우 격자에 쓰면** 허용 가능하긴 하지만 약해서 손해다.

**타이브레이킹**: `f` 가 같은 항목이 많으면 목표에 가까운 쪽(`h` 가 작은 쪽)을 먼저 꺼내도록
2차 기준을 두면 눈에 띄게 빨라진다.

## 변형과 확장

- **가중 A\* (weighted A\*)**: `f = g + ε·h` (ε > 1). 허용 가능성을 포기하는 대신 훨씬 빠르다.
  답은 최적의 `ε` 배 이내임이 보장된다 — 실시간 경로 탐색에서 흔히 쓴다.
- **IDA\***: 반복 심화로 메모리를 O(깊이)까지 줄인다. 15-퍼즐 같은 거대 상태 공간용.
- **양방향 A\***: 시작과 목표에서 동시에 탐색한다. 휴리스틱 일관성 조건이 까다로워진다.
- **점프 포인트 탐색(JPS)**: 균일 격자에서 대칭인 경로들을 통째로 건너뛴다.
- **ALT / 랜드마크 휴리스틱**: 미리 고른 랜드마크까지의 실제 거리와 삼각부등식으로 `h` 를 만든다.
  좌표가 없는 그래프에서도 강력한 `h` 를 얻는 방법이다.
