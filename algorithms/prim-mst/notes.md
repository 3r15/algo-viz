## 한눈에

한 정점에서 트리를 시작해, 트리와 바깥을 잇는 **경계 간선 중 가장 싼 것**을 반복해 골라
정점을 하나씩 흡수한다. **절단 성질**이 이 탐욕을 정당화한다.

- **시간** `O(E log V)`(이진 힙) · `O(E + V log V)`(피보나치 힙) · `O(V²)`(배열, 밀집 그래프에 유리)
- **공간** `O(V + E)`
- **그리디가 최적** — MST 는 그리디가 통하는 대표 문제(절단 성질·사이클 성질)
- 크루스칼과 **가중치 합이 같다**(MST 합은 유일). 간선 조합은 다를 수 있다

**언제 쓰나** — 네트워크·회로·도로 설계에서 "모두 잇는 최소 비용". **밀집 그래프**(`E ≈ V²`)에서
배열 구현이 `O(V²)` 로 크루스칼(`O(E log E)`)보다 유리하다. 근사 알고리즘의 부품으로도 쓴다
(외판원 2-근사, 슈타이너 트리).

**언제 안 쓰나** — **희소 그래프**에서는 [크루스칼](#/algo/kruskal)이 구현이 단순하고 비슷하게 빠르다.
간선이 동적으로 추가/삭제되면 링크-컷 트리 같은 동적 MST 구조가 필요하다.
방향 그래프의 최소 신장 **수목도(arborescence)** 는 다른 알고리즘(Chu–Liu/Edmonds)이다.

## 동작 원리

MST 는 정점 `n` 개를 잇는 사이클 없는 부분 그래프 중 가중치 합 최소인 것이다.
간선은 정확히 `n-1` 개.

프림은 **정점 집합을 키운다**. 트리 `T`(처음엔 `{s}`)와 나머지 사이의 절단에서
가장 싼 간선을 골라 반대편 정점을 `T` 에 넣는다.

```
key[v] = min{ w(u,v) : u ∈ T }        v 를 트리에 잇는 최소 간선 가중치
매 단계:  key 가 최소인 바깥 정점 u 를 뽑아 T 에 넣고, u 의 이웃 key 갱신
```

우선순위 큐로 최소 `key` 를 꺼낸다. 구조가 [다익스트라](#/algo/dijkstra)와 판박이고,
차이는 갱신 식 하나다.

```
다익스트라:  cand = dist[u] + w        시작점까지 누적
프림      :  cand = w                  트리까지 간선 하나
```

### 실행 예 (기본 그래프)

```
{0}                key: 1→2, 2→4
0—1(2)  {0,1}      1—2(3)<4 → key2=3,  1—3(3) → key3=3
1—2(3)  {0,1,2}    2—4(6) → key4=6
1—3(3)  {…,3}      3—4(5)<6 → key4=5,  3—5(1) → key5=1
3—5(1)  {…,5}      4—5(4)<5 → key4=4
4—5(4)  전부

MST 간선: 0—1, 1—2, 1—3, 3—5, 4—5    합 = 2+3+3+1+4 = 13
```

## 정확성

두 성질이 MST 그리디의 양대 축이다. 프림은 **절단 성질**로 정당화된다.

### 절단 성질

> **정의.** 절단 `(S, V∖S)` 는 정점을 두 덩어리로 나눈 것이고, 경계 간선은 양쪽에 끝점을 하나씩 둔 간선이다.
> **절단 성질.** 어떤 절단에서든, 그 경계 간선 중 **가중치가 유일한 최소**인 간선 `e` 는 **모든** MST 에 속한다.
> (최소가 여럿이면, 그중 적어도 하나를 포함하는 MST 가 존재한다.)

**증명(교환 논법).** `e = (u, v)` 를 절단 `(S, V∖S)` 의 최소 경계 간선이라 하자.
`e` 를 포함하지 않는 MST `T` 가 있다고 가정한다. `T` 에 `e` 를 더하면 유일한 사이클 `C` 가 생긴다.
`C` 는 `e` 로 절단을 한 번 넘었으므로, 반드시 **다른 경계 간선 `f`** 로 절단을 되넘어 온다.

`e` 가 최소 경계 간선이므로 `w(e) ≤ w(f)`. `T' = T − f + e` 를 보자.

- `T'` 도 신장 트리다 — 사이클 `C` 에서 간선 하나(`f`)를 빼면 연결성이 유지되고 간선 수도 `n-1` 이다.
- `w(T') = w(T) − w(f) + w(e) ≤ w(T)`.

`T` 가 MST 이므로 `w(T') ≥ w(T)`, 따라서 `w(T') = w(T)` 이고 `T'` 도 MST 다.
`T'` 은 `e` 를 포함한다. `w(e)` 가 유일 최소면 `w(e) < w(f)` 라 `w(T') < w(T)` 가 되어
`T` 가 최적이라는 데 모순이므로 애초에 `e ∉ T` 일 수 없다. ∎

### 프림의 정확성

> **불변식.** 프림이 만드는 트리 `T` 는 항상 **어떤 MST 의 부분 트리**다.

`T` 에 든 간선 개수에 대한 귀납법.

**기저** — `T = {s}`, 간선 0개. 공집합은 모든 MST 의 부분 집합이므로 성립. ✓

**유지** — `T` 가 어떤 MST `T*` 의 부분 트리라 하자. 프림은 절단 `(V(T), V∖V(T))` 의
최소 경계 간선 `e` 를 고른다. 절단 성질에 의해 `e` 를 포함하는 MST 가 존재한다.

- `e ∈ T*` 이면 `T + e` 도 `T*` 의 부분 트리다. ✓
- `e ∉ T*` 이면, 절단 성질 증명의 교환으로 `T*' = T* − f + e` 도 MST이고 `T + e ⊆ T*'`.
  ( `f` 는 `T* + e` 의 사이클이 절단을 되넘는 경계 간선. `V(T)` 안의 `T` 간선은 절단을 넘지 않으므로
  `f ∉ T`, 따라서 `T + e ⊆ T*'` 가 유지된다.) ✓

어느 경우든 `T + e` 가 어떤 MST 의 부분 트리다.

**종료 시** — `T` 가 모든 정점을 포함하고 어떤 MST 의 부분 트리이며 간선이 `n-1` 개다.
`n-1` 개 간선을 가진 신장 부분 트리는 MST 자신이다. ∎

**가중치 합의 유일성** — 서로 다른 MST 라도 가중치 다중집합이 같음이 알려져 있다.
그래서 프림·크루스칼이 다른 간선 집합을 내도 **합은 항상 같다**(예제에서 13).

## 복잡도

| 구현 | 시간 | 유리한 경우 |
|---|---|---|
| 이진 힙 + 인접 리스트 | `O(E log V)` | 희소 그래프 |
| 피보나치 힙 | `O(E + V log V)` | 이론적 최적(상수 큼) |
| 배열(힙 없음) | `O(V²)` | **밀집** 그래프 `E ≈ V²` |

**이진 힙** — 각 간선이 최대 한 번 `key` 를 낮춰 PQ 에 들어가므로 push 가 `O(E)`,
각 push/pop 이 `O(log V)`. 정점 pop 이 `O(V log V)`. 합쳐 `O(E log V)`.
"낡은 항목" 을 지연 삭제하므로 PQ 크기가 `O(E)` 까지 커질 수 있지만 점근은 같다.

**배열 구현** — 매 단계 `key` 배열을 훑어 최소를 찾으면 `O(V)`, `V` 번 반복해 `O(V²)`.
간선 갱신 총합이 `O(E)`. 밀집 그래프(`E = Θ(V²)`)에서는 `O(V²)` 가 힙의 `O(E log V) = O(V² log V)` 보다
빨라 **힙 없는 쪽이 이긴다**.

**크루스칼과 비교**

```
프림(힙)   :  O(E log V)      정점 중심, 밀집에 배열로 O(V²)
크루스칼   :  O(E log E)      간선 중심, 정렬 + 유니온-파인드
```

`E ≤ V²` 이라 `log E ≤ 2 log V` — 점근적으로 둘은 같은 급이다. 선택은 그래프 밀도와 구현 편의로 갈린다.

## 구현 노트

**최소 힙** — `greater<>` 필수.

**낡은 항목 지연 삭제** — `if (inMST[u]) continue;`. PQ 에서 `decrease-key` 를 직접 지원하지 않으므로
갱신된 값을 새로 push 하고, 꺼낼 때 이미 처리된 것을 버린다.

**갱신 식** — `key[v] = w`(간선 가중치)지 누적 거리가 아니다. 이 한 줄이 MST 와 최단 경로 트리를 가른다.

**비연결 판정** — 끝에 트리 정점 수가 `V` 보다 작으면 신장 트리가 없다.
모든 정점을 강제로 훑는 **최소 신장 숲(forest)** 변형은 각 연결 요소의 MST 를 따로 만든다.

**밀집 그래프면 배열로** — 인접 행렬 + `key` 배열 스캔이 `O(V²)` 이고 상수도 작다.

## 변형과 확장

### 최소 신장 숲

그래프가 끊겨 있으면 각 연결 요소마다 MST 를 만든다. 아직 안 든 정점이 있으면 그중 하나에서
다시 시작하는 바깥 루프를 두면 된다.

### 크루스칼 — 같은 정리의 다른 얼굴

간선을 가중치 순으로 훑으며 사이클을 안 만드는 것만 채택한다. 절단 성질 대신 **사이클 성질**
("사이클에서 가장 비싼 간선은 어떤 MST 에도 없다")로 정당화되지만, 둘은 동전의 양면이다.
[유니온-파인드](#/algo/kruskal)로 사이클을 판정한다.

### 보르브카 알고리즘

각 정점이 동시에 자기 최소 간선을 고르고 요소를 합친다. 라운드마다 요소 수가 절반 이하로 줄어
`O(E log V)`. **병렬화가 쉬워** 분산 MST 의 기반이고, 현대 준선형 MST 알고리즘의 출발점이다.

### 외판원 문제 2-근사

MST 를 만들고 DFS 순회로 정점을 방문하면, 삼각 부등식을 만족하는 TSP 의 최적해의 **2배 이내** 경로를 얻는다.
MST 가 최적 투어의 하한이라는 성질을 쓴다. 크리스토파이디스 알고리즘은 이를 1.5-근사로 개선한다.

### 최소 병목 신장 트리

가중치 **합** 대신 **최대 간선**을 최소화한다. 놀랍게도 **모든 MST 가 최소 병목 신장 트리**다
(절단 성질의 따름). 역은 성립하지 않는다.
