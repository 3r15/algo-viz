## 한눈에

텍스트에서 패턴을 찾되 **텍스트 포인터를 절대 되돌리지 않는다.** 패턴이 자기 자신과 겹치는 정도
(**실패 함수** `fail`)를 미리 계산해, 어긋나면 패턴만 그만큼 미끄러뜨린다. 전체 `Θ(n + m)`.

- **시간** `Θ(n + m)` — 전처리 `Θ(m)` + 검색 `Θ(n)` · **공간** `Θ(m)`(실패 함수)
- 순진한 `O(n·m)` 의 텍스트 되읽기를 없앤다
- `fail[i]` = `pattern[0..i]` 의 최장 **진접두사=진접미사** 길이
- 알파벳 크기와 무관 — 비교만으로 동작

**언제 쓰나** — 한 패턴을 (여러) 텍스트에서 찾을 때, 스트리밍(텍스트를 되감을 수 없을 때),
`O(n·m)` 이 위험한 큰 입력. 실패 함수는 문자열의 주기·경계 분석에도 쓰인다.

**언제 안 쓰나** — 패턴이 여러 개면 [아호-코라식], 근사 매칭이면 다른 알고리즘.
평균적으로는 Boyer–Moore 가 더 빠를 때가 많다(KMP 는 **최악** 보장이 강점).

## 동작 원리

두 단계 모두 **"어긋나면 `k = fail[k-1]` 로 줄인다"** 는 같은 규칙을 쓴다.

```
① buildFail(p):  패턴을 패턴에 맞춰 보며 접두사=접미사 길이를 채운다
② search(t, p):  텍스트를 훑으며 k 글자까지 일치를 추적, k==m 이면 발견
```

### 실패 함수의 의미

`fail[i]` 는 `pattern[0..i]` 에서 **양끝이 겹치는 가장 긴 조각**의 길이다.
어긋났을 때 이미 맞은 `k` 글자의 뒤쪽 `fail[k-1]` 글자는 패턴 앞쪽과 같음이 보장되므로,
그만큼은 **다시 맞출 필요가 없다.** 패턴을 `k − fail[k-1]` 칸 미끄러뜨리면 된다.

### 실행 예

패턴 `ababa` → `fail = [0, 0, 1, 2, 3]`.
텍스트 `ababcababa` 에서 `i=4`(`c`)에 어긋나면 `k=4 → fail[3]=2` 로 줄여, 앞 `ab` 는 맞은 셈 치고
텍스트 `i=4` 에서 이어 본다. 텍스트 포인터는 그대로다.

## 정확성

> **실패 함수 정의.** `fail[i] = max { ℓ < i+1 : pattern[0..ℓ-1] = pattern[i-ℓ+1..i] }`,
> 없으면 0. (진접두사 = 진접미사의 최장 길이.)

> **검색 불변식.** 텍스트 위치 `i` 를 처리한 뒤 `k` 는 **`pattern[0..k-1] = text[i-k+1..i]` 를 만족하는
> 최대값**이다. 즉 현재 위치에서 맞을 수 있는 가장 긴 패턴 접두사의 길이.

**미끄러뜨림의 정당성** — `pattern[0..k-1] = text[i-k+1..i]` 인데 `text[i+1] ≠ pattern[k]` 로 어긋났다 하자.
다음으로 가능한 일치는 패턴의 어떤 **접두사** 가 텍스트의 현재 **접미사** 와 맞을 때뿐이다.
그런 접두사 중 가장 긴 것의 길이가 정확히 `fail[k-1]` 이다. 그래서 `k ← fail[k-1]` 로 줄이면
가능한 일치를 **하나도 놓치지 않는다.** `k=0` 까지 줄면 `text[i+1]` 부터 새로 시작. ∎

**완전성** — `k` 는 위 불변식의 최대값을 항상 유지하므로, `k=m` 이 되는 첫 순간이 패턴의 첫 등장이고
그 위치는 `i − m + 1`. 텍스트를 왼→오 순회하므로 **가장 이른** 등장이 먼저 잡힌다.

## 복잡도

| | 전처리 | 검색 | 공간 |
|---|---|---|---|
| KMP | `Θ(m)` | `Θ(n)` | `Θ(m)` |

### 왜 검색이 `Θ(n)` 인가 — 전위(amortized) 인자 `2i − k`

각 반복에서 `i` 는 최대 1 증가하고, `while` 은 `k` 를 **줄이기만** 한다. 포텐셜 `Φ = 2i − k` 를 보자.

- `i` 가 1 늘고 `k` 가 최대 1 늘면 `Φ` 는 최소 `2−1 = 1` 증가.
- `while` 한 번 돌 때 `k` 는 최소 1 감소 → `Φ` 는 최소 1 증가하지만 이는 `i` 증가로 **미리 적립된** 몫에서 빠진다.

`k ≥ 0` 이고 `i ≤ n` 이라 `Φ ≤ 2n`. `while` 총 실행 횟수는 `Φ` 증가분에 묶이므로 `O(n)`.
즉 어긋남 미끄러뜨림을 다 합쳐도 `2n` 을 못 넘는다 — **텍스트를 되감지 않기** 때문이다.
전처리도 같은 논증으로 `O(m)`.

### 순진한 방법과의 대비

순진한 방법은 각 시작 위치에서 최대 `m` 글자를 다시 비교 → 최악 `Θ(n·m)`
(예: 텍스트 `aa…a`, 패턴 `aa…ab`). KMP 는 이미 맞은 정보를 재활용해 이 되읽기를 제거한다.

## 구현 노트

**진접두사=진접미사** — `fail` 은 반드시 자기 자신 전체를 **제외**해야 한다. 포함하면 미끄러뜨림이 멈춰
무한 루프/오답.

**`while` 이지 `if` 가 아니다** — 한 번 줄여도 또 어긋날 수 있어 `fail` 사슬을 따라 여러 번 줄인다.

**모든 등장 찾기** — `k == m` 에서 반환하지 말고 위치를 기록한 뒤 `k = fail[m-1]` 로 이어 탐색하면
겹치는 등장까지 모두 찾는다.

**두 루프가 쌍둥이** — `buildFail` 은 패턴을 자기 자신에 대해 KMP 한 것이다. 같은 미끄러뜨림 규칙.

## 변형과 확장

### Z-함수 — 같은 정보, 다른 각도

`z[i]` = 위치 `i` 에서 시작하는 접미사와 전체 문자열의 최장 공통 접두사 길이. `fail` 과 상호 변환 가능하며,
패턴+구분자+텍스트에 Z-함수를 돌려도 검색이 된다.

### 아호-코라식 — 패턴 여러 개

여러 패턴을 트라이로 묶고 실패 링크(KMP 의 `fail` 을 트라이로 일반화)를 걸어, 텍스트 한 번 훑기로
모든 패턴을 동시에 찾는다(`O(n + Σm + 매칭 수)`).

### 문자열 주기 — `fail` 의 응용

문자열 `s`(길이 `L`)의 최소 주기는 `L − fail[L-1]`. `fail` 하나로 주기성·경계(border) 구조를 읽는다.
문자열이 어떤 조각의 반복인지 판정하는 고전 문제가 이 한 줄로 풀린다.

### Boyer–Moore·Rabin–Karp — 다른 접근

Boyer–Moore 는 패턴을 **뒤에서** 비교해 평균적으로 글자를 건너뛴다(실전 최속 계열).
Rabin–Karp 는 해시로 후보를 걸러 다중 패턴·2차원 매칭에 유리. KMP 는 이들과 달리 **최악 선형**을 보장한다.
