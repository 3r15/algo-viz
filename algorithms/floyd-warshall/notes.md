## 한눈에

**모든 정점 쌍**에 대한 최단 거리를 한 번에 구한다. 3중 반복문 다섯 줄이 전부다.

```cpp
for (int k = 0; k < n; k++)
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
```

핵심 발상은 "경유해도 되는 정점을 하나씩 늘려 간다"는 것이다.
`k` 가 늘어날 때마다 표 전체가 한 단계씩 더 정확해진다.

- 시간 O(V³) · 공간 O(V²)
- **음수 간선을 허용한다**([다익스트라](#/algo/dijkstra)는 못 한다). 음수 사이클도 탐지할 수 있다
- V 가 400~500 정도까지 현실적. 그보다 크면 각 정점에서 다익스트라를 돌리는 편이 낫다

## 동작 원리

`dist_k[i][j]` 를 이렇게 정의한다.

> **중간 경유지를 `0 .. k-1` 중에서만 고를 때**의 `i → j` 최단 거리
> (양 끝 `i`, `j` 는 이 제한과 무관하다)

`k = 0` 이면 경유가 아예 금지되므로 간선 하나로 가는 경우뿐이다 — 이게 초기 표다.

이제 `k` 를 하나 늘려 정점 `k` 를 경유지로 허용하면, `i → j` 최단 경로는 둘 중 하나다.

1. **`k` 를 지나지 않는다** → 값은 그대로 `dist_k[i][j]`
2. **`k` 를 지난다** → 경로는 `i ⇝ k ⇝ j` 로 쪼개지고, 각 조각은 `k` 를 중간에 쓰지 않는다
   (최단 경로는 같은 정점을 두 번 지나지 않는다). 따라서 `dist_k[i][k] + dist_k[k][j]`

```
dist_{k+1}[i][j] = min( dist_k[i][j],  dist_k[i][k] + dist_k[k][j] )
```

`k = n` 까지 돌리면 모든 정점을 경유지로 쓸 수 있으니 진짜 최단 거리다.

시각화에서 `k` 가 바뀔 때마다 그래프의 정점 하나가 밝아지고, 표의 **`k` 행과 `k` 열**이
강조된다. 그 두 줄이 이번 라운드의 재료 전부다.

### 왜 `k` 가 가장 바깥이어야 하는가

`i`, `j` 순서는 바꿔도 되지만 **`k` 는 반드시 맨 바깥**이어야 한다.
`k` 루프가 안쪽에 있으면 "경유지 집합을 0..k-1 로 제한한다"는 정의가 깨진다.
어떤 `(i,j)` 는 아직 갱신되지 않은 `k` 정보를 쓰고, 어떤 것은 이미 갱신된 것을 써서
계층이 뒤섞인다. 결과는 대부분의 입력에서 **조용히 틀린다** — 이 알고리즘에서 가장 흔한 버그다.

### 제자리 갱신은 왜 안전한가

`dist_k` 와 `dist_{k+1}` 을 따로 두지 않고 배열 하나를 덮어써도 된다. `k` 번째 라운드에서
읽는 값은 `dist[i][k]` 와 `dist[k][j]` 인데, 이 둘은 이 라운드에서 바뀌지 않기 때문이다.

```
dist[i][k] 가 갱신되려면  dist[i][k] > dist[i][k] + dist[k][k]  이어야 한다
                        ⟺ dist[k][k] < 0  ⟺ k 를 지나는 음수 사이클
```

음수 사이클이 없다면 `dist[k][k] = 0` 이라 `k` 행·열은 그대로다. 그래서 안전하다.

## 정확성

### `k` 에 대한 귀납

> **주장**: `k` 번째 라운드가 끝난 뒤 `dist[i][j]` 는 "경유지를 `0..k` 로 제한한 최단 거리"다.

**기저** (`k` 라운드 전, 즉 초기 표): 경유가 금지되므로 `i→j` 간선이 있으면 그 가중치,
없으면 `∞`, `i = j` 면 0. 정의와 일치한다.

**귀납 단계**: `k-1` 까지 참이라 하자. 경유지를 `0..k` 로 허용한 최단 경로 `P` 를 보자.

- `P` 가 `k` 를 지나지 않으면 `P` 는 경유지 `0..k-1` 짜리 경로이므로 귀납 가정에 의해
  이미 `dist[i][j]` 에 반영돼 있다.
- `P` 가 `k` 를 지나면, `P` 를 `k` 에서 잘라 `P₁: i ⇝ k` 와 `P₂: k ⇝ j` 로 나눈다.
  **최단 경로는 어떤 정점도 두 번 지나지 않으므로**(음수 사이클이 없다는 가정 아래)
  `P₁`, `P₂` 의 중간 정점에는 `k` 가 없다. 즉 둘 다 경유지 `0..k-1` 짜리 경로이고,
  각각 최단이어야 한다(부분 경로 최적성). 귀납 가정에 의해 그 값이 `dist[i][k]`, `dist[k][j]` 다.

두 경우의 최솟값을 취하는 것이 정확히 갱신식이므로 주장이 성립한다. ∎

### 음수 간선은 되고, 음수 사이클은 안 된다

증명에서 **"최단 경로는 정점을 두 번 지나지 않는다"** 를 썼다. 음수 사이클이 있으면
사이클을 돌수록 비용이 줄어 최단 경로가 존재하지 않으므로 이 전제가 깨진다.

다만 **탐지는 가능하다.** 알고리즘을 끝까지 돌린 뒤

```cpp
for (int i = 0; i < n; i++)
    if (dist[i][i] < 0) → i 를 지나는 음수 사이클이 존재
```

`dist[i][i] < 0` 은 "`i` 에서 출발해 `i` 로 돌아오는 음수 비용 경로"라는 뜻이니 그대로 음수 사이클이다.

> 주의: 음수 사이클이 있으면 그 사이클의 영향을 받는 쌍들의 `dist` 값 자체는 의미가 없다.
> `-INF` 로 표시하려면 "음수 사이클에 도달 가능하고, 거기서 `j` 로 갈 수 있는" 쌍을 따로 표시해야 한다.

## 복잡도

| | |
|---|---|
| 시간 | **Θ(V³)** — 입력에 무관하게 항상 |
| 공간 | **Θ(V²)** — 표 하나 |

반복 횟수가 `V³` 로 고정이라 최선·평균·최악이 없다. 대신 **상수가 매우 작다**.
안쪽 루프가 덧셈 한 번, 비교 한 번, 연속된 메모리 접근이라 캐시에 잘 맞는다.
그래서 실측에서는 `V ≈ 400` 정도까지 다른 방법보다 빠른 경우가 많다.

### 모든 쌍을 구하는 다른 방법과 비교

| 방법 | 시간 | 음수 간선 |
|---|---|---|
| 플로이드-워셜 | Θ(V³) | ○ (사이클만 없으면) |
| 각 정점에서 [다익스트라](#/algo/dijkstra) | O(V·E log V) | ✗ |
| 존슨 (벨만-포드 + 다익스트라 V회) | O(VE + V² log V) | ○ |

**희소 그래프**(E ≈ V)에서는 다익스트라 V 회가 `O(V² log V)` 로 훨씬 빠르다.
**밀집 그래프**(E ≈ V²)에서는 다익스트라 V 회가 `O(V³ log V)` 라 플로이드-워셜이 이긴다.

## 구현 노트

**`INF` 오버플로**: `dist[i][k] + dist[k][j]` 에서 둘 다 `INF` 면 오버플로가 난다.
`INF = 0x3f3f3f3f` 처럼 **두 배 해도 int 범위 안에 드는 값**을 쓰거나,
갱신 전에 `if (dist[i][k] == INF || dist[k][j] == INF) continue;` 로 걸러 낸다.
이 페이지의 생성기도 후자를 쓴다.

**초기화 순서**: `dist[i][i] = 0` 을 간선 반영 **뒤에** 하면, `i→i` 자기 루프 간선이
0 으로 덮여 버린다. 보통은 자기 루프가 최단 거리에 영향을 주지 않아 상관없지만,
음수 자기 루프를 탐지하려면 순서에 주의해야 한다.

**중복 간선**: 같은 `(u,v)` 간선이 여러 개면 **최솟값**을 넣어야 한다. 그냥 덮어쓰면
나중에 읽은 값이 남는다.

**경로 복원**: `next[i][j]` 에 "`i` 에서 `j` 로 갈 때 첫 걸음"을 기록한다.
갱신할 때 `next[i][j] = next[i][k]` 로 두면 된다.

```cpp
vector<int> path(int i, int j) {
    if (next[i][j] == -1) return {};          // 경로 없음
    vector<int> p = {i};
    while (i != j) { i = next[i][j]; p.push_back(i); }
    return p;
}
```

**메모리**: `V = 1000` 이면 `int` 표가 4MB다. `V` 가 커지면 공간이 먼저 문제가 된다.

## 변형과 확장

- **워셜 알고리즘 (도달 가능성)**: `min`/`+` 를 `OR`/`AND` 로 바꾸면 **추이 폐포**(어느 정점에서
  어느 정점으로 갈 수 있는가)를 구한다. `bitset` 으로 64배 가속하는 것이 정석이다.
  ```cpp
  if (reach[i][k]) reach[i] |= reach[k];      // bitset<N> reach[N]
  ```
- **최소-최대 경로 (병목 경로)**: `min(dist[i][j], max(dist[i][k], dist[k][j]))` 로 바꾸면
  "경로상 최대 간선을 최소화"하는 값을 얻는다.
- **최대 확률 경로**: `max` 와 `×` 로 바꾸면 가장 확률이 높은 경로.
- **세미링 일반화**: `(min, +)` 를 임의의 **닫힌 세미링** 연산으로 바꿔도 골격이 그대로 동작한다.
  위 변형들이 전부 이 한 틀의 특수한 경우다.
- **동적 추가**: 간선 하나가 추가됐을 때는 전체를 다시 돌릴 필요 없이
  `O(V²)` 에 갱신할 수 있다(추가된 간선 `(u,v)` 를 경유지로 한 번만 돌리면 된다).
