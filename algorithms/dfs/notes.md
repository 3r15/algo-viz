## 한눈에

갈 수 있는 데까지 **깊이 파고들었다가**, 더 갈 곳이 없으면 한 걸음 되돌아와(백트래킹)
다른 길을 시도한다. 재귀 호출 스택이 곧 "지금까지 걸어온 경로"다.

BFS가 "가까운 순서"를 준다면 DFS는 **"들어간 순서와 나온 순서"** 를 준다. 이 두 시각이
위상 정렬·사이클 판정·단절점·SCC 같은 구조적 성질을 푸는 열쇠가 된다.

- 자료구조는 **스택(LIFO)** — 재귀가 암묵적으로 제공한다
- 시간 O(V+E) · 공간 O(V)

## 동작 원리

```
dfs(u):
    visited[u] = true
    for v in adj[u]:
        if !visited[v]:
            dfs(v)              // 되돌아올 자리는 호출 스택이 기억한다
```

BFS와 코드 구조가 거의 같다. 차이는 딱 하나, **다음에 처리할 정점을 어디서 꺼내는가**다.

| | 꺼내는 곳 | 방문 순서 |
|---|---|---|
| BFS | 큐의 앞 (FIFO) | 가까운 정점부터 층별로 |
| DFS | 스택의 위 (LIFO) | 한 줄기를 끝까지 |

시각화의 `stack` 표시가 현재 재귀 경로다. 스택이 깊어졌다가 얕아지는 리듬이 곧
"파고들었다가 되돌아오는" 움직임이다.

### 진입/종료 시각

DFS를 쓸모 있게 만드는 것은 각 정점에 두 개의 타임스탬프를 붙이는 것이다.

```cpp
void dfs(int u) {
    tin[u] = ++timer;            // 진입 시각
    for (int v : adj[u]) if (!visited[v]) dfs(v);
    tout[u] = ++timer;           // 종료 시각
}
```

`[tin[u], tout[u]]` 구간들은 서로 **포함되거나 완전히 분리되거나** 둘 중 하나다(괄호 성질).
`u`가 `v`의 조상 ⟺ `tin[u] < tin[v] < tout[v] < tout[u]` 라는 판정이 O(1)에 된다.

## 정확성

### 도달 가능한 정점을 모두 방문한다

`s`에서 도달 가능한 정점 `v`를 보자. `s → x₁ → x₂ → … → v` 경로를 잡는다.
`visited` 가 되지 않은 첫 번째 정점을 `x_k` 라 하면, `x_{k-1}` 은 방문됐으므로 `dfs(x_{k-1})`
이 호출됐고, 그 안의 for 문은 **모든** 이웃을 검사하므로 `x_k` 도 검사된다.
그 시점에 `x_k` 가 미방문이면 `dfs(x_k)` 가 호출되고, 이미 방문됐다면 모순이다.
따라서 그런 `x_k` 는 없고 `v`는 방문된다. ∎

### 흰 경로 정리 (white-path theorem)

> `dfs(u)` 를 **시작하는 시점**에, `u`에서 `v`로 가는 경로가 존재하고 그 경로 위의 모든 정점이
> 아직 미방문("흰색")이라면, `v`는 DFS 트리에서 `u`의 자손이 된다.

이것이 DFS 트리의 구조를 지배하는 핵심 정리다. 사이클 판정과 SCC 알고리즘의 정당성이
모두 여기서 나온다.

### 종료성

각 정점에서 `dfs` 는 최대 한 번 호출된다(`visited` 검사). 정점 수가 유한하므로 종료한다.

## 복잡도

| | |
|---|---|
| 시간 | **O(V + E)** |
| 공간 | O(V) — `visited` + **재귀 스택 최악 O(V)** |

BFS와 동일하다. 각 정점에서 `dfs` 가 한 번 호출되고(O(V)), 각 호출이 그 정점의 인접 리스트를
한 번 훑는다(총합 O(E)).

공간에서 BFS와 다른 점은 **재귀 깊이**다. 경로 그래프처럼 한 줄로 늘어선 그래프에서는
재귀 깊이가 `V`에 도달한다. 정점이 수십만 개면 **스택 오버플로가 실제로 발생한다.**

## 구현 노트

**재귀 깊이가 위험할 때는 명시적 스택으로 바꾼다.**

```cpp
stack<int> st;  st.push(s);  visited[s] = true;
while (!st.empty()) {
    int u = st.top(); st.pop();
    // u 처리
    for (int v : adj[u])
        if (!visited[v]) { visited[v] = true; st.push(v); }
}
```

> 주의: 이 반복 버전은 방문 순서가 재귀 버전과 **다르다**(인접 리스트를 역순으로 밀어 넣는 셈이라
> 마지막 이웃부터 파고든다). 그리고 `tout`(종료 시각)을 얻으려면 "정점을 두 번 스택에 넣고
> 두 번째 방문에서 종료 처리"하는 식의 추가 장치가 필요하다. 순서나 종료 시각이 중요한
> 알고리즘을 반복 버전으로 옮길 때 가장 흔히 깨지는 지점이다.

**연결 요소 세기**: 모든 정점에 대해 미방문이면 `dfs` 를 시작한다. 시작한 횟수가 연결 요소 수다.

```cpp
int cnt = 0;
for (int v = 0; v < n; v++) if (!visited[v]) { dfs(v); cnt++; }
```

**사이클 판정**: 무방향 그래프에서는 "부모가 아닌 이미 방문한 이웃"을 만나면 사이클이다.
방향 그래프에서는 `visited` 만으로는 부족하고, **현재 재귀 경로 위에 있는지**를 나타내는
별도 상태(회색)가 필요하다. 회색 정점으로 가는 간선(back edge)이 사이클이다.

## 변형과 확장

- **위상 정렬**: DFS 종료 시각의 **역순**이 위상 순서다. 방향 비순환 그래프(DAG)에서
  O(V+E)에 정렬된다.
- **강한 연결 요소(SCC)**: 코사라주(두 번의 DFS) 또는 타잔(한 번의 DFS + low-link)으로 O(V+E).
- **단절점·다리(articulation point / bridge)**: `tin` 과 low-link 값을 비교해 한 번의 DFS로 찾는다.
- **백트래킹**: N-Queens, 순열 생성, 스도쿠 같은 탐색 문제는 "상태 공간 그래프 위의 DFS"다.
  DFS의 되돌아오는 성질이 곧 백트래킹이다.
- **오일러 경로**: Hierholzer 알고리즘은 DFS를 변형해 모든 간선을 정확히 한 번 지나는 경로를 찾는다.
