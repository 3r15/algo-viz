## 어떤 문제인가

미로에 들어갔다고 하자. 지도도 없고 전체를 볼 수도 없다. 어떻게 탐색하겠는가?

한 가지 방법은 **한쪽 길로 갈 수 있는 데까지 가 보는 것**이다. 막다른 골목이면
갈림길로 되돌아와 다른 길을 시도한다. 이게 **깊이 우선 탐색(Depth-First Search)** 이다.

[BFS](#/algo/bfs)가 "가까운 곳부터 골고루"라면, DFS 는 **"한 줄기를 끝까지"** 다.

> 최단 경로는 DFS 로 못 구한다. 대신 DFS 는 다른 걸 준다 —
> **"언제 들어갔고 언제 나왔는가"**, 즉 그래프의 구조 정보다.

## 손으로 해보기

같은 그래프에서 0번부터 출발해 보자.

```
      1 ─── 3
     /        \
    0          5
     \        /
      2 ─── 4
```

이웃은 번호가 작은 것부터 본다고 하자.

```
0 방문 (들어감)
 └ 이웃 1 → 안 봤다 → 내려간다
   1 방문 (들어감)
    └ 이웃 0 → 이미 봤다 → 건너뜀
    └ 이웃 3 → 안 봤다 → 내려간다
      3 방문 (들어감)
       └ 이웃 1 → 이미 봤다
       └ 이웃 5 → 안 봤다 → 내려간다
         5 방문 (들어감)
          └ 이웃 3 → 이미 봤다
          └ 이웃 4 → 안 봤다 → 내려간다
            4 방문 (들어감)
             └ 이웃 2 → 안 봤다 → 내려간다
               2 방문 (들어감)
                └ 이웃 0 → 이미 봤다
                └ 이웃 4 → 이미 봤다
               2 나옴 ←
            4 나옴 ←
         5 나옴 ←
      3 나옴 ←
   1 나옴 ←
0 나옴 ←
```

방문 순서는 `0 → 1 → 3 → 5 → 4 → 2`.

BFS 의 `0, 1, 2, 3, 4, 5` 와 비교해 보자. **완전히 다르다.**
DFS 는 `0→1→3→5→4→2` 로 한 줄기를 쭉 따라갔다.

### 되돌아오는 것이 핵심이다

들여쓰기가 깊어졌다가 얕아지는 리듬을 보자. `2` 에서 더 갈 곳이 없자
`2 → 4 → 5 → 3 → 1 → 0` 순서로 차례차례 빠져나온다.

**"어디로 되돌아가야 하는지"를 누가 기억하고 있는가?** 우리가 따로 적어 두지 않았다.
들여쓰기 자체, 즉 **함수 호출이 쌓인 순서**가 기억하고 있다.

## 아이디어 쌓기

### 1단계 — 재귀가 곧 "되돌아오기"다

DFS 를 말로 쓰면 이렇다.

```
방문(u):
    u 를 방문했다고 표시
    u 의 각 이웃 v 에 대해:
        v 를 아직 안 봤으면 → 방문(v)
```

`방문(v)` 가 끝나고 돌아오면 자동으로 `u` 의 다음 이웃으로 넘어간다.
**되돌아오는 코드를 우리가 쓰지 않아도 된다** — 함수가 반환하는 것이 곧 되돌아오기다.

### 2단계 — 무한 루프를 막는 것도 `visited`

사이클이 있으면 `0 → 1 → 0 → 1 → …` 로 영원히 내려간다.
[BFS](#/algo/bfs)와 똑같이 `visited` 로 막는다.

### 3단계 — BFS 와 무엇이 다른가

코드 구조가 거의 같다. 딱 하나가 다르다.

| | 다음에 볼 정점을 어디서 꺼내나 |
|---|---|
| BFS | **큐** — 가장 먼저 넣은 것 |
| DFS | **스택** — 가장 나중에 넣은 것 |

재귀를 쓰면 스택을 직접 만들 필요가 없다. 함수 호출 스택이 그 역할을 한다.
시각화의 `stack` 표시가 바로 지금 재귀로 내려와 있는 경로다.

### 4단계 — DFS 가 진짜로 주는 것

방문 순서 자체는 별로 쓸모가 없다. 값진 건 **들어간 시각과 나온 시각**이다.

```cpp
void dfs(int u) {
    tin[u] = ++timer;                              // 들어간 시각
    for (int v : adj[u]) if (!visited[v]) dfs(v);
    tout[u] = ++timer;                             // 나온 시각
}
```

이 두 숫자로 "u 가 v 의 조상인가?"를 O(1)에 판정할 수 있고,
사이클 판정·위상 정렬·[SCC](#/algo/tarjan-scc)가 전부 여기서 나온다.

## 코드로 옮기기

```cpp
void dfs(vector<vector<int>>& adj, int u,
         vector<bool>& visited) {
    visited[u] = true;                // ← 2단계: 방문 표시
    for (int v : adj[u]) {            // ← 이웃을 차례로
        if (!visited[v]) {            // ← 안 본 것만
            dfs(adj, v, visited);     // ← 1단계: 재귀로 내려간다
        }                             //    (돌아오면 다음 이웃으로)
    }
}
```

BFS 코드와 나란히 놓고 보자.

```cpp
// BFS                              // DFS
q.push(s);                          dfs(s):
while (!q.empty()) {                    visited[u] = true;
    u = q.front(); q.pop();             for (v : adj[u])
    for (v : adj[u])                        if (!visited[v])
        if (!visited[v]) {                      dfs(v);
            visited[v] = true;
            q.push(v);
        }
}
```

**루프 몸통은 사실상 같다.** 큐를 쓰느냐 호출 스택을 쓰느냐만 다르다.

### 연결 요소 세기

DFS 의 가장 쉬운 응용이다. 모든 정점에 대해, 아직 안 봤으면 거기서 새로 시작한다.

```cpp
int count = 0;
for (int v = 0; v < n; v++)
    if (!visited[v]) { dfs(adj, v, visited); count++; }
// count = 서로 떨어져 있는 덩어리의 개수
```

## 자주 하는 실수

**`visited` 를 안 쓰거나 늦게 쓴다.** 사이클에서 무한 재귀 → 스택 오버플로.
함수에 들어가자마자 표시하는 것이 안전하다.

**재귀가 너무 깊어진다.** 정점이 한 줄로 늘어선 그래프(`0-1-2-…-99999`)에서는
재귀 깊이가 10만이 된다. 실제로 프로그램이 죽는다. 그럴 땐 스택을 직접 만든다.

```cpp
stack<int> st; st.push(s); visited[s] = true;
while (!st.empty()) {
    int u = st.top(); st.pop();
    for (int v : adj[u]) if (!visited[v]) { visited[v] = true; st.push(v); }
}
```

> 주의: 이 반복 버전은 **방문 순서가 재귀 버전과 다르다.** 이웃을 스택에 밀어 넣는 순서 때문에
> 마지막 이웃부터 파고든다. 그리고 "나온 시각"을 얻으려면 장치가 더 필요하다.

**BFS 를 써야 할 곳에 DFS 를 쓴다.** "최소 몇 번 만에"가 나오면 DFS 가 아니라 BFS 다.
DFS 로 찾은 경로는 **아무 경로**일 뿐 최단이 아니다.

## 스스로 확인하기

1. **`stack` 표시를 계속 보자.** 깊어졌다가 얕아지는 리듬이 곧 "파고들었다 되돌아오기"다.
2. 같은 그래프를 [BFS](#/algo/bfs)에도 넣어 방문 순서를 비교해 보자.
   BFS 는 `0 1 2 3 4 5`, DFS 는 `0 1 3 5 4 2` 다.
3. 편집기에서 **정점 하나를 떼어 놓고**(간선 없이) 실행해 보자.
   시작점에서 도달할 수 없으면 끝까지 방문되지 않는다.
4. 삼각형(`0-1`, `1-2`, `2-0`)을 만들어 보자. `visited` 가 없으면 무한히 돌 그래프다.

아래 **깊이 보기**에서는 **흰 경로 정리**를 소개하고, 그것이
위상 정렬·[SCC](#/algo/tarjan-scc)·단절점 같은 응용의 토대가 되는 과정을 다룬다.
