## 한눈에

평면 위 점 집합에서 **가장 가까운 두 점**을, x 로 나눠 재귀하고 분할선 근처 **띠(strip)** 만 검사해
`Θ(n log n)` 에 찾는다. 모든 쌍 비교 `O(n²)` 를 분할 정복으로 넘어선다.

- **시간** `Θ(n log n)` · **공간** `O(n)`
- 병합 단계의 **띠 성질** — 분할선 좌우 `d` 안, y 정렬 후 각 점당 **상수 개(≈8)** 만 비교
- 거리는 **제곱**으로 비교(정수 좌표면 전 과정 정수, 오차 0)
- 분할 정복 + 기하의 대표 결합

**언제 쓰나** — 최근접 쌍, 그로부터 파생되는 문제(충돌 후보, 군집의 밀도, 최소 간격).
스위프라인·격자 해싱으로도 풀린다.

**언제 안 쓰나** — 점이 적으면 `O(n²)` 전수 비교가 더 간단·빠르다. 동적 삽입/삭제엔 다른 구조.

## 동작 원리

```
closest(px):                       # px: x 로 정렬
    n ≤ 3 → 전수 비교
    분할선 x = px[mid].x 로 좌/우
    d = min(closest(left), closest(right))
    strip = { |x − 분할선| 이 √d 미만인 점 }, y 로 정렬
    for i in strip:
        for j in 다음 몇 개(y차 < √d):
            d = min(d, dist(strip[i], strip[j]))
    return d
```

### 띠 성질 — 왜 상수 개만?

각 절반은 이미 내부 최근접이 `≥ d` 다. 띠 안에서 한 점 `p` 를 기준으로 세로 `d`, 가로 `2d` 인 상자를
보면, 그 안의 점들은 서로 `≥ d` 떨어져 있어야 하므로 **많아야 상수 개(격자 논증으로 ≤ 8)** 만 들어간다.
따라서 y 정렬 후 각 점은 뒤쪽 상수 개만 비교하면 되고, 띠 검사가 `O(n)`.

## 정확성

> **정리.** `closest` 는 실제 최근접 쌍 거리를 반환한다.

*증명(분할 정복 귀납).* 최근접 쌍 `(p,q)` 는 세 경우 중 하나:
① 둘 다 왼쪽 → `closest(left)` 가 잡는다(귀납). ② 둘 다 오른쪽 → `closest(right)`. ③ 좌우로 갈림.

경우 ③: `dist(p,q) = δ < d = min(dl,dr)` 라 하자. 그러면 `p,q` 모두 분할선에서 `x` 거리 `< d` 안
(더 멀면 `δ ≥ d`), 즉 **둘 다 띠 안**에 있다. 또 `|p.y − q.y| < d` 이므로, y 정렬한 띠에서 `p` 뒤
상수 개 안에 `q` 가 있어 **반드시 비교된다**. 따라서 `d` 가 `δ` 로 갱신된다. 세 경우 모두 최근접을
놓치지 않는다. ∎

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 최근접 점 쌍 | `Θ(n log n)` | `O(n)` |

### 점화식

x 정렬을 한 번 해 두면(`O(n log n)`), 재귀는 `T(n) = 2T(n/2) + O(n)`. 띠 검사가 `O(n)`(각 점 상수 개
비교)이라 병합이 선형. [마스터 정리](#/paradigm/divide-and-conquer)로 `T(n) = O(n log n)`.

y 정렬을 순진하게 매 재귀에서 하면 `O(n log² n)` 이 되므로, **y 정렬 결과를 병합해 올리면**(병합 정렬처럼)
`O(n log n)` 을 지킨다.

### 하한

비교 기반 모델에서 최근접 점 쌍은 `Ω(n log n)`(원소 유일성 문제로 환원). 따라서 이 알고리즘이 최적.

## 구현 노트

**제곱 거리** — 비교엔 `dist²` 로 충분. 정수 좌표면 정수 연산(오버플로는 `long long`).

**띠 폭** — 분할선 좌우 `√d`. 제곱 비교라면 `(x − midX)² < d²`(여기 `d` 는 제곱 거리).

**y 정렬 유지** — 재귀 반환 시 y 정렬된 리스트를 병합해 올리면 로그 인자를 아낀다.

**공선·중복점** — 같은 좌표면 거리 0. 중복 제거하거나 그대로 두되 0을 답으로.

**경계** — 점 0/1개(답 없음), 모든 점 동일(거리 0)을 따로 처리.

## 변형과 확장

### 스위프라인 + 정렬 집합

점을 x 로 훑으며 현재 최소 거리 `d` 안의 점만 균형 이진 탐색 트리(y 정렬)에 유지해 `O(n log n)`.
분할 정복 대신 증분 스위프로 같은 복잡도.

### 격자 해싱 (기대 선형)

칸 크기 `d` 인 격자에 점을 해싱하면, 각 점은 인접 9칸만 확인 → 기대 `O(n)`(무작위 순서, 최소 거리 갱신 시
격자 재구성). 실전에서 빠르다.

### k-최근접·모든 이웃

최근접 쌍을 일반화해 각 점의 최근접 이웃(all-nearest-neighbors)이나 k개를 구한다(보로노이·k-d 트리).

### 3차원 이상

분할 평면 + 얇은 판(slab) 검사로 확장. 차원이 오르면 "상자 안 상수 개" 상수가 커진다.
