## 한눈에

용량이 있는 방향 그래프에서 **소스 S → 싱크 T** 로 보낼 수 있는 최대 유량을 구한다.
**잔여 그래프**에서 증가 경로를 찾아 병목만큼 흘리기를 반복(포드-풀커슨), 경로를 **BFS** 로 찾으면
에드몬드-카프로 `O(VE²)`. 끝나면 소스 도달 집합이 **최소 컷** — **최대 유량 = 최소 컷**.

- **시간** `O(VE²)`(에드몬드-카프) · **공간** `O(V²)`(인접 행렬 잔여) 또는 `O(V+E)`(리스트)
- 핵심은 **역방향 잔여 간선** — 흘린 유량을 되돌릴 여지가 최적성을 만든다
- **최대 유량 = 최소 컷**(강한 쌍대성). 최소 컷 = 네트워크를 가르는 가장 싼 절단
- 정수 용량이면 정수 최대 유량이 존재(정수성 정리)

**언제 쓰나** — 이분 매칭(최대 매칭), 정점/간선 서로소 경로 수, 프로젝트 선택·이미지 분할(최소 컷),
스케줄링·할당 문제. "얼마나 보낼 수 있나 / 어디를 끊어야 막나" 로 환원되는 문제들.

**언제 안 쓰나** — 비용까지 최소화해야 하면 **최소 비용 최대 유량**(다른 알고리즘). 아주 큰 그래프는
디닉·푸시-리라벨이 더 빠르다.

## 동작 원리

```
maxflow(s, t):
  flow = 0
  반복:
    잔여 그래프에서 s→t 경로를 BFS 로 찾는다
    없으면 종료
    병목 = 경로의 최소 잔여
    경로를 따라 정방향 −병목, 역방향 +병목
    flow += 병목
  return flow
```

### 잔여 그래프와 역간선

간선 `u→v`(용량 `c`, 유량 `f`)의 잔여는 정방향 `c−f`, 역방향 `f`. 역방향 잔여가 있어야
"이미 흘린 유량을 다른 경로로 재배치" 할 수 있다. 이 되돌림 여지가 **국소적 그리디를 전역 최적**으로 만든다.

### 최소 컷

`s`–`t` 컷 `(A, B)`(`s∈A, t∈B`)의 용량은 `A→B` 간선 용량의 합. 알고리즘 종료 시
`A` = 잔여 그래프에서 `s` 가 닿는 집합으로 잡으면, `A→B` 간선은 모두 **포화**(잔여 0)이고
`B→A` 간선의 유량은 0 → 그 컷 용량이 현재 유량과 같다.

## 정확성

> **최대 유량–최소 컷 정리.** 임의의 흐름 네트워크에서 최대 유량의 값 = 최소 컷의 용량.

세 명제가 동치임을 보이면 된다.

1. `f` 가 최대 유량이다.
2. 잔여 그래프에 증가 경로가 없다.
3. 어떤 컷 `(A,B)` 의 용량이 `|f|` 와 같다.

**(1⟹2)** 증가 경로가 있으면 병목만큼 더 흘려 `f` 를 키울 수 있어 최대가 아니다(대우).

**(2⟹3)** 증가 경로가 없으면, `A =` 잔여에서 `s` 가 닿는 집합으로 두자. `t ∉ A`(못 닿음).
`A→B` 간선은 잔여 0 = **포화**(`f=c`), `B→A` 간선은 유량 0(있으면 역잔여로 `A` 가 더 커짐). 그러면
`|f| = (A→B 유량) − (B→A 유량) = Σcap(A→B) − 0 = cap(A,B)`.

**(3⟹1)** 임의의 흐름 `|f| ≤` 임의의 컷 용량(약한 쌍대성: 유량은 반드시 컷을 건너야 하므로).
어떤 컷이 `|f|` 와 같으면 그 `f` 는 최대이고 그 컷은 최소다. ∎

> **정수성 정리.** 용량이 모두 정수면, 최대 유량과 각 간선 유량이 정수인 해가 존재한다.

증가 경로마다 병목(정수)만큼 정수로 흘리므로 유량이 정수로 유지된다. (이분 매칭의 0/1 유량이 이 덕분.)

## 복잡도

| 방법 | 증가 경로 선택 | 시간 |
|---|---|---|
| 포드-풀커슨(일반) | 임의 | 정수면 `O(E·|f|)`, 무리수면 종료 안 될 수도 |
| **에드몬드-카프** | **BFS(최단)** | `O(V·E²)` |
| 디닉 | 레벨 그래프 + blocking flow | `O(V²·E)`(단위 용량 `O(E√V)`) |

### 왜 에드몬드-카프가 `O(VE²)` 인가

BFS 로 최단 증가 경로를 쓰면, 각 정점까지의 **최단 거리(간선 수)가 단조 비감소**한다.
한 간선이 병목이 되어 포화·재등장하는 사이 소스로부터의 거리가 최소 2 늘어난다는 보조정리에서,
각 간선이 병목이 되는 횟수 `O(V)` → 총 증가 경로 수 `O(VE)`. 경로당 BFS `O(E)` → `O(VE²)`. ∎

순수 포드-풀커슨은 나쁜 경로 선택으로 용량에 비례해 느려질 수 있다(무리수 용량이면 수렴 실패도).
BFS 라는 규칙 하나가 이 병을 없앤다.

## 구현 노트

**역방향 잔여** — `cap[v][u] += bott` 를 반드시. 없으면 재배치 불가로 최적을 놓친다.

**자료구조** — 조밀 그래프는 인접 행렬 `cap[V][V]`(여기 구현), 희소 그래프는 간선 리스트 +
`to/cap/rev` 인덱스로 `O(E)` 공간.

**반평행 간선** — `u→v` 와 `v→u` 가 함께 있으면 각 방향을 **별도 간선**으로 두고 각자의 역간선을 관리한다
(행렬로 합치면 유량 매핑이 꼬인다). 예시 그래프는 이를 피했다.

**최소 컷 복원** — 종료 후 잔여 그래프에서 `s` BFS → 도달 집합 `A`. `A→B` 간선이 컷.

**비용까지** — 최소 비용 최대 유량은 BFS 대신 **최단(비용) 경로**(벨만-포드/SPFA/존슨)로 증가.

## 변형과 확장

### 이분 매칭 = 단위 용량 최대 유량

이분 그래프의 최대 매칭은, 소스→왼쪽(용량1), 왼쪽→오른쪽(1), 오른쪽→싱크(1) 네트워크의 최대 유량과 같다.
정수성 정리로 유량이 0/1 이라 매칭이 된다. 홉크로프트-카프는 이를 `O(E√V)` 에.

### 최소 컷 응용 — 프로젝트 선택·이미지 분할

"이득을 최대화하며 서로 의존하는 항목 고르기(project selection)", "전경/배경 분할(image segmentation)"
같은 문제가 최소 컷으로 정확히 모델링된다. 최대 유량을 풀면 최적 분할이 나온다.

### 서로소 경로 (메뉴거 정리)

`s`–`t` 간선 서로소 경로의 최대 수 = 최소 `s`–`t` 간선 컷(모든 용량 1). 정점 서로소는 정점 분할로.
메뉴거 정리가 최대 유량–최소 컷의 조합론적 형태다.

### 디닉·푸시-리라벨

레벨 그래프 + blocking flow(디닉, `O(V²E)`), 또는 지역적 push/relabel(`O(V²√E)`)이 큰 그래프에서 더 빠르다.
