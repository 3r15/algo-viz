## 한눈에

`n`개 원소의 **모든 부분집합**을 정수 마스크 `0 … 2ⁿ−1` 로 훑는다. 마스크의 `j`번 비트가 부분집합에
`aⱼ` 가 있는지를 나타낸다. 부분집합 DP·조합 생성·완전 탐색의 공통 뼈대이며, 비트 연산으로 집합을
`O(1)` 에 다룬다.

- **시간** `Θ(n·2ⁿ)`(각 마스크마다 비트 훑기) · **공간** `O(1)`
- 부분집합 ↔ 정수: **비트 = 원소 포함 여부**. `mask & (1<<j)` 로 검사
- 집합 연산이 비트 연산: 합집합 `|`, 교집합 `&`, 차집합 `& ~`, 대칭차 `^`
- `n ≲ 20` 에서 현실적(`2²⁰ ≈ 10⁶`). 더 크면 DP·가지치기·수학

**언제 쓰나** — 작은 `n`(≤ 20)의 완전 탐색, 부분집합 DP(외판원 Held-Karp, 집합 덮개),
상태를 비트로 압축(방문 집합·켜짐 여부), 조합 생성.

**언제 안 쓰나** — `n` 이 크면 `2ⁿ` 폭발. 구조가 있으면 그리디·DP·수학으로 지수를 피한다.

## 동작 원리

```
for mask in 0 .. 2^n - 1:          # 각 정수 = 한 부분집합
    for j in 0 .. n-1:
        if mask & (1 << j):        # j번 비트가 1이면
            a[j] 를 이 부분집합에 포함
    # mask 가 하나의 부분집합 — 합·크기·XOR 등으로 답 갱신
```

### 부분집합 ↔ 정수 전단사

`n`비트 정수는 `2ⁿ`개, 부분집합도 `2ⁿ`개. `mask` 의 비트 패턴 ↔ 원소 포함 여부가 **일대일 대응**이다.
그래서 `0`부터 세는 것만으로 **빠짐도 중복도 없이** 전부 열거된다.

### 핵심 비트 트릭

```
1 << j            j번 자리만 1
mask & (1<<j)     j번 비트가 켜졌는지
mask | (1<<j)     j번 원소 추가       mask & ~(1<<j)  제거
mask & -mask      최하위 1비트(lowbit) 추출
mask & (mask-1)   최하위 1비트 제거
__builtin_popcount(mask)  켜진 비트 수(부분집합 크기)
```

## 정확성

> **열거 완전성·무중복.** `mask` 를 `0 … 2ⁿ−1` 로 돌리면, `{0,…,n−1}` 의 모든 부분집합이 **정확히 한 번씩**
> 생성된다.

*증명.* 함수 `f(mask) = { j : mask 의 j번 비트가 1 }` 은 `{0,…,2ⁿ−1}` 에서 `{0,…,n−1}` 의 멱집합으로 가는
**전단사**다. 각 부분집합 `S` 는 유일한 마스크 `Σ_{j∈S} 2ʲ` 에 대응하고, 서로 다른 마스크는 서로 다른
비트 패턴이라 서로 다른 부분집합을 준다. 정의역을 모두 훑으므로 치역(멱집합)도 모두, 한 번씩 나온다. ∎

> **집계 정확성.** 각 마스크에서 `mask & (1<<j)` 로 원소를 정확히 골라 집계하므로, "모든 부분집합에 대한
> 최대/개수/존재" 질의가 옳다.

완전 탐색이므로 후보를 하나도 놓치지 않는다 — 정확성은 자명하고, 비용이 문제일 뿐이다.

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 부분집합 열거 | `Θ(n·2ⁿ)` | `O(1)` |
| (마스크당 O(1) 집계로 줄이면) | `Θ(2ⁿ)` | `O(1)` |

### `2ⁿ` 의 벽

`n` 이 하나 늘면 시간이 **두 배**. `n=20`≈10⁶, `n=30`≈10⁹, `n=40`≈10¹². 그래서 비트마스크 완전 탐색은
`n ≲ 20`(집계까지 하면 `≲ 25`)에서만 현실적. 이 벽을 넘으려면 **부분집합 DP** 로 지수의 밑을 낮추거나
(외판원 `O(2ⁿ·n²)` 는 여전히 지수지만 `n!` 보다 훨씬 낫다), 구조를 이용한다.

### 부분집합의 부분집합 순회

`mask` 의 모든 **부분마스크**를 도는 `for (sub = mask; sub; sub = (sub-1) & mask)` 는 전체가
`Σ_mask 2^popcount(mask) = 3ⁿ`. 집합 덮개·분할 DP 에서 쓰인다.

## 구현 노트

**오버플로** — `n ≥ 31` 이면 `1 << j` 대신 `1LL << j`(64비트). 마스크 자체도 `long long`.

**비트 검사 두 형태** — `mask & (1<<j)` 와 `(mask >> j) & 1` 은 동치. 후자는 0/1 값을 바로 준다.

**popcount·lowbit** — 컴파일러 내장(`__builtin_popcount`, `__builtin_ctz`)이 빠르다. [펜윅 트리](#/algo/fenwick-tree)의
`i & -i` 도 같은 lowbit 트릭.

**공집합/전체집합** — `mask=0`, `mask=2ⁿ−1` 도 유효. 범위 `0 … 2ⁿ−1` 이 포함한다.

**상태 압축** — "방문한 정점 집합", "켜진 스위치" 같은 상태를 정수 하나로 담아 DP 키·해시로 쓴다.

## 변형과 확장

### 부분집합 DP — 외판원(Held-Karp)

`dp[mask][v]` = "방문 집합이 mask 이고 지금 v 에 있을 때 최소 경로". 상태 `2ⁿ·n`, 전이 `n` → `O(2ⁿ·n²)`.
순열 `n!` 완전 탐색을 지수로 끌어내린 대표 사례.

### 집합 덮개·분할

원소를 덮는 부분집합들의 최소 개수(집합 덮개), 집합을 조각으로 나누는 최적 분할 등을 부분마스크
순회(`3ⁿ`)로 푼다.

### 그레이 코드

연속한 두 수가 **한 비트만** 다른 순서 `g(i) = i ^ (i>>1)`. 부분집합을 원소 하나씩만 바꾸며 열거해,
증분 계산(추가/제거 한 번)으로 이어 갈 수 있다.

### 비트셋으로 집합 연산 가속

큰 집합 연산(교집합·합집합)을 워드 단위로 묶어 `O(n/64)` 에. DP·그래프의 인접 집합 연산을 상수배 빠르게.
