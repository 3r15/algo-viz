## 한눈에

손에 든 카드를 정렬하는 방식 그대로다. 왼쪽은 이미 정렬돼 있다고 보고, 새 원소를 **왼쪽으로
밀어 넣어** 제자리를 찾는다.

O(n²) 정렬이지만 **거의 정렬된 입력에서는 사실상 선형**이라, 실제 표준 라이브러리 정렬들이
작은 구간의 마무리 단계에 이 알고리즘을 쓴다.

- 비교 기반 · 제자리(in-place) · 안정(stable) · **온라인(online)**
- 정렬 확정 구간이 **앞에서 뒤로** 자란다 (버블 정렬과 반대 방향)

## 동작 원리

`i = 1`부터 시작해 `a[i]`를 왼쪽 정렬 구간 `a[0 .. i-1]` 의 알맞은 자리에 끼워 넣는다.
끼워 넣기는 "왼쪽 이웃이 나보다 크면 자리를 바꾼다"를 더 이상 못 바꿀 때까지 반복하는 것이다.

```
[5 | 2 9 1 5 6]   2를 삽입 → [2 5 | 9 1 5 6]
[2 5 | 9 1 5 6]   9는 제자리 → [2 5 9 | 1 5 6]
[2 5 9 | 1 5 6]   1을 삽입 → [1 2 5 9 | 5 6]
```

`|` 왼쪽이 정렬된 구간이다. 매 단계 구간이 하나씩 늘어난다.

**온라인**이라는 말은 원소가 하나씩 도착하는 상황에서도 그대로 쓸 수 있다는 뜻이다.
지금까지 받은 것만으로 항상 정렬된 상태를 유지한다. 병합 정렬이나 퀵 정렬은 이게 안 된다.

## 정확성

### 내부 while 루프 불변식

> `a[j+1 .. i]` 는 정렬돼 있고, 이 구간의 모든 원소는 `a[j]` 이상이다.

루프 조건 `a[j-1] > a[j]` 가 참이면 두 원소를 교환하고 `j`를 하나 줄인다. 교환 직후
`a[j-1] < a[j]` 가 되므로 정렬된 구간이 하나 늘어난 채 불변식이 유지된다.

### 외부 for 루프 불변식

> `Q(i)`: `i`번째 반복을 **시작할 때** `a[0 .. i-1]` 은 정렬돼 있다.

`Q(1)`은 원소 하나짜리 구간이라 자명하다. `Q(i)`를 가정하자. while 루프는 두 가지 방식으로 끝난다.

1. `j == 0` 에 도달 — 삽입할 값이 구간 전체보다 작아 맨 앞에 놓였다.
2. `a[j-1] <= a[j]` — 왼쪽 이웃이 자기보다 작거나 같다. 여기가 제자리다.

두 경우 모두 `a[j-1] <= a[j]` 이고, 내부 불변식에 의해 `a[j] <= a[j+1] <= ... <= a[i]` 이며,
`Q(i)`에 의해 `a[0..j-1]` 도 정렬돼 있다. 따라서 `a[0 .. i]` 전체가 정렬된다. 즉 `Q(i+1)`이 성립한다.

`i = n`에서 `Q(n)` 은 곧 배열 전체가 정렬됐다는 뜻이다. ∎

### 종료성과 안정성

내부 루프에서 `j`는 매 반복 1씩 감소하고 `j > 0` 이 조건이므로 최대 `i`번 만에 끝난다.

비교가 `a[j-1] > a[j]` 이므로 **같은 값을 만나면 즉시 멈춘다.** 뒤에서 온 원소가 같은 값의
앞으로 넘어가지 않으므로 **안정(stable)** 하다.

## 복잡도

| | 비교 · 이동 횟수 | 시간 |
|---|---|---|
| 최선(이미 정렬) | n-1 비교, 0 이동 | **O(n)** |
| 평균 | ≈ n²/4 | O(n²) |
| 최악(역순) | n(n-1)/2 | O(n²) |

최선의 경우 매 `i`마다 while 조건이 첫 비교에서 거짓이 되어 바로 빠져나온다. 총 비교 `n-1`번.

버블 정렬과 마찬가지로 **인접 교환 한 번이 역전(inversion) 하나를 없앤다.** 그러므로

> 교환 횟수 = 입력의 역전 수 `I`,  전체 시간 = **Θ(n + I)**

이 식이 삽입 정렬의 정체를 가장 정확히 설명한다. `I = 0`이면 O(n), `I = Θ(n²)`이면 O(n²)이고,
"각 원소가 제자리에서 최대 k칸 떨어져 있는" 배열은 `I ≤ nk` 이므로 **O(nk)** 에 정렬된다.

공간은 O(1).

## 구현 노트

이 페이지의 코드는 이해하기 쉽도록 `swap` 을 반복하지만, 실전에서는 **한 칸씩 밀고(shift)
마지막에 한 번만 대입**하는 편이 상수가 3배쯤 빠르다. `swap` 은 대입 3번이기 때문이다.

```cpp
for (int i = 1; i < n; i++) {
    int key = a[i], j = i - 1;
    while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; }   // 밀기
    a[j + 1] = key;                                          // 한 번만 대입
}
```

**이진 삽입 정렬**은 삽입 위치를 이분 탐색으로 찾아 비교 횟수를 `O(n log n)`으로 줄인다.
하지만 원소를 밀어내는 **이동 비용은 그대로 O(n²)** 라 전체 시간은 개선되지 않는다.
비교가 아주 비쌀 때(문자열 비교 등)만 의미가 있다.

## 변형과 확장

- **셸 정렬(Shell sort)**: 간격 `h`씩 떨어진 원소끼리 삽입 정렬을 하고 `h`를 줄여 간다.
  멀리 떨어진 역전을 한 번에 없애 O(n^1.3) 수준까지 내려간다. 삽입 정렬의 직계 개선판이다.
- **하이브리드 정렬**: libstdc++ 의 `std::sort`(introsort)는 구간 길이가 16 이하가 되면
  재귀를 멈추고 삽입 정렬로 마무리한다. 작은 배열에서는 O(n²)의 상수가 O(n log n)보다 작기 때문이다.
