## 어떤 문제인가

정수 배열에서 **연속한** 부분 배열의 합 중 **최댓값**을 찾는다. 음수가 섞여 있어 "전부 더하기" 는 답이 아니다.

```
a = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
             └───────────┘
             [4, -1, 2, 1] 의 합 = 6  ← 최대
```

모든 시작·끝 쌍을 다 보면 `O(n²)`(또는 `O(n³)`). 한 번 훑기로 `O(n)` 에 할 수 없을까?

## 손으로 해보기

핵심 아이디어: **각 위치에서 "여기서 끝나는 최대 합"** `cur` 을 이어 간다.

> 새 원소 `a[i]` 를 만나면 두 선택뿐이다:
> ① 지금까지의 구간에 **이어 붙인다**(`cur + a[i]`), ② 여기서 **새로 시작한다**(`a[i]`).
> 둘 중 큰 쪽. 그리고 그때그때 `best` 를 갱신한다.

### 왜 "새로 시작" 하나

`cur` 이 **음수**면, 그건 뒤에 붙일수록 손해다. 그러니 미련 없이 버리고 `a[i]` 부터 새로 센다.
`cur + a[i] < a[i]` ⟺ `cur < 0` — 이때가 재시작 신호다.

### 훑어 보기

```
i        0    1    2    3    4    5    6    7    8
a[i]    -2    1   -3    4   -1    2    1   -5    4
cur     -2    1   -2    4    3    5    6    1    5
best    -2    1    1    4    4    5    6    6    6
```

- `i=1`: cur=-2<0 → 버리고 새로 시작 → cur=1
- `i=2`: cur+(-3)=-2 vs -3 → 이어 붙임 cur=-2
- `i=3`: cur=-2<0 → 새로 시작 → cur=4 (여기서부터 최대 구간이 시작!)
- `i=4..6`: -1,2,1 을 이어 붙여 cur=3→5→6, best=6
- `i=7`: cur+(-5)=1 → 이어 붙임 cur=1 (아직 양수라 유지)

**최대 부분합 = 6** (구간 `[3..6] = 4,-1,2,1`).

### 비용

```
배열을 딱 한 번 훑는다 → O(n)
추가 메모리 cur, best 둘뿐 → O(1)
```

## 아이디어 쌓기

### 1단계 — "여기서 끝나는 최대 합"

각 위치 `i` 에서, `i` 로 끝나는 부분 배열의 최대 합을 `cur` 로 잇는다.

### 2단계 — 잇기 vs 새로 시작

`cur = max(a[i], cur + a[i])`. 앞이 손해(cur<0)면 버린다.

### 3단계 — 전체 최대 갱신

`best = max(best, cur)`. cur 은 "끝나는" 최대, best 는 "지금까지" 최대.

### 4단계 — 한 번 훑기

두 값만 들고 왼→오로 한 번. `O(n)`, `O(1)`.

## 코드로 옮기기

```cpp
int kadane(vector<int>& a) {
    int cur = a[0], best = a[0];
    for (int i = 1; i < a.size(); i++) {
        cur = max(a[i], cur + a[i]);    // 잇거나, 여기서 새로 시작
        best = max(best, cur);          // 지금까지 최대
    }
    return best;
}
```

`cur` 과 `best` 를 헷갈리지 말자 — `cur` 은 **여기서 끝나는** 최대, `best` 는 **전체** 최대.

## 자주 하는 실수

**best 를 0 으로 초기화한다.** 모두 음수인 배열(`[-3,-1,-2]`)이면 답은 `-1`(가장 큰 원소)인데,
best=0 으로 두면 0을 답으로 낸다(빈 구간 허용 시에만 0). **best = a[0]** 로 시작.

**cur 과 best 를 같은 것으로 본다.** cur 은 계속 이어지는 값, best 는 그중 최댓값. 분리해야 한다.

**빈 구간 허용 여부.** "빈 부분 배열(합 0) 허용" 이면 best 를 0 과도 비교. 문제 정의를 확인.

**구간 위치가 필요하면 추적을 빼먹는다.** 합만이 아니라 구간 `[l,r]` 도 원하면 재시작·갱신 때 인덱스를 기록.

## 스스로 확인하기

1. **cur 이 음수가 될 때 새로 시작**(빨강)하는 것을 보자 — i=1, i=3.
2. **i=3 에서 최대 구간이 시작**해 4,-1,2,1 로 이어지는 것을 보자.
3. **best 가 6 에서 멈추는 것**을 보자(뒤의 -5,4 로는 안 넘음).
4. **최종 초록 구간 [3..6]** 을 확인하자.
5. 입력을 `-3 -1 -2` 로 바꿔 보자 — 전부 음수면 답은 가장 큰 -1.
6. 입력을 `1 2 3 4` 로 바꿔 보자 — 전부 양수면 전체 합 10.
