## 한눈에

연속 부분 배열의 **최대 합**을 `O(n)`, `O(1)` 에 구한다(카데인). "위치 `i` 에서 끝나는 최대 합" `cur` 을
이어 가되, 앞 구간이 손해(`cur < 0`)면 버리고 새로 시작한다. 가장 단순한 **1D 동적 계획법**.

- **시간** `Θ(n)` · **공간** `O(1)` · 한 번 훑기
- `cur = max(a[i], cur + a[i])` · `best = max(best, cur)`
- **best = a[0]** 로 초기화(모두 음수인 경우까지 옳게) — 0으로 두면 틀림
- 구간 위치, 최대 곱, 원형 배열 등으로 자연스럽게 확장

**언제 쓰나** — 최대 합 구간, 주가 매매(최대 이익 구간), 신호에서 최대 강도 구간, 2D 최대 부분행렬의 부품.

**언제 안 쓰나** — 최댓값이 아닌 다른 집계(개수·특정 길이 제약)나, 불연속 부분수열(다른 문제).

## 동작 원리

```
cur = a[0], best = a[0]
for i in 1..n-1:
    cur = max(a[i], cur + a[i])   # 잇거나, 여기서 새로 시작
    best = max(best, cur)
return best
```

### DP 점화식

`dp[i]` = "인덱스 `i` 에서 **끝나는** 최대 부분합". 그러면

```
dp[i] = max(a[i], dp[i-1] + a[i])
답  = max_i dp[i]
```

`dp[i-1] < 0` 이면 이어 붙이는 게 손해라 `a[i]` 부터 새로. `dp` 는 직전 값만 필요해 변수 하나(`cur`)로 압축.

## 정확성

> **정리.** `best` 는 배열의 최대 연속 부분합과 같다.

*불변식.* 루프가 `i` 를 처리한 뒤 `cur = dp[i]`(= `i` 로 끝나는 최대 부분합), `best = max_{k≤i} dp[k]`.

*유지.* `dp[i] = max(a[i], dp[i-1] + a[i])`: `i` 로 끝나는 부분합은 "`a[i]` 하나" 이거나 "`i-1` 로 끝나는
부분합 + `a[i]`" 뿐이고, 후자의 최댓값이 `dp[i-1]`. 둘 중 큰 쪽이 `dp[i]`. `best` 는 그때까지의 최댓값
유지. 모든 부분합은 어떤 `i` 로 끝나므로, 최종 `best = max_i dp[i]` = 전체 최대. ∎

### best=0 이 틀리는 이유

빈 부분 배열을 허용하지 않으면 답은 항상 어떤 실제 구간의 합이다. 모두 음수면 그 최댓값(가장 큰 원소)이
답인데, `best=0` 은 존재하지 않는 빈 구간(합 0)을 답으로 낸다. `best=a[0]` 초기화가 이를 막는다.

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 카데인 | `Θ(n)` | `O(1)` |

한 번 훑기, 상수 메모리. 분할 정복 대안은 `O(n log n)` 이라 카데인이 더 빠르다.

## 구현 노트

**초기화** — `cur = best = a[0]`, 루프는 `i=1` 부터. 빈 배열은 별도 처리.

**빈 구간 허용** — 허용하면 `best` 를 0과도 비교(또는 `cur = max(0, cur + a[i])`). 문제 정의에 맞춰.

**구간 추적** — 재시작 시 `curStart = i`, `cur > best` 갱신 시 `bestL=curStart, bestR=i` 를 기록하면 실제 구간을 얻는다.

**오버플로** — 합이 커지면 64비트.

## 변형과 확장

### 최대 곱 부분배열

곱은 음수×음수가 양수가 되므로 **최솟값도 함께** 추적한다(`curMax`, `curMin` 을 함께 갱신).

### 원형 배열의 최대 부분합

원형이면 답 = max(일반 카데인, 전체합 − **최소** 부분합). 단, 전부 음수인 경우 예외 처리.

### 2D 최대 부분행렬

두 행 경계를 고정하고 열을 압축한 1D 배열에 카데인 → `O(rows² · cols)`.

### 분할 정복

`[좌 최대, 우 최대, 경계 넘는 최대]` 중 최댓값. `T(n)=2T(n/2)+O(n)=O(n log n)`. 교육용으론
분할 정복, 실전은 카데인.
