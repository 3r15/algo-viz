## 한눈에

시작 정점에서 **가까운 순서대로** 정점을 방문한다. 거리 0인 정점, 거리 1인 정점들,
거리 2인 정점들… 이렇게 층(layer) 단위로 물결처럼 퍼져 나간다.

이 "층별로 퍼진다"는 성질 덕분에 BFS는 **간선 가중치가 모두 같은 그래프에서 최단 경로**를 준다.

- 자료구조는 **큐(FIFO)** — 먼저 발견한 정점을 먼저 처리한다
- 시간 O(V+E) · 공간 O(V)

## 동작 원리

```
q.push(s);  visited[s] = true
while q 가 비어 있지 않은 동안:
    u = q.front();  q.pop()
    u 를 처리한다
    for v in adj[u]:
        if !visited[v]:
            visited[v] = true       // ★ 꺼낼 때가 아니라 넣을 때 표시
            q.push(v)
```

시각화에서 정점 색이 네 단계로 바뀐다.

| 상태 | 의미 |
|---|---|
| 미방문 | 아직 발견되지 않음 |
| 큐 대기 | 발견되어 큐에 들어감 (`visited = true`) |
| 방문 중 | 큐에서 꺼내 이웃을 훑는 중 |
| 완료 | 이웃을 모두 확인함 |

### `visited` 를 넣을 때 표시하는 이유

`q.push(v)` 하는 시점이 아니라 `q.pop()` 하는 시점에 `visited` 를 표시하면,
같은 정점이 여러 이웃에게서 발견되어 **큐에 중복으로 들어간다**. 큐 크기가 O(E)까지
부풀고, 정점을 여러 번 처리하게 된다. 넣을 때 표시하면 각 정점은 **정확히 한 번** 큐에 들어간다.

## 정확성

`dist[v]` 를 "s에서 v까지 간선 수 기준 최단 거리"라고 하자. BFS가 `v`를 큐에 넣는 시점의
층 번호를 `d[v]` 라 하면, 다음이 성립한다.

### 큐 단조성 보조정리

> BFS 실행 중 어느 시점에나, 큐 안의 정점들의 `d` 값은 **비내림차순**이고
> 최댓값과 최솟값의 차이는 **최대 1**이다.

귀납으로 보인다. 처음엔 `[s]` 하나뿐이라 자명하다. `d`값이 `k`인 정점 `u`를 꺼내면
큐에는 `k` 또는 `k+1` 만 남아 있고, `u`의 이웃 중 새로 발견한 것들은 `d = k+1` 로 뒤에 붙는다.
따라서 큐는 여전히 비내림차순이고 폭은 1 이하다. ∎

### `d[v] = dist[v]`

**(≥)** `d[v]` 는 실제로 s에서 v로 가는 길이 `d[v]`짜리 경로에 대응하므로 `d[v] ≥ dist[v]`.

**(≤)** `dist[v]` 에 대한 귀납. `dist[v] = k` 인 정점 `v`를 보자. 최단 경로상 `v` 바로 앞
정점 `u`는 `dist[u] = k-1` 이고, 귀납 가정에 의해 `d[u] = k-1` 이다. `u`가 큐에서 꺼내질 때
`v`는 이미 발견됐거나, 그때 발견된다. 큐 단조성에 의해 그 시점까지 발견된 정점의 `d`값은
`k` 이하이므로 `d[v] ≤ k` 이다.

두 부등식을 합치면 `d[v] = dist[v]`. **BFS가 정점을 꺼내는 순서는 최단 거리 순서다.** ∎

### 도달성

`visited[v] = true` 가 되는 정점은 정확히 `s`에서 도달 가능한 정점 전체다.
(도달 가능하면 위 귀납으로 발견되고, 발견됐다면 발견 경로가 곧 s→v 경로다.)

## 복잡도

| | |
|---|---|
| 시간 | **O(V + E)** |
| 공간 | O(V) — `visited` 배열 + 큐 |

- 각 정점은 큐에 정확히 한 번 들어가고 한 번 나온다 → **O(V)**
- 각 정점을 꺼낼 때 그 인접 리스트를 한 번씩 훑는다. 인접 리스트 길이의 총합은
  방향 그래프에서 `E`, 무방향 그래프에서 `2E` → **O(E)**

인접 **행렬**로 구현하면 정점마다 `V`개를 훑으므로 **O(V²)** 가 된다. 간선이 적은
희소 그래프에서는 인접 리스트가 압도적으로 유리하다. 시각화의 그래프 편집기에서
두 표현을 나란히 볼 수 있다.

큐 최대 크기는 가장 큰 층의 크기이고, 최악에는 O(V)다.

## 구현 노트

**최단 경로 복원**: `visited` 대신 `prev[v] = u` 를 기록해 두면, 도착점에서 `prev` 를 거슬러
올라가 경로를 얻는다. 거리만 필요하면 `dist[v] = dist[u] + 1` 을 쓰고 `dist[v] == -1` 을
미방문 표시로 겸하면 배열 하나로 끝난다.

```cpp
vector<int> dist(n, -1);
dist[s] = 0;  q.push(s);
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : adj[u])
        if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); }
}
```

**다중 시작점(multi-source BFS)**: 시작 정점 여러 개를 처음부터 큐에 모두 넣고 거리 0으로
표시하면, 각 정점까지의 "가장 가까운 시작점으로부터의 거리"를 한 번에 얻는다.
격자에서 "가장 가까운 물까지의 거리" 같은 문제가 이 형태다.

**격자 그래프**: 인접 리스트를 만들지 않고 `dx[] = {0,0,1,-1}, dy[] = {1,-1,0,0}` 으로
이웃을 즉석에서 계산하는 것이 보통이다.

## 변형과 확장

- **0-1 BFS**: 간선 가중치가 0 또는 1뿐이면, 큐 대신 **덱(deque)** 을 써서 가중치 0인 간선은
  앞에, 1인 간선은 뒤에 넣는다. 여전히 O(V+E)로 최단 경로를 얻는다.
- **다익스트라**: 가중치가 일반 양수면 큐를 **우선순위 큐**로 바꾼다. BFS의 자연스러운 일반화다.
- **양방향 BFS**: 시작점과 도착점에서 동시에 퍼뜨려 중간에서 만난다. 탐색 공간이
  `b^d` 에서 `2·b^(d/2)` 로 줄어든다.
- **이분 그래프 판정**: 층 번호의 홀짝으로 2색 칠하기를 시도하면 O(V+E)에 판정된다.
