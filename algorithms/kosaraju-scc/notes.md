## 한눈에

방향 그래프의 **강한 연결 요소(SCC)** — 서로 오갈 수 있는 최대 정점 집합 — 를 **두 번의 DFS** 로 찾는다.
① 원래 그래프를 DFS 해 **완료 순서**를 스택에 쌓고, ② **전치 그래프**(간선 뒤집기)를 그 역순으로 DFS 한다.

- **시간** `Θ(V + E)` — DFS 두 번 + 전치 구성 · **공간** `Θ(V + E)`(전치 그래프·스택)
- [타잔](#/algo/tarjan-scc)과 **같은 문제**를 다르게 — 타잔은 DFS 한 번(low-link), 코사라주는 DFS 두 번
- 아이디어가 **직관적**이다: "완료 역순 + 전치" 의 조합이 SCC 를 하나씩 잘라낸다
- SCC 를 한 점으로 축약하면 **DAG**(축약 그래프)가 된다

**언제 쓰나** — SCC 분해, 2-SAT(함의 그래프의 SCC), 축약 DAG 위의 DP, 웹/의존성 그래프의 순환 덩어리 분석.
전치 그래프가 자연스럽거나 개념 설명이 목적일 때 특히 좋다.

**언제 안 쓰나** — 간선을 두 번 훑기 부담(초대형 그래프)이면 [타잔](#/algo/tarjan-scc)·가보우가 한 번 순회로 끝낸다.
무방향 그래프의 연결 요소는 그냥 DFS/[BFS](#/algo/bfs) 한 번(SCC 개념은 방향 그래프 전용).

## 동작 원리

```
① for u in V: if !visited[u]: dfs1(u)     // 완료되면 order.push(u)
② 간선을 뒤집어 radj 를 만든다
③ for u in reverse(order):
       if u 미배정: dfs2(u, 새 SCC 번호)    // 닿는 정점 = SCC 하나
```

### 두 축 — 완료 순서와 전치 그래프

- **완료 순서(post-order)**: `dfs1` 이 `u` 의 모든 자손을 마친 뒤 `u` 를 쌓는다. 완료가 늦은 정점일수록
  축약 DAG 에서 위상적으로 **앞선** SCC 에 있다.
- **전치 그래프 `Gᵀ`**: 모든 간선을 뒤집는다. SCC 는 그대로(대칭 관계라), 하지만 SCC **사이** 의 방향은 반대.

이 둘을 합치면: 완료가 가장 늦은 정점 `r` 은 원 그래프에서 자기 SCC 밖으로 **나가기만** 한다.
`Gᵀ` 에서는 그 방향이 뒤집혀, `r` 에서 시작한 DFS 가 자기 SCC 밖으로 **못 나간다** → 딱 그 덩어리만 닿는다.

### 실행 예

기본 그래프 `0→1→2→0, 2→3, 3→4→3, 4→5`.
① 완료 순서 스택 `[5,4,3,2,1,0]`(위=0). ② 전치에서 `0`→{0,1,2}=C0, `3`→{3,4}=C1, `5`→{5}=C2.

## 정확성

핵심은 두 정점이 같은 SCC ⟺ `dfs2` 의 같은 트리에 들어감을 보이는 것이다.
SCC 들을 축약한 DAG 를 `G↓` 라 하고, 각 SCC 의 **완료 시각** 을 그 안 정점들의 완료 시각 최댓값으로 정의한다.

> **보조정리 (완료 시각과 위상 순서).** 축약 DAG `G↓` 에 간선 `C → C'` (SCC `C` 에서 `C'` 로 가는 간선이
> 원 그래프에 존재)가 있으면, `f(C) > f(C')`. 즉 **완료 시각이 큰 SCC 가 위상적으로 앞선다.**

*증명 스케치.* 원 그래프에서 `C→C'` 만 있고 `C'→C` 는 없다(있으면 한 SCC). DFS 가 `C` 를 `C'` 보다
먼저 건드리면 `C` 에서 `C'` 로 내려가 `C'` 를 다 마치고 올라오므로 `C` 의 어떤 정점이 마지막에 완료 →
`f(C) > f(C')`. `C'` 를 먼저 건드리면 `C'→C` 가 없어 `C` 로 못 올라가고 `C'` 를 다 마친 뒤 나중에 `C` 를
탐색 → 역시 `f(C) > f(C')`. ∎

> **정리.** `②` 에서 완료 역순(즉 `f` 큰 것부터)으로 아직 배정 안 된 정점 `r` 을 골라 `Gᵀ` 에서 DFS 하면,
> 닿는 정점 집합은 정확히 `r` 이 속한 SCC 다.

*증명.* `Gᵀ` 에서 `r` 이 닿는 정점 `v` 를 보자. `Gᵀ` 경로 `r→…→v` 는 원 그래프 경로 `v→…→r` 이다.
`v` 가 아직 배정 안 됐다면 `v` 의 SCC `C_v` 는 이번에 처음 열린 것이고, 보조정리상 이미 배정된 SCC 들은
모두 `f` 가 `r` 의 SCC `C_r` 보다 크다. 원 그래프에 `C_v → C_r` (경로 `v→r`)가 있으므로 `f(C_v) > f(C_r)`.
만약 `C_v ≠ C_r` 이면 `C_v` 는 `f` 가 더 커서 **이미 배정됐어야** 한다(역순 처리) — 모순.
따라서 `C_v = C_r`, 즉 닿는 정점은 전부 `r` 의 SCC. 반대로 같은 SCC 정점은 `Gᵀ` 에서도 서로 닿으므로
모두 방문된다. ∎

**종료성** — DFS 두 번, 각 정점·간선 상수 번. `Θ(V+E)`.

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 코사라주 | `Θ(V + E)` | `Θ(V + E)` |

두 번의 DFS(`Θ(V+E)` 씩)와 전치 그래프 구성(`Θ(V+E)`). 상수 인자는 타잔보다 크다(간선을 두 번,
전치 저장). 점근적으론 동일.

### 타잔·가보우와의 비교

| | 순회 | 추가 자료 | 특징 |
|---|---|---|---|
| **코사라주** | DFS 2회 + 전치 | `order` 스택, `radj` | 가장 이해하기 쉬움 |
| **타잔** | DFS 1회 | `low[]`, `disc[]`, 스택 | 전치 불필요, 한 번에 |
| **가보우** | DFS 1회 | 스택 2개 | low-link 없이 |

세 알고리즘 모두 `Θ(V+E)`. 코사라주는 **개념의 투명함**이, 타잔·가보우는 **단일 순회**가 장점이다.

## 구현 노트

**완료 순서** — `dfs1` 에서 정점을 **자손을 다 마친 뒤**(post-order) 쌓는다. 발견 순서로 쌓으면 틀린다.

**전치 그래프** — `radj[v].push(u)` 를 `adj[u]` 순회로 미리 만들거나, 간선 리스트를 `(v,u)` 로 뒤집는다.

**재귀 깊이** — 깊은 그래프는 스택 오버플로 위험. 큰 입력은 명시적 스택으로 반복 DFS 를 쓴다.

**SCC 번호와 축약 DAG** — `comp[v]` 가 SCC 번호다. `comp[u] ≠ comp[v]` 인 간선 `u→v` 만 모으면
축약 DAG 를 얻는다(중복 제거하면 단순 그래프).

**②의 시작 순서** — `order` 를 **뒤에서부터**(늦게 완료 = 큰 `f`) 꺼내는 게 핵심. 앞에서 꺼내면 SCC 가 샌다.

## 변형과 확장

### 2-SAT — 함의 그래프의 SCC

각 절 `(a ∨ b)` 를 함의 `¬a→b`, `¬b→a` 로 바꾼 그래프에서 SCC 를 구한다.
변수 `x` 와 `¬x` 가 **같은 SCC** 면 모순(해 없음). 아니면 SCC 위상 순서로 값을 정한다.

### 축약 DAG 위의 DP

SCC 로 압축하면 사이클이 사라져 DAG DP 가 가능하다 — 최장 경로, 도달 가능 정점 수 등.
"가장 많은 노드를 방문하는 경로" 류 문제의 표준 전처리.

### 강한 연결성 판정

SCC 가 **하나** 면 그래프 전체가 강하게 연결됨. 코사라주로 `sccCount == 1` 을 확인하면 된다.
