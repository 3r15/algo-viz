## 어떤 문제인가

파이프 망에서 각 파이프에 **용량**뿐 아니라 **단위당 비용**이 있다. 소스 S 에서 싱크 T 로
**최대한 많이** 흘리되, 그 최대 유량을 **가장 싸게** 보내려면?

```
        용량,비용
   S ──(3,1)── 1 ──(2,1)── T
   │           │           │
 (2,3)       (1,1)       (3,2)
   │           │           │
   2 ──────────┘           │
   └────────────(위 2)─────┘
```

[최대 유량](#/algo/max-flow)은 "얼마나" 만 물었다. 여기선 "얼마나" 를 최대로 하면서 "비용" 을 최소로.

## 손으로 해보기

핵심 변화 하나: **증가 경로를 아무거나(BFS) 가 아니라 "가장 싼 경로" 로** 고른다.

> 매번 **최단 비용 경로**를 찾아 병목만큼 흘린다. 그러면 그 유량에서 항상 최소 비용을 유지한다.

### 왜 최단 비용 경로인가

싼 경로부터 채우면, 각 단계가 "이 유량까지는 최소 비용" 을 보장한다(그리디처럼 보이지만
역간선 덕에 재배치가 가능해 진짜 최적이 된다).

### 역간선의 비용은 음수

[최대 유량](#/algo/max-flow)처럼, 간선 `u→v` 에 `f` 를 흘리면 역방향 잔여 `v→u` 를 만든다.
그 역간선의 비용은 **−(원래 비용)** 이다("되돌리면 비용을 환불받는다"). 음수 간선이 생기므로
경로 탐색은 BFS 가 아니라 **벨만-포드/SPFA** 를 쓴다.

### 기본 그래프로

```
경로 S→1→T: 단가 1+1=2, 용량 2 → 2단위 흘림.        누적 유량 2, 비용 4
경로 S→1→2→T: 단가 1+1+2=4, 병목 1 → 1단위.          누적 3, 비용 8
경로 S→2→T: 단가 3+2=5, 병목 2 → 2단위.              누적 5, 비용 18
더 이상 경로 없음 → 최대 유량 5, 최소 비용 18
```

싼 경로(`S→1→T`, 단가 2)부터 채우고, 점점 비싼 경로를 쓴다. **최대 유량 5, 그때의 최소 비용 18.**

### 비용

```
증가 경로 한 번: SPFA O(V·E)
경로 횟수: 최대 유량 F 에 비례(정수 용량)
합계: O(F · V · E)  (스케일링·다익스트라+퍼텐셜로 개선 가능)
```

## 아이디어 쌓기

### 1단계 — 최대 유량 골격

잔여 그래프 + 증가 경로 + 역간선(되돌리기). 여기까진 최대 유량과 같다.

### 2단계 — 경로 선택을 "최단 비용" 으로

BFS 대신 최단 비용 경로. 싼 흐름부터 채운다.

### 3단계 — 역간선 비용 = −원가

음수 간선이 생겨 SPFA(벨만-포드)로 경로를 찾는다.

### 4단계 — 병목만큼 흘리고 비용 누적

`비용 += 병목 × 경로 단가`. 경로가 없을 때까지 반복.

## 코드로 옮기기

```cpp
int mcmf(int s, int t) {                     // 최소 비용, 최대 유량
    int flow = 0, cost = 0;
    while (true) {
        auto [dist, par] = spfa(s);           // 최단 비용 증가 경로
        if (dist[t] == INF) break;            // 더 못 보내면 끝
        int bott = INF;                        // 경로의 최소 잔여
        for (int v = t; v != s; v = from[par[v]])
            bott = min(bott, cap[par[v]]);
        for (int v = t; v != s; v = from[par[v]]) {
            cap[par[v]]     -= bott;           // 정방향 소모
            cap[par[v] ^ 1] += bott;           // 역방향 잔여(비용 −)
        }
        flow += bott;
        cost += bott * dist[t];               // 이 경로 단가 × 유량
    }
    return cost;
}
```

`par[v] ^ 1` 로 역간선을 찾는다(간선을 쌍으로 저장). `dist[t]` 가 이번 경로의 단위 비용.

## 자주 하는 실수

**BFS 로 경로를 찾는다.** 그건 최대 유량(비용 무시)이다. 비용까지면 **최단 비용 경로(SPFA)**.

**역간선 비용을 +로 둔다.** 반드시 −(원가). 안 그러면 재배치가 비용을 안 줄여 최적을 놓친다.

**음수 간선에 다익스트라(순진).** 역간선이 음수라 순진한 다익스트라는 틀린다. SPFA 나 **퍼텐셜(존슨)**
로 음수를 없앤 다익스트라를 쓴다.

**용량과 비용을 헷갈린다.** 병목은 **용량(잔여)** 의 최소, 단가는 **비용** 의 합.

## 스스로 확인하기

1. **최단 비용 경로**가 매 라운드 강조되는 것을 보자 — 단가가 점점 커진다.
2. **간선 라벨 "유량/용량 ¢비용"** 이 갱신되는 것을 보자.
3. **S→1→2→T** 가 역간선/교차 간선을 쓰는지 관찰하자.
4. **누적 유량 5, 누적 비용 18** 로 끝나는 것을 확인하자.
5. 그래프 편집기로 용량을 바꿔(비용은 1로 처리) 유량이 어떻게 바뀌는지 보자.
6. 어떤 간선의 용량을 0에 가깝게 줄여 병목이 옮겨가는 것을 보자.

아래 **깊이 보기**에서는 최단 비용 경로 그리디가 왜 최적인지, 퍼텐셜(존슨)로 다익스트라를 쓰는 가속,
할당·수송 문제로의 응용을 다룬다.
