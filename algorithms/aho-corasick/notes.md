## 한눈에

여러 패턴을 텍스트 **한 번 훑기**로 모두 찾는다. 패턴들을 [트라이](#/algo/trie)에 넣고, [KMP](#/algo/kmp)의
실패 함수를 트라이로 일반화한 **실패 링크**를 걸어, 텍스트를 되돌리지 않고 전이하며 매칭을 보고한다.

- **시간** `O(n + m + z)`(텍스트 n, 패턴 총길이 m, 매칭 수 z) · **공간** `O(m·Σ)`(자식 배열이면)
- **실패 링크** `fail[u]` = 루트→u 문자열의 최장 진접미사에 해당하는 노드
- **출력 링크** `out[v] ⊇ out[fail[v]]` — 접미사로 끝나는 패턴까지 상속(겹침 포착)
- 트라이 + KMP 의 결합 — 다중 패턴판 KMP

**언제 쓰나** — 사전의 여러 단어를 텍스트에서 동시 검색(스팸/바이러스 시그니처, 금칙어, 자동완성 사전
매칭, 생물정보 모티프). "패턴이 여럿" 이면 아호-코라식.

**언제 안 쓰나** — 패턴이 하나면 [KMP](#/algo/kmp)로 충분. 근사/와일드카드 매칭은 다른 기법.

## 동작 원리

```
insert(패턴들)                    # 트라이(goto 간선)
build():                          # 실패 링크 BFS
    루트 자식의 fail = 루트
    BFS: 노드 u 의 자식 v(문자 c):
        f = fail[u]; while f≠루트 and go[f][c] 없음: f = fail[f]
        fail[v] = go[f][c] (없으면 루트)
        out[v] |= out[fail[v]]    # 접미사 패턴 상속
search(t):
    u = 루트
    for c in t:
        while u≠루트 and go[u][c] 없음: u = fail[u]   # 막히면 미끄러짐
        u = go[u][c] (없으면 루트)
        report(out[u])
```

### 실패 링크 = 트라이 위의 KMP

KMP 의 `fail[i]` 는 문자열 하나의 접두사=접미사였다. 아호-코라식은 이를 **트라이의 모든 경로**로
확장한다: `fail[v]` 는 루트→v 문자열의 최장 진접미사에 대응하는 노드. BFS 로 계산하는 이유는
`fail[v]` 가 `fail[부모]` 를 참조하기 때문(레벨 순 의존).

### 자동자 형태(전이 접기)

매 전이에서 fail 사슬을 따라가는 대신, 없는 전이를 미리 `go[u][c] = go[fail[u]][c]` 로 **접어** 두면
각 전이가 `O(1)` 인 결정적 유한 자동자(DFA)가 된다. 스캔이 정확히 `n` 스텝.

## 정확성

> **실패 링크 정의.** `fail[v]` = 루트→v 문자열 `S(v)` 의 **가장 긴 진접미사** 중 트라이에 존재하는
> 것에 해당하는 노드.

*BFS 계산의 정당성.* `v` 가 `u` 의 `c`-자식이면 `S(v)=S(u)+c`. `S(v)` 의 진접미사는 "`S(u)` 의 어떤
접미사 + c". 그 최장을 찾으려면 `S(u)` 의 접미사들을 긴 것부터, 즉 `fail[u], fail[fail[u]], …` 를 따라가며
`c`-자식이 있는 첫 노드를 취한다. BFS 순서라 `fail[u]` 는 이미 확정. ∎

> **매칭 완전성.** `search` 가 위치 `i` 를 처리한 뒤 도달한 노드 `u` 는 "`t[0..i]` 의 접미사이면서
> 트라이 경로인 최장 문자열" 이다. `out[u]`(상속 포함)가 `i` 에서 끝나는 모든 패턴을 정확히 준다.

*불변식.* 전이 규칙이 "현재 접미사에 `c` 를 붙여 가장 긴 트라이 경로 유지" 를 보장(실패 링크의 정의).
어떤 패턴이 `i` 에서 끝나면 그것은 `t[0..i]` 의 접미사이자 트라이 경로 → `u` 또는 그 fail 사슬 위의
끝 노드. `out` 상속이 이를 모두 포함. ∎

## 복잡도

| 단계 | 시간 |
|---|---|
| 트라이 구성 | `O(m)` (m = 패턴 총길이) |
| 실패 링크 BFS | `O(m·Σ)` 또는 `O(m)`(맵) |
| 텍스트 스캔 | `O(n + z)` (z = 매칭 수) |
| **전체** | `O(n + m + z)` |

### 왜 스캔이 선형인가

전이 접기(DFA)면 각 글자마다 `O(1)` 전이 → `O(n)`. 접지 않고 fail 사슬을 따라도, 스캔 중 `u` 의
깊이가 전이마다 최대 1 증가하고 fail 은 깊이를 줄이므로, KMP 와 같은 분할상환으로 총 `O(n)`.
매칭 보고가 `z` 개.

## 구현 노트

**전이 표현** — 조밀 알파벳은 `go[node][Σ]` 배열(빠름), 희소하면 맵.

**출력 상속** — `out[v] |= out[fail[v]]` 필수. 없으면 접미사 패턴(겹침) 누락. 매칭 보고 시 fail 사슬을
따라가며 보고해도 되지만, 상속해 두면 보고가 빠르다(다만 z 가 커질 수 있음).

**BFS 순서** — 실패 링크는 반드시 레벨 순으로 계산.

**루트 자기 참조** — `fail[루트]=루트`. 막혀서 루트에 오면 멈춘다.

## 변형과 확장

### 전이 접기(DFA)

`go[u][c]` 를 완전히 채워(없으면 `go[fail[u]][c]`) 스캔을 `O(n)` 결정적 전이로. 온라인 스트리밍에 유리.

### 사전 매칭·필터

금칙어·시그니처 사전을 한 자동자에 넣고 스트림을 훑어 실시간 탐지(IDS, 스팸, DLP).

### dp on trie/automaton

"금칙어를 포함하지 않는 길이 L 문자열 수" 같은 문제를, 자동자 상태를 DP 차원으로 삼아 푼다
(automaton + DP).

### 접미사 자동자·접미사 배열

한 텍스트의 모든 부분문자열을 다루려면 접미사 자동자/배열. 아호-코라식은 **여러 패턴 vs 한 텍스트** 에 특화.
