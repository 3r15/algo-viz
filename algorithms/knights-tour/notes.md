## 한눈에

나이트가 판의 모든 칸을 정확히 한 번씩 밟는 경로(열린 여행)를 찾는다.
골격은 백트래킹이지만, 후보를 **바른스도르프 규칙**(갈 곳이 가장 적은 칸부터)으로
정렬하는 것만으로 물러남이 거의 사라진다.

- **시간** 휴리스틱이 통하면 `Θ(n²)`(칸마다 상수 작업). 최악은 지수
- **공간** `Θ(n²)` — `order` 판 + 재귀 스택 `n²` 단
- **완전하지만 보장은 아니다** — 백트래킹은 완전하고, 바른스도르프는 **휴리스틱**이다
- 본질은 **해밀턴 경로** 찾기. 일반 그래프에서는 NP-완전이지만 나이트 그래프는 구성적 해법이 있다

**언제 쓰나** — 백트래킹에서 **후보 순서가 성능을 지배한다**는 것을 보여 주는 최고의 예제.
같은 원리가 스도쿠(MRV)·SAT 솔버의 변수 선택 휴리스틱·제약 프로그래밍에 그대로 쓰인다.

**언제 안 쓰나** — `8×8` 이상에서 **여행 하나만** 필요하면 백트래킹이 아니라
**분할 정복 구성법**을 쓴다(판을 조각내어 각 조각의 여행을 이어 붙인다, `Θ(n²)` 보장).
"여행의 개수" 를 세는 것은 `8×8` 만 해도 열린 여행이 약 `1.9 × 10^13` 개라 전수 탐색이 무의미하다.

## 동작 원리

### 그래프로 보면

칸을 정점, 나이트 이동을 간선으로 두면 **나이트 그래프**가 된다.
열린 여행 = **해밀턴 경로**, 닫힌 여행 = **해밀턴 순환**이다.

이 그래프는 **이분 그래프**다. 나이트는 `(±1, ±2)` 로 움직이므로 `(r + c)` 의 홀짝이 매번 바뀐다 —
**항상 반대 색 칸으로 간다.** 이 사실 하나가 뒤의 존재성 논증을 전부 만들어 낸다.

### 백트래킹 골격

```
order[r][c] = step                    // 번호를 적는다(0 = 안 밟음)
if step == total: 성공
for 후보 in 갈 수 있는 칸들:
    성공하면 즉시 반환
order[r][c] = 0                       // 물러난다
```

`order` 가 방문 여부와 방문 순서를 **겸한다**. 그래서 `visited` 배열이 따로 없다.

### 바른스도르프 규칙

> 후보 칸들을 `degree`(그 칸에서 아직 안 밟은 칸으로 갈 수 있는 가짓수) **오름차순**으로 시도한다.

근거는 이렇다. 구석·가장자리 칸은 출입구가 적다(`5×5` 구석은 2개, 가운데는 8개).
출입구가 적은 칸을 뒤로 미루면 그 통로가 다른 이동에 쓰여 버려 **고립**된다.
고립된 칸은 나중에 못 밟으므로 깊은 곳에서 되돌아와야 한다.

**제약이 가장 심한 것을 먼저 처리한다** — 이것이 규칙의 전부이고, 스도쿠의 MRV 와 같은 원리다.

`degree` 는 밟을 때마다 줄어들므로 **매번 다시 센다.** 캐시하면 규칙이 무의미해진다.

### 실행 예 (`5×5`, 시작 `(0,0)`)

```
   1  20   9  14   3
  10  15   2  19  24
  21   8  23   4  13
  16  11   6  25  18
   7  22  17  12   5

이동 25번, 물러남 0번
```

후보 수의 흐름을 보면 규칙이 하는 일이 드러난다.

```
1: 후보 2곳 → 2: 후보 5곳, 그중 1곳짜리로 → 3: 후보 1곳 → 4: 후보 5곳, 1곳짜리로 → …
```

**"여유 있는 칸" 에서 "위험한 칸" 으로** 계속 오간다.

## 정확성

### 백트래킹 부분 — 완전성과 건전성

> **건전성.** 성공 반환 시 `order` 는 유효한 열린 여행이다.

`step` 은 `1` 부터 `total` 까지 정확히 한 번씩 배정되고(재귀 깊이마다 `step + 1`),
`order[nr][nc]` 가 0이 아닌 칸으로는 진입하지 않으므로 **각 칸이 한 번만** 번호를 받는다.
또한 후보는 `dr`/`dc` 로 만든 나이트 이동뿐이므로 연속한 두 번호는 나이트 이동 관계다. ∎

> **완전성.** `tour(r, c, step)` 이 `false` 를 반환하면, 지금까지의 부분 경로를 접두사로 갖는
> 완전한 여행은 존재하지 않는다.

`total - step` 에 대한 귀납법이다. `false` 는 후보 루프를 전부 소진했다는 뜻이고,
각 후보는 (판 밖이거나 이미 밟았거나) 또는 (귀납 가정에 의해 그쪽으로도 완성 불가) 였다.
현재 칸에서 다음에 갈 수 있는 곳은 이 후보들뿐이므로, 확장이 아예 불가능하다. ∎

**후보 순서는 완전성에 영향을 주지 않는다.** 순서를 어떻게 바꿔도 같은 집합을 전부 시도하므로,
바른스도르프는 **속도만** 바꾼다. 이것이 휴리스틱을 마음 편히 얹을 수 있는 근거다.

**종료성** — 각 호출은 아직 안 밟은 칸으로만 내려가므로 재귀 깊이가 `total` 을 넘지 않고,
각 깊이의 후보가 최대 8개이므로 탐색 트리가 유한하다.

### 색칠 논증 — 어디서 출발할 수 있나

나이트는 항상 반대 색으로 간다. 길이 `total` 인 경로는 색이 **번갈아** 나타나므로,
시작 색을 `X` 라 하면

```
X 색 칸 수 = ⌈total / 2⌉,   반대 색 칸 수 = ⌊total / 2⌋
```

**`total` 이 홀수면** 두 수가 다르다. 즉 **많은 쪽 색에서 출발해야 한다.**

`5×5` 를 보자. `(r+c)` 가 짝수인 칸이 13개, 홀수인 칸이 12개다.

```
총 25칸(홀수)  →  많은 쪽(짝수 색, 13개)에서 시작해야 한다
(0,0):  0+0 = 0 (짝수)  →  가능      ← 이 페이지의 시작점
(0,1):  0+1 = 1 (홀수)  →  열린 여행이 존재하지 않는다
```

**같은 판에서도 시작점에 따라 답이 없을 수 있다.** 이 페이지는 항상 `(0,0)` 에서 출발하므로
`5×5` 에서 이 문제를 피한다.

> **닫힌 여행은 홀수 칸 판에 아예 없다.** 순환은 시작과 끝이 같은 칸이므로 길이가 짝수여야 하는데,
> `total` 이 홀수면 불가능하다. 그래서 `5×5` 에는 닫힌 여행이 **존재하지 않는다.** ∎

### 존재하지 않는 판

**`3×3`** — 가운데 칸 `(1,1)` 에서 나이트가 갈 수 있는 8방향이 모두 판 밖이다.
`degree = 0`, 즉 **고립점**이다. 고립점을 지나는 경로는 없으므로 여행이 존재하지 않는다. ∎
(이 페이지에서 `3` 을 넣으면 32스텝 만에 소진하고 "없다" 로 끝난다.)

**`4×4`** — 여행이 존재하지 않음이 알려져 있다. 증명은 `3×3` 처럼 짧지 않고
경우 분석이 필요하다. 이 페이지에서 `4` 를 넣으면 **1200스텝 예산을 다 쓰고 중단**한다 —
"없음" 을 확인하려면 전수 탐색이라 스텝이 폭발한다는 것을 그대로 보여 준다.

**일반 판** — `m ≤ n` 인 `m×n` 판에서 `m ≥ 5` 이면 **항상 열린 여행이 존재**한다.
더 작은 판은 일부만 가능하고, 완전한 분류가 알려져 있다.

닫힌 여행의 조건은 **슈벵크 정리**로 완전히 정리된다. `m ≤ n` 인 `m×n` 판은
다음 중 하나라도 성립하면 닫힌 여행이 없고, 아니면 있다.

```
① m 과 n 이 모두 홀수            (위의 색칠 논증)
② m = 1, 2, 4
③ m = 3 이고 n = 4, 6, 8
```

### 바른스도르프는 보장이 아니다

> 바른스도르프 규칙만 따라가면(물러나지 않고) 항상 여행이 완성된다 — **이것은 참이 아니다.**

동점 처리 방식과 시작점에 따라 막히는 경우가 알려져 있고, 판이 커지면 실패 사례도 생긴다.
그래서 이 구현은 **백트래킹을 그대로 남겨 둔다** — 휴리스틱은 순서만 정하고,
막히면 완전한 탐색이 받쳐 준다.

실무에서 보강하는 방법은 두 갈래다. **동점을 더 정교하게 깨거나**(가장자리에서 먼 쪽 우선 등),
아니면 아래의 **구성적 방법**으로 갈아타는 것이다.

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 휴리스틱 성공 | `Θ(n²)` | `Θ(n²)` |
| 최악 | 지수(`O(8^{n²})` 상한) | `Θ(n²)` |

**휴리스틱이 통할 때** — 칸마다 한 번 방문하고, 각 방문에서 후보 8개의 `degree` 를 세며
각 `degree` 계산이 8번 검사다.

```
칸 n² 개 × (후보 8개 × degree 8검사) = Θ(n²) × O(64) = Θ(n²)
```

이 페이지의 스텝 수가 그 증거다.

```
n = 5:  26 스텝  (칸 25개, 물러남 0)
n = 6:  37 스텝  (칸 36개, 물러남 0)
n = 7:  50 스텝  (칸 49개, 물러남 0)
```

**스텝 수가 칸 수에 비례한다** — 휴리스틱이 통하는 동안은 사실상 선형(칸 수 기준)이다.

**최악** — 물러남이 시작되면 지수로 간다. `4×4` 처럼 **해가 없는 판**이 최악을 그대로 보여 준다.
1200스텝 예산으로 끊었지만, 예산 없이 두면 그 판은 훨씬 더 많은 스텝을 소모한다.

**해밀턴 경로의 어려움** — 일반 그래프에서 해밀턴 경로 판정은 **NP-완전**이다.
나이트 그래프는 구조가 특수해서 다항 시간 구성법이 있지만, "임의의 시작·끝점을 지정한
여행" 같은 변형은 훨씬 어려워진다.

## 구현 노트

**`order` 가 방문 여부와 순서를 겸한다.** `0` 을 "안 밟음" 으로 쓰므로 `step` 은 **1부터** 세야 한다.
0부터 세면 출발점이 안 밟은 칸으로 취급된다.

**경계 검사를 `order` 접근보다 앞에.** `if (!inside(nr, nc) || order[nr][nc])` 의 순서가 중요하다.
`&&`/`||` 의 단축 평가에 의존해 배열 밖 접근을 막는다.

**`degree` 를 캐시하지 마라.** 밟을 때마다 이웃의 `degree` 가 줄어든다.

**동점 처리를 고정하라.** `degree` 가 같은 후보가 여럿일 때 순서가 실행마다 바뀌면
같은 입력에 다른 경로가 나온다. 이 페이지는 `(degree, 이동 번호)` 로 정렬해
`generate` 의 순수성을 지킨다.

**8방향 배열은 관례를 따르자.**

```cpp
int dr[8] = {-2,-2,-1,-1, 1, 1, 2, 2};
int dc[8] = {-1, 1,-2, 2,-2, 2,-1, 1};
```

**닫힌 여행이 목표라면** 조건이 하나 더 붙는다 — 마지막 칸에서 출발점으로 돌아올 수 있어야 한다.
바른스도르프에 "출발점의 이웃은 가능한 늦게 밟는다" 를 더하는 식으로 보강한다.

## 변형과 확장

### 분할 정복 구성법 — `Θ(n²)` 보장

큰 판을 `5×5` ~ `10×10` 정도의 조각으로 나누고, 각 조각의 **닫힌 여행**을 미리 준비해 둔 뒤
인접한 조각의 순환을 하나로 잇는다(순환 두 개를 교차 간선 두 개로 합치는 표준 기법).
백트래킹 없이 항상 성공하고 시간이 칸 수에 선형이다. **여행 하나만 필요할 때의 정답**이다.

### 닫힌 여행

해밀턴 순환을 찾는다. 슈벵크 정리가 존재 조건을 완전히 말해 준다.
`8×8` 에는 존재하고(오일러가 1759년에 예를 제시했다), 방향을 구분하면
`26,534,728,821,064` 개가 있다.

### MRV — 같은 규칙의 일반형

바른스도르프의 "갈 곳이 적은 칸부터" 는 제약 충족 문제의 **MRV(minimum remaining values)**
휴리스틱이다. [N-퀸](#/algo/n-queens)에서 "후보가 가장 적은 행부터 채우기",
스도쿠에서 "빈칸 중 가능한 숫자가 가장 적은 칸부터" 가 정확히 같은 것이다.
**변수 선택 순서가 백트래킹의 성능을 지배한다**는 것이 이 계열의 핵심 교훈이다.

### 마방진 여행

여행의 방문 순서 번호가 마방진(각 행·열의 합이 같은)을 이루게 하는 문제.
`8×8` 에서 완전한 마방진 여행은 **존재하지 않음**이 2003년 전수 계산으로 증명되었다
(반마방진은 존재한다).

### 다른 말로 바꾸기

킹·룩·비숍으로 바꾸면 그래프가 달라져 난이도가 완전히 달라진다.
룩은 자명하게 여행이 존재하고(지그재그), 비숍은 색이 갇혀 절반만 밟을 수 있다.
**그래프 구조가 문제의 성질을 정한다**는 점을 비교해 보기 좋다.
