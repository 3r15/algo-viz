## 한눈에

문자열 `A` 를 `B` 로 바꾸는 최소 편집 수(삽입·삭제·교체 각 비용 1). 접두사 쌍 `(i, j)` 로 상태를
잡아 `(m+1) × (n+1)` 표를 채우는 2차원 DP다. [LCS](#/algo/lcs)와 형제 관계다.

- **시간** `Θ(mn)` · **공간** `Θ(mn)`(복원까지) / `Θ(min(m,n))`(값만)
- 세 이웃(위·왼쪽·대각선)이 세 편집(삭제·삽입·교체)에 정확히 대응
- **거리 공리를 만족한다** — 비음수·대칭·삼각 부등식. 진짜 "거리" 다
- 역추적으로 실제 편집 스크립트(정렬)를 복원한다

**언제 쓰나** — 맞춤법 교정("did you mean"), 퍼지 문자열 검색, DNA/단백질 서열 정렬,
`diff`·버전 관리, OCR 후처리. "두 열이 얼마나 다른가" 를 **연산 횟수**로 재는 표준 도구다.

**언제 안 쓰나** — `m`, `n` 이 각각 수만이면 `Θ(mn)` 이 벅차다. 거리가 작다고 알려져 있으면
**밴드형 DP**(대각선 근처만, `O(nd)`)나 Myers 의 `O(nd)` 가 낫다.
전치(swap)를 1로 세려면 **다메라우–레벤슈타인**으로 확장해야 한다.

## 동작 원리

핵심은 LCS 와 같다 — **양쪽 접두사 쌍**으로 상태를 잡는다.

> `dp[i][j]` = `A[1..i]` 를 `B[1..j]` 로 바꾸는 최소 편집 수

### 점화식

```
dp[i][0] = i                                    A 의 i 글자를 모두 삭제
dp[0][j] = j                                    B 의 j 글자를 모두 삽입
dp[i][j] = dp[i-1][j-1]                          A[i] = B[j]  (편집 0)
         = 1 + min( dp[i-1][j],                  삭제
                    dp[i][j-1],                  삽입
                    dp[i-1][j-1] )               교체         A[i] ≠ B[j]
```

세 참조가 모두 위·왼쪽·대각선이라 행 우선 순회로 위상 순서가 지켜진다.
**세 방향이 세 편집에 대응**하는 것이 이 DP 의 뼈대다.

### 실행 예

`A = kitten`, `B = sitting`

```
      ∅  s  i  t  t  i  n  g
   ∅  0  1  2  3  4  5  6  7
   k  1  1  2  3  4  5  6  7
   i  2  2  1  2  3  4  5  6
   t  3  3  2  1  2  3  4  5
   t  4  4  3  2  1  2  3  4
   e  5  5  4  3  2  2  3  4
   n  6  6  5  4  3  3  2  3
```

`dp[6][7] = 3`. 역추적: `k→s` 교체, `itt` 유지, `e→i` 교체, `g` 삽입.

## 정확성

> **불변식.** 반복이 `(i, j)` 를 지난 뒤 `dp[i][j]` 는 `A[1..i]` 를 `B[1..j]` 로 바꾸는
> 최소 편집 수와 같다.

`i + j` 에 대한 강귀납법.

**기저** — `i = 0` 또는 `j = 0`. 한쪽이 빈 문자열이면 나머지를 통째로 삽입하거나 삭제하는 것이
유일하고 최적인 방법이므로 `dp[i][0] = i`, `dp[0][j] = j`. ✓

**귀납 단계** — `i, j ≥ 1`. 최적 편집열의 **마지막 연산**으로 경우를 나눈다.
(어떤 최적 편집열이든 마지막 연산은 아래 넷 중 하나로 볼 수 있다.)

*`A[i] = B[j]` 이고 마지막에 이 글자를 건드리지 않음* — 나머지는 `A[1..i-1] → B[1..j-1]` 이므로
비용 `dp[i-1][j-1]`. 귀납 가정으로 이 값이 최적이다.

*교체 `A[i] → B[j]`* — 나머지는 `A[1..i-1] → B[1..j-1]`, 총 `1 + dp[i-1][j-1]`.

*삭제 `A[i]`* — 나머지는 `A[1..i-1] → B[1..j]`, 총 `1 + dp[i-1][j]`.

*삽입 `B[j]`* — 나머지는 `A[1..i] → B[1..j-1]`, 총 `1 + dp[i][j-1]`.

최적해는 이 중 하나이므로 최솟값이다. `A[i] = B[j]` 이면 첫 경우가 `dp[i-1][j-1]` 로
나머지 셋(모두 `≥ dp[i-1][j-1]`, 아래 립시츠 참고)보다 크지 않아 지배하므로 코드의
`dp[i][j] = dp[i-1][j-1]` 가 옳다. 다르면 세 편집의 최솟값 + 1 이 코드와 일치한다. ∎

> **립시츠 성질(참고).** `|dp[i][j] − dp[i-1][j]| ≤ 1`, 대각·열 방향도 같다.
> 글자 하나를 더 봐도 편집 수가 1을 넘게 변할 수 없기 때문이며,
> 이 성질이 위에서 "첫 경우가 지배" 를 정당화하고 밴드형 최적화의 근거가 된다.

**거리 공리** — 이렇게 정의된 `d(A, B) = dp[m][n]` 은 (1) `d ≥ 0`, `d = 0 ⟺ A = B`,
(2) `d(A,B) = d(B,A)`(삽입↔삭제 대칭), (3) `d(A,C) ≤ d(A,B) + d(B,C)`(편집열을 이어 붙이면 되므로)
를 만족한다. 그래서 진짜 **거리(metric)** 다 — 클러스터링·최근접 탐색에 쓸 수 있는 근거다.

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 최선 | `Θ(mn)` | `Θ(mn)` / `Θ(min(m,n))` |
| 평균 | `Θ(mn)` | 〃 |
| 최악 | `Θ(mn)` | 〃 |

**시간** — 칸이 `(m+1)(n+1)` 개, 각 칸이 상수 작업. 조기 종료가 없어 최선·최악이 같다.

**공간** — `dp[i]` 가 `dp[i-1]` 과 `dp[i][j-1]` 만 참조하므로 **행 하나 + 변수 하나**면 값 계산은 된다
→ `Θ(min(m,n))`(짧은 쪽을 열로). 다만 **역추적을 하려면 표 전체**가 필요하다.
둘 다 원하면 **Hirschberg** 분할 정복이 `Θ(mn)` 시간에 `Θ(min(m,n))` 공간으로 편집열까지 준다.

**하한** — 일반 알파벳에서 편집 거리를 `O((mn)^{1-ε})` 에 푸는 알고리즘은 SETH 를 깨뜨린다는
결과가 있다. 즉 **이차 시간을 실질적으로 개선할 수 없다**(LCS 와 같은 벽).

## 구현 노트

**경계는 인덱스 값으로.** `dp[i][0] = i`, `dp[0][j] = j`. 0으로 두는 실수가 가장 흔하다.

**같을 때 +0.** `A[i] == B[j]` 면 대각선 그대로다. `+1` 하면 안 된다.

**1-based 표 vs 0-based 문자열.** `A[i-1]`. LCS 와 같은 어긋남.

**비용을 바꾸려면** — 삽입·삭제·교체에 서로 다른 비용을 주면 각 항에 그 비용을 곱한다.
DNA 정렬은 교체 비용을 치환 행렬(BLOSUM 등)로, 갭(삽입/삭제)을 별도 비용으로 준다.

**롤링 배열(값만):**

```cpp
vector<int> prev(n + 1), cur(n + 1);
for (int j = 0; j <= n; j++) prev[j] = j;
for (int i = 1; i <= m; i++) {
    cur[0] = i;
    for (int j = 1; j <= n; j++)
        cur[j] = (A[i-1] == B[j-1]) ? prev[j-1]
               : 1 + min({ prev[j], cur[j-1], prev[j-1] });
    swap(prev, cur);
}
return prev[n];
```

## 변형과 확장

### LCS 와의 관계

**삽입·삭제만** 허용하고 교체를 금지하면(또는 교체 비용을 2로 주면)

```
edit(A, B) = m + n − 2·LCS(A, B)
```

가 성립한다. 교체를 비용 1로 허용하면 이 관계가 깨진다 —
`kitten/sitting` 이 그렇다(edit 3, 위 공식은 다른 값을 준다). **교체의 유무가 두 문제를 가른다.**

### 다메라우–레벤슈타인 — 전치 추가

인접한 두 글자의 **자리 바꿈**(`ab → ba`)을 1로 센다. `teh → the` 가 1이 된다.
오타의 상당수가 전치라 맞춤법 교정에서 중요하다. 점화식에 항이 하나 더 붙는다.

### 밴드형 DP — 거리가 작을 때

편집 거리가 `d` 이하라고 알면, 최적 경로는 주대각선에서 `d` 칸 이상 벗어나지 않는다.
대각선 주변 폭 `2d+1` 띠만 채우면 `O(nd)` 다. `d` 가 작으면(닮은 문자열) 극적으로 빠르다.

### Myers 의 `O(nd)` diff

`git diff` 가 쓰는 알고리즘. 편집 그래프의 최단 경로를 대각선(diagonal) 단위로 탐색해
차이 `d` 에 비례하는 시간에 편집 스크립트를 찾는다. 삽입·삭제만 다루는 LCS 형 diff 다.

### Hirschberg — 선형 공간 복원

분할 정복으로 표를 절반씩 나눠, `Θ(mn)` 시간을 유지하면서 `Θ(min(m,n))` 공간에 편집열까지 복원한다.
LCS 에서 본 그 기법이 그대로 적용된다.

### 근사 문자열 검색

텍스트 `T` 안에서 패턴 `P` 를 편집 거리 `k` 이하로 포함하는 위치를 찾는다.
DP 표의 첫 행을 0으로 두는 변형으로 `O(|T||P|)` 에, 비트 병렬(Bitap)로는 훨씬 빠르게 푼다.
