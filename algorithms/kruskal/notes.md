## 한눈에

가중치가 있는 무방향 그래프에서, 모든 정점을 잇는 간선 부분집합 중 **가중치 합이 최소인 것**을
찾는다. 그런 부분집합은 항상 트리가 되므로 **최소 신장 트리(MST)** 라 부른다.

크루스칼의 전략은 놀랄 만큼 단순하다.

> 간선을 **싼 것부터** 훑으면서, **사이클을 만들지 않는 것만** 채택한다.

- 시간 O(E log E) — 사실상 정렬 비용
- "사이클을 만드는가"는 **유니온 파인드**로 거의 O(1) 에 판정한다
- 그리디가 통하는 이유는 아래 **컷 성질** 때문이다

## 동작 원리

```
1. 간선을 가중치 오름차순으로 정렬
2. 각 정점을 자기 자신만 있는 집합으로 초기화
3. 간선 (u,v) 를 순서대로:
       find(u) == find(v) 이면  → 이미 연결됨 = 사이클 → 버린다
       아니면                    → 채택하고 union(u,v)
4. 간선을 V-1 개 모으면 끝
```

**유니온 파인드(서로소 집합)** 는 "지금 어떤 정점들이 서로 연결돼 있는가"를 관리한다.
시각화의 정점 아래 숫자가 그 정점이 속한 집합의 **대표(root)** 이고,
간선을 채택할 때마다 두 집합의 대표가 하나로 합쳐지는 것을 볼 수 있다.

```
find(x)   x 가 속한 집합의 대표를 찾는다
union(a,b) 두 집합을 합친다
```

`find(u) == find(v)` 는 곧 "u 와 v 가 이미 이어져 있다"는 뜻이고, 거기에 간선을 하나 더
얹으면 반드시 사이클이 생긴다.

### 경로 압축

```cpp
int find(int x) {
    return parent[x] == x ? x : parent[x] = find(parent[x]);
}
```

대표를 찾아 올라가면서 **지나온 노드들의 부모를 대표로 바로 바꿔 둔다.**
다음 번 `find` 는 한 칸 만에 끝난다. 이 한 줄이 복잡도를 거의 상수로 만든다.

## 정확성

### 컷 성질 (cut property)

> 정점 집합을 두 덩이 `(S, V∖S)` 로 가르는 임의의 컷을 생각하자.
> 그 컷을 가로지르는 간선 중 **가중치가 가장 작은 간선 `e`** 는 어떤 MST 에 반드시 포함된다.
> (가중치가 유일하게 최소라면 **모든** MST 에 포함된다.)

**증명 (교환 논법)**: `e = (u,v)` 를 포함하지 않는 MST `T` 가 있다고 하자.
`T` 는 신장 트리이므로 `u`—`v` 경로가 존재하고, 그 경로는 컷을 홀수 번 가로지르므로
컷을 가로지르는 간선 `e'` 를 적어도 하나 포함한다.

`T` 에 `e` 를 넣으면 사이클이 하나 생기고, 그 사이클 위의 `e'` 를 빼면 다시 신장 트리
`T' = T − e' + e` 가 된다. `e` 는 컷 최소 간선이므로 `w(e) ≤ w(e')` 이고,

```
w(T') = w(T) − w(e') + w(e) ≤ w(T)
```

`T` 가 최소였으므로 `w(T') = w(T)`, 즉 `T'` 도 MST 이고 `e` 를 포함한다. ∎

### 크루스칼이 옳다

`k` 번째로 채택한 간선까지 모은 집합을 `F_k` 라 하자.

> **불변식**: `F_k` 는 어떤 MST 의 부분집합이다.

`F₀ = ∅` 는 자명하다. `F_k` 가 MST `T` 의 부분집합이라 하고, 다음에 채택하는 간선을
`e = (u,v)` 라 하자. 채택했다는 것은 `u` 와 `v` 가 `F_k` 에서 서로 다른 연결 요소에
있다는 뜻이다. `u` 가 속한 연결 요소를 `S` 로 두고 컷 `(S, V∖S)` 를 보면,

- `e` 는 이 컷을 가로지른다.
- 이 컷을 가로지르는 간선 중 `e` 보다 싼 것은 없다. 있었다면 **더 먼저 검사됐을 것이고**,
  그 간선의 양 끝은 컷의 서로 다른 쪽이라 사이클이 아니므로 이미 채택돼 `S` 가 더 컸을 것이다.

따라서 `e` 는 컷 최소 간선이고, 컷 성질에 의해 `F_k + e` 도 어떤 MST 의 부분집합이다. ∎

간선을 `V-1` 개 모으면 사이클 없는 `V-1` 개 간선 = 신장 트리이고, 불변식에 의해 그것이 MST 다.

### 동점 간선

가중치가 같은 간선이 여럿이면 MST 가 여러 개일 수 있다. 크루스칼은 그중 **하나**를 찾는다.
어떤 것을 찾을지는 정렬의 타이브레이킹에 달려 있다(이 페이지는 원래 입력 순서로 고정해
같은 그래프에 항상 같은 트레이스가 나오게 했다). **총 가중치는 어느 MST 를 고르든 같다.**

### 그래프가 연결되어 있지 않으면

간선을 `V-1` 개 모으지 못하고 끝난다. 결과는 각 연결 요소의 MST 를 모은
**최소 신장 숲(minimum spanning forest)** 이 되고, 위 증명은 그대로 성립한다.

## 복잡도

| 단계 | 시간 |
|---|---|
| 간선 정렬 | **O(E log E)** ← 지배적 |
| 유니온 파인드 `E` 번 | O(E · α(V)) |
| 합계 | **O(E log E) = O(E log V)** |

`E ≤ V²` 이므로 `log E ≤ 2 log V` 라 두 표기는 같다.

`α(V)` 는 **역 아커만 함수**로, 우주의 원자 수 규모의 입력에서도 5 를 넘지 않는다.
사실상 상수다. 경로 압축과 랭크(또는 크기) 합치기를 **둘 다** 쓸 때의 값이다.

공간은 `parent` 배열 O(V) 와 간선 목록 O(E).

### 프림과 비교

| | 크루스칼 | 프림 |
|---|---|---|
| 관점 | 간선 중심 — 싼 간선부터 | 정점 중심 — 트리를 키워 나감 |
| 자료구조 | 정렬 + 유니온 파인드 | 우선순위 큐 |
| 시간 | O(E log E) | O(E log V) (힙) / O(V²) (배열) |
| 유리한 경우 | **희소 그래프** | **밀집 그래프**(E ≈ V²) |

프림은 [다익스트라](#/algo/dijkstra)와 골격이 같다. 차이는 우선순위가
"시작점으로부터의 거리"냐 "트리까지의 거리"냐 하나뿐이다.

## 구현 노트

**정렬을 직접 하지 말고 간선 구조체에 비교 연산자를 두거나**, `(w, u, v)` 튜플로 만들어
기본 정렬을 쓰는 편이 실수가 적다.

**랭크(또는 크기) 합치기**를 빼면 최악에 트리가 한 줄로 길어질 수 있다.
경로 압축만 써도 평균적으로는 충분히 빠르지만(이 페이지의 구현), 엄밀한 `α(V)` 보장을
원하면 둘 다 쓴다.

```cpp
void unite(int a, int b) {
    a = find(a); b = find(b);
    if (a == b) return;
    if (size[a] < size[b]) swap(a, b);   // 큰 쪽에 붙인다
    parent[b] = a;  size[a] += size[b];
}
```

**재귀 `find` 의 깊이**: 랭크 합치기가 없으면 재귀가 깊어져 스택 오버플로가 날 수 있다.
반복문으로 바꾸거나 랭크를 함께 쓰자.

**`V-1` 개를 모으면 즉시 중단**하면 남은 간선을 훑지 않아도 된다. 정렬 비용이 지배적이라
점근 복잡도는 그대로지만, 실측에서는 의미 있는 차이가 난다.

## 변형과 확장

- **최대 신장 트리**: 가중치 내림차순으로 정렬하면 그대로 동작한다. 컷 성질의 부호만 뒤집힌다.
- **최소 병목 신장 트리**: MST 는 "경로상 최대 간선"을 최소화하는 트리이기도 하다.
  두 정점 사이 경로의 최대 간선을 묻는 질의는 MST 위에서
  [이진 상승](#/algo/binary-lifting)으로 O(log V) 에 답한다.
- **차선 MST**: MST 간선 하나를 빼고 다른 간선으로 바꾸는 최선의 교환을 찾는다.
  역시 경로 최대 간선 질의가 핵심이다.
- **동적 연결성**: 유니온 파인드는 간선 추가만 다룬다. 삭제까지 필요하면
  링크-컷 트리나 오프라인 처리(시간 분할 정복)로 간다.
- **클러스터링**: 크루스칼을 `V-k` 개 간선에서 멈추면 `k` 개 클러스터가 남는다
  (단일 연결 계층 군집화와 동일).
