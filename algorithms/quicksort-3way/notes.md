## 한눈에

피벗 기준으로 배열을 **세 구간** `<피벗 · =피벗 · >피벗` 으로 나눈다(네덜란드 국기 분할).
같은 값 구간은 **최종 위치가 확정**되어 재귀에서 빠지므로, 중복이 많은 입력에서 일반 퀵 정렬의
`O(n²)` 퇴화를 막는다.

- **시간** 평균 `O(n log n)` / 최악 `O(n²)`(피벗 나쁨) / **중복 많으면 O(n·(1+H))** (H=값 분포 엔트로피) · **공간** `O(log n)`
- 세 포인터 `lt, i, gt` 로 **한 번 훑기** 파티션 · **제자리(in-place)**
- 같은 값을 한 번에 확정 → 값 종류가 적으면 매우 빠름(모두 같으면 `O(n)`)
- 불안정 정렬(교환으로 순서 바뀜)

**언제 쓰나** — **중복이 많은** 데이터 정렬, 범주형 키, 퀵셀렉트/부분 정렬의 파티션.

**언제 안 쓰나** — 안정성이 필요하면(병합 정렬), 최악 보장이 절대적이면(힙·병합). 거의 유일값이면
일반 퀵 정렬과 큰 차이 없다.

## 동작 원리

```
sort3(a, lo, hi):
    if lo >= hi: return
    pivot = a[lo];  lt = lo;  gt = hi;  i = lo+1
    while i <= gt:
        if a[i] < pivot:  swap(a[lt++], a[i++])   # 작은 것 왼쪽
        elif a[i] > pivot: swap(a[i], a[gt--])     # 큰 것 오른쪽(i 유지)
        else: i++                                   # 같은 것 가운데
    sort3(a, lo, lt-1);  sort3(a, gt+1, hi)         # =피벗 구간 [lt..gt] 는 제외
```

### 왜 `>` 에서 i 를 안 올리나

`a[i] < pivot` 교환은 `lt` 자리(이미 지나온 `<피벗` 또는 `=피벗`)에서 값을 가져오므로 `i` 를 올려도 안전.
`a[i] > pivot` 교환은 `gt` 자리(**아직 안 본** 값)를 가져오므로 그 자리를 **다시 검사**해야 해 `i` 를 유지.

## 정확성

> **루프 불변식.** `while` 각 반복 시작 시:
> `a[lo..lt-1] < pivot`,  `a[lt..i-1] == pivot`,  `a[i..gt]` 미검사,  `a[gt+1..hi] > pivot`.

*유지.* 세 경우가 각각 불변식을 지킨다:
- `<`: `a[i]` 를 `a[lt]`(=pivot 이거나 경계)와 교환 → `<pivot` 이 `[lo..lt]` 로, `=pivot` 이 한 칸 밀림. `lt++, i++`.
- `>`: `a[i]` 를 `a[gt]`(미검사)와 교환 → `>pivot` 이 `[gt..hi]` 로. `gt--`, `i` 유지(새 `a[i]` 재검사).
- `=`: `a[i]==pivot` 이 `=` 구간에 편입. `i++`.

*종료.* `gt - i` 가 매 반복 감소(`<`: i↑, `>`: gt↓, `=`: i↑) → `i > gt` 로 종료. 그때
`a[lt..gt] == pivot` 이고 좌우가 각각 `<`, `>`. ∎

> **정확성.** `[lt..gt]` 는 정렬 후에도 그 위치(피벗과 같은 값들의 최종 자리)다. 좌우 구간을 재귀
> 정렬하면 전체가 정렬된다.

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 평균(고유값 많음) | `O(n log n)` | `O(log n)` |
| 최악(피벗 편향) | `O(n²)` | `O(log n)` |
| 중복 많음(값 종류 적음) | `O(n·(1+H))` ~ `O(n)` | `O(log n)` |

### 중복 입력에서의 우위

일반 2-way 파티션은 `[v,v,…,v]` 에서 피벗과 같은 값을 계속 한쪽으로 밀어 `O(n²)`. 3-way 는 같은 값을
한 번에 확정해 **한 번의 파티션으로 `O(n)`**. 값 종류가 `k` 개면 재귀 깊이가 대략 `O(log k)`,
전체는 정보 이론적 하한 `O(n·H)`(H = 값 분포 엔트로피)에 가깝다 — **엔트로피 최적** 정렬로 알려져 있다.

## 구현 노트

**`>` 분기 i 유지** — 가장 흔한 버그. `gt` 에서 온 값은 미검사.

**루프 경계** — `while (i <= gt)`. `gt` 포함.

**피벗 선택** — `a[lo]` 는 이미 정렬된 입력에서 최악. 무작위 피벗/median-of-three 권장.

**재귀 제외** — `=피벗` 구간 `[lt..gt]` 는 재귀 안 함. 작은 쪽부터 재귀하면 스택 `O(log n)`.

**Bentley–McIlroy** — 실전 라이브러리는 파티션 중 피벗-동일값을 양끝에 모았다가 가운데로 합치는 변형을 쓴다.

## 변형과 확장

### 무작위 피벗 (라스베이거스)

`swap(a[lo], a[rand(lo,hi)])` 후 파티션 → 적대적 입력의 최악을 확률적으로 제거.

### 퀵셀렉트에 응용

[퀵셀렉트](#/algo/quickselect)를 3-way 파티션으로 하면 중복이 많아도 안정적으로 평균 `O(n)`.

### 문자열 3-way radix quicksort

문자열을 한 글자씩 3-way 로 나누며 정렬(멀티키 퀵 정렬) — 접두사 공유를 활용해 빠르다.

### 이분 파티션과의 관계

고유값이 많으면 3-way 는 사실상 일반 퀵 정렬과 같다(=구간 크기 1). 이득은 오직 중복에서 온다.
