## 한눈에

한 정점에서 나머지 모든 정점까지의 **최단 거리**를 구한다. 핵심은 한 문장이다.

> 아직 확정되지 않은 정점 중 **잠정 거리가 가장 작은 것**을 고르면, 그 거리는 이미 최단 거리다.

이게 성립하려면 **간선 가중치가 음수가 아니어야** 한다. 음수 간선이 하나라도 있으면
"돌아가면 오히려 싸지는" 일이 생겨 그리디 선택이 무너진다.

- 시간 O((V+E) log V) · 공간 O(V) · 우선순위 큐 사용
- 가중치가 모두 같다면 [BFS](#/algo/bfs) 로 충분하다. 다익스트라는 그 일반화다.

## 동작 원리

`dist[v]` 를 "지금까지 발견한 s→v 경로 중 가장 짧은 것"으로 두고 시작한다.
시작점만 0, 나머지는 ∞다.

```
1. PQ 에서 dist 가 가장 작은 정점 u 를 꺼낸다        → dist[u] 확정
2. u 의 모든 이웃 v 에 대해 완화(relax) 를 시도한다
       dist[u] + w(u,v) < dist[v] 이면 dist[v] 를 줄이고 PQ 에 다시 넣는다
3. PQ 가 빌 때까지 반복
```

**완화(relaxation)** 는 "u 를 거쳐 가면 더 싸지는가?"를 묻는 것이다. 시각화에서 간선이
잠깐 밝아지는 순간이 이 질문이고, 성공하면 그 정점의 거리 라벨이 줄어든다.

### 낡은 항목 버리기

이 구현은 PQ 에서 원소를 **수정하지 않는다**(decrease-key 없이). 거리가 줄면 그냥 새 항목을
하나 더 넣는다. 그래서 같은 정점이 PQ 에 여러 번 들어갈 수 있고, 나중에 꺼낼 때

```cpp
if (d > dist[u]) continue;      // 이미 더 좋은 값으로 확정됨 → 버린다
```

로 걸러 낸다. 기본 그래프에서 정점 1 은 거리 4 로 한 번, 2 를 거쳐 3 으로 한 번 들어가는데,
나중에 꺼내는 `(4, 1)` 이 바로 이 낡은 항목이다. 시각화에서 직접 확인할 수 있다.

## 정확성

### 그리디 선택이 옳다

> **주장**: PQ 에서 꺼낸 정점 `u` 의 `dist[u]` 는 s→u 의 진짜 최단 거리다.

확정된 정점의 집합을 `S` 라 하고, `S` 안의 모든 정점에 대해 주장이 성립한다고 가정하자
(귀납 가설). 이제 `u` 를 꺼낼 차례다.

`dist[u]` 가 최단이 아니라고 하자. 그러면 더 짧은 경로 `P: s → … → u` 가 존재한다.
`P` 를 따라가다 **처음으로 `S` 를 벗어나는 정점**을 `y`, 그 직전 정점을 `x ∈ S` 라 하자.

- `x ∈ S` 이므로 귀납 가설에 의해 `dist[x]` 는 최단이고, `x` 를 꺼낼 때 간선 `x→y` 를
  완화했으므로 `dist[y] ≤ dist[x] + w(x,y)` 다. 즉 **`dist[y] ≤ (P 에서 y 까지의 비용)`**.
- `y` 부터 `u` 까지의 구간은 **가중치가 음수가 아니므로** 비용이 0 이상이다.
  따라서 `P 에서 y 까지의 비용 ≤ P 전체 비용 < dist[u]`.

두 줄을 이으면 `dist[y] < dist[u]` 다. 그런데 `y` 는 아직 `S` 밖이므로 PQ 안에 있고,
우리는 PQ 에서 **가장 작은 것**을 꺼냈으니 `dist[u] ≤ dist[y]` 여야 한다. 모순이다. ∎

### 음수 가중치가 왜 치명적인가

위 증명에서 **"`y`부터 `u`까지 비용이 0 이상"** 딱 한 줄만 음이 아님을 썼다. 그 한 줄이 깨지면
전부 무너진다. 가장 작은 반례:

```
s --1--> a --(-5)--> b
s -------2---------> b
```

`b` 를 거리 2 로 확정해 버리지만, 실제 최단은 `s→a→b = -4` 다. 확정한 뒤에는 다시 보지
않으므로 영영 고쳐지지 않는다. 음수 간선이 있으면 **벨만-포드**나
[플로이드-워셜](#/algo/floyd-warshall) 을 써야 한다.

### 종료성

각 정점은 `dist` 가 줄어들 때만 PQ 에 추가되고, `dist` 는 단조 감소하며 유한한 값들만 갖는다.
PQ 에 들어가는 항목 수는 완화 성공 횟수 이하이고, 그 횟수는 O(E) 로 유한하다.

## 복잡도

| | |
|---|---|
| 시간 | **O((V + E) log V)** — 이진 힙 기준 |
| 공간 | O(V) — dist 배열 + PQ(최악 O(E) 항목) |

- 각 정점은 최대 한 번 확정된다 → pop 은 유효한 것 V 번
- 완화가 성공할 때마다 PQ 에 push → 최대 E 번, 각 O(log)
- 낡은 항목까지 세면 PQ 크기가 O(E) 라 `log E = O(log V)` (E ≤ V²)

| 우선순위 큐 | 시간 |
|---|---|
| 이진 힙 (`priority_queue`) | O((V+E) log V) |
| 배열에서 매번 최솟값 찾기 | O(V² + E) — 밀집 그래프(E ≈ V²)에서는 오히려 유리 |
| 피보나치 힙 | O(E + V log V) — 이론상 최적, 상수가 커서 실전에선 드묾 |

## 구현 노트

**`dist` 자료형과 INF**: `INF` 를 `INT_MAX` 로 두면 `dist[u] + w` 에서 오버플로가 난다.
`INF = 0x3f3f3f3f`(약 10억) 처럼 **두 배 해도 int 범위 안에 드는 값**을 쓰거나 `long long` 을 쓴다.

**decrease-key 대신 재삽입**: 위에서 설명한 "낡은 항목 버리기" 방식이 표준이다.
`std::priority_queue` 는 원소 수정을 지원하지 않기 때문이고, 성능도 충분하다.

**최소 힙 만들기**: C++ 의 `priority_queue` 는 기본이 최대 힙이다.
`greater<>` 를 넣거나, 거리를 음수로 바꿔 넣는 트릭을 쓴다.

**경로 복원**: `dist` 와 나란히 `parent[v]` 를 기록하면 도착점에서 거슬러 올라가 경로를 얻는다.
시각화에서 초록으로 남는 간선들이 바로 이 **최단 경로 트리**다.

**시작점이 여러 개면** 그 모두를 거리 0 으로 넣고 시작하면 된다(multi-source).

## 변형과 확장

- **[A*](#/algo/a-star)** — 우선순위를 `dist` 대신 `dist + h(목표까지의 추정)` 로 바꾼다.
  목표가 하나로 정해져 있을 때 탐색 공간을 크게 줄인다. `h ≡ 0` 이면 다익스트라와 같아진다.
- **0-1 BFS** — 가중치가 0 또는 1 뿐이면 PQ 대신 덱으로 O(V+E).
- **벨만-포드** — 음수 간선 허용, O(VE). 음수 사이클도 탐지한다.
- **존슨 알고리즘** — 벨만-포드로 가중치를 음이 아니게 재조정한 뒤 각 정점에서 다익스트라.
  희소 그래프의 모든 쌍 최단 경로에서 [플로이드-워셜](#/algo/floyd-warshall)보다 빠르다.
- **K번째 최단 경로** — 정점당 K 번까지 꺼내도록 완화 조건을 바꾼다.
