## 한눈에

인접한 두 원소를 비교해서 순서가 뒤집혀 있으면 교환한다. 이 과정을 배열 끝까지 한 번 훑으면
그 구간의 **최댓값이 반드시 맨 뒤에 도착**한다. 큰 값이 거품처럼 떠오른다고 해서 버블 정렬이다.

실무에서 쓸 일은 거의 없다. 그럼에도 첫 정렬 알고리즘으로 배우는 이유는, **불변식(invariant)으로
정렬을 증명하는 방법**을 가장 적은 코드로 보여주기 때문이다.

- 비교 기반 · 제자리(in-place) · 안정(stable)
- 정렬 확정 구간이 **뒤에서 앞으로** 자란다 (시각화에서 초록으로 표시되는 부분)

## 동작 원리

바깥 루프 한 바퀴를 **패스(pass)** 라고 부른다. `i`번째 패스는 `a[0 .. n-1-i]` 구간만 훑는다.
뒤쪽 `i`개는 이미 제자리를 찾았으므로 건드릴 필요가 없다.

```
패스 0:  [5 2 9 1 5 6]  →  [2 5 1 5 6 | 9]     9가 확정
패스 1:  [2 5 1 5 6]    →  [2 1 5 5 | 6 9]     6이 확정
패스 2:  [2 1 5 5]      →  [1 2 5 | 5 6 9]     5가 확정
...
```

내부 루프는 "지금까지 본 것 중 가장 큰 값"을 손에 들고 오른쪽으로 밀고 가는 것과 같다.
`a[j] > a[j+1]` 이면 교환하므로, 큰 값은 계속 오른쪽으로 끌려간다.

## 정확성

### 내부 루프 불변식

내부 루프에서 `j`번째 반복이 끝난 시점에 다음이 성립한다.

> `a[j]` 는 `a[0 .. j]` 중 최댓값이다.

`j = 0` 일 때는 자명하다. `j-1`까지 성립한다고 하자. `a[j-1]`이 `a[0..j-1]`의 최댓값이므로,
`a[j-1]`과 `a[j]`를 비교해 큰 쪽을 `a[j]`에 두면 `a[j]`는 `a[0..j]`의 최댓값이 된다.

따라서 내부 루프가 `j = n-1-i` 까지 돌고 끝나면 **구간의 최댓값이 맨 오른쪽 칸에 놓인다**.

### 외부 루프 불변식

> `P(i)`: `i`번째 패스가 끝난 뒤 `a[n-i .. n-1]` 은 배열 전체에서 가장 큰 `i`개가 오름차순으로
> 놓여 있고, 앞쪽 `a[0 .. n-1-i]` 의 모든 원소는 그 이하다.

`P(0)`은 공집합이라 자명하다. `P(i)`가 성립하면, 위의 내부 루프 결론에 의해 `a[0..n-1-i]`의
최댓값이 `a[n-1-i]`로 이동한다. 이 값은 앞쪽 구간 전체보다 크거나 같고, `P(i)`에 의해 뒤쪽
구간 전체보다는 작거나 같다. 따라서 `P(i+1)`이 성립한다.

`i = n-1`에서 확정 구간의 크기가 `n-1`이 되고, 남은 `a[0]` 은 자동으로 최솟값이므로 배열 전체가 정렬된다. ∎

### 종료성과 안정성

두 for 문 모두 상한이 고정된 유한 루프라 반드시 종료한다.

비교가 `a[j] > a[j+1]` 이므로 **값이 같으면 교환하지 않는다**. 같은 값끼리는 원래 순서를 그대로
유지하므로 이 정렬은 **안정(stable)** 하다. 조건을 `>=` 로 바꾸면 안정성이 깨진다.

## 복잡도

| | 비교 횟수 | 교환 횟수 | 시간 |
|---|---|---|---|
| 최선(이미 정렬) | n(n-1)/2 | 0 | O(n²) |
| 평균 | n(n-1)/2 | ≈ n(n-1)/4 | O(n²) |
| 최악(역순) | n(n-1)/2 | n(n-1)/2 | O(n²) |

비교 횟수는 입력과 무관하게 항상 같다.

```
(n-1) + (n-2) + ... + 1 = n(n-1)/2 = Θ(n²)
```

교환 횟수에는 더 정확한 표현이 있다. **인접 교환 한 번은 역전(inversion) 을 정확히 하나 없앤다.**
역전이란 `i < j` 이면서 `a[i] > a[j]` 인 쌍이다. 그러므로

> 버블 정렬의 교환 횟수 = 입력 배열의 역전 수

이다. 역순 배열의 역전 수가 `n(n-1)/2`로 최대이고, 무작위 배열의 기댓값은 `n(n-1)/4`다.
같은 이유로 [삽입 정렬](#/algo/insertion-sort)의 이동 횟수도 정확히 역전 수와 같다.

공간은 교환용 임시 변수 하나뿐이라 **O(1)** — 제자리 정렬이다.

## 구현 노트

**이 페이지의 코드에는 조기 종료가 없다.** 카탈로그에 적힌 최선 `O(n)` 은 아래처럼 "이번 패스에
교환이 한 번도 없었다"를 감지하는 플래그를 넣은 버전의 값이다.

```cpp
for (int i = 0; i < n - 1; i++) {
    bool swapped = false;
    for (int j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j + 1]) { swap(a[j], a[j + 1]); swapped = true; }
    if (!swapped) break;          // 이미 정렬됨 → 최선 O(n)
}
```

교환이 없다는 것은 모든 인접 쌍이 `a[j] <= a[j+1]` 이라는 뜻이고, 이는 곧 정렬 완료와 같다.
시각화에서는 매 패스의 진행을 끝까지 보여주려고 일부러 이 최적화를 뺐다.

`n - 1 - i` 를 `n - 1` 로 잘못 쓰면 결과는 여전히 맞지만 확정된 뒤쪽을 계속 다시 훑어
상수가 두 배가 된다. 시각화에서 초록 구간이 자라지 않는 것으로 바로 드러난다.

## 변형과 확장

- **칵테일 셰이커 정렬**: 좌→우, 우→좌를 번갈아 수행한다. 작은 값이 맨 뒤에 하나 있는
  "거북이(turtle)" 입력에서 패스 수를 절반으로 줄인다. 여전히 O(n²).
- **홀짝 전위 정렬(odd-even transposition sort)**: 인접 비교를 병렬로 수행하는 버전.
  버블 정렬이 병렬 하드웨어에서 살아남은 거의 유일한 형태다.
