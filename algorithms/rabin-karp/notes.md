## 한눈에

문자열 창을 **다항식 해시** 하나로 요약해, 패턴 해시와 다르면 문자 비교 없이 건너뛴다.
창을 옮길 때 **롤링 해시**(앞 빼고 뒤 더하기)로 `O(1)` 갱신. 해시가 같을 때만 실제 비교(충돌 방지).
기대 `O(n+m)`.

- **시간** 기대 `O(n+m)` / 최악 `O(n·m)`(충돌 다발) · **공간** `O(1)`
- **해시 같음 = 후보**일 뿐 — 반드시 문자로 확인(충돌 존재)
- **무작위 밑**이면 적대적 충돌을 막는 랜덤화 알고리즘(검증하면 라스베이거스, 생략하면 몬테카를로)
- **다중 패턴·2차원**에 자연스럽게 확장(해시 지문)

**언제 쓰나** — 여러 패턴을 같은 텍스트에서(패턴 해시들을 집합으로), 2차원 패턴 매칭,
중복 부분문자열 탐지, 문자열 동등 비교의 빠른 사전 필터.

**언제 안 쓰나** — 단일 패턴의 **최악 보장**이 필요하면 [KMP](#/algo/kmp)(`O(n+m)` 확정).
평균 최속은 보통 Boyer–Moore.

## 동작 원리

```
hp = hash(p), ht = hash(t[0..m-1])          # 다항식 해시
for i in 0 .. n-m:
    if ht == hp and t[i..i+m-1] == p: 기록/반환   # 후보 → 문자 확인
    ht = roll(ht, t[i], t[i+m])              # 창을 한 칸: 앞 빼고 뒤 더하기
```

### 다항식 해시

문자열 `s`(길이 `m`)의 해시:

```
hash(s) = (s[0]·B^(m-1) + s[1]·B^(m-2) + … + s[m-1]) mod M
```

### 롤링 — O(1) 갱신

창 `t[i..i+m-1]` → `t[i+1..i+m]` 로 옮길 때:

```
ht' = ( (ht − t[i]·B^(m-1)) · B + t[i+m] ) mod M
```

맨 앞 항 `t[i]·B^(m-1)` 을 빼고, 전체에 `B` 를 곱해 자리를 올린 뒤 새 뒤 글자를 더한다.

## 정확성

> **해시 불변식.** 각 `i` 에서 `ht = hash(t[i..i+m-1])`.

*유지.* 초기값은 첫 창 해시. 롤링 식이 `hash(t[i..i+m-1]) → hash(t[i+1..i+m])` 를 정확히 계산함을
다항식 전개로 확인할 수 있다(맨 앞 항 제거 + `B` 자리이동 + 새 항 추가). ∎

> **정확성.** 반환된 위치 `i` 는 실제로 `t[i..i+m-1] == p`.

`ht == hp` 만으로는 부족하다(충돌). 그래서 **문자 비교로 확인**한 뒤에만 일치로 인정한다.
누락은 없다 — 실제 일치면 해시도 반드시 같으므로 `ht==hp` 검사를 통과해 확인 단계로 간다. ∎

### 충돌 확률

무작위 밑 `B`(균등, `M` 이 소수)에서, 서로 다른 두 길이 `m` 문자열의 해시가 우연히 같을 확률은
다항식이 근을 가질 확률로 `≤ m/M`. `M ≈ 10⁹` 이면 극히 작다. 이중 해시(서로 다른 `M` 두 개)면
충돌 확률이 곱으로 떨어져 사실상 0.

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 기대(충돌 드묾) | `O(n + m)` | `O(1)` |
| 최악(충돌 다발) | `O(n · m)` | `O(1)` |

### 최악은 언제

법·밑이 나쁘거나 적대적 입력이면 해시가 자주 충돌해 매번 문자 비교 → `O(n·m)`.
**무작위 밑**과 **큰 소수 법**(또는 이중 해시)이 이를 확률적으로 막는다.

### KMP 와의 대비

| | 라빈-카프 | [KMP](#/algo/kmp) |
|---|---|---|
| 보장 | 기대 `O(n+m)`(최악 `O(nm)`) | 최악 `O(n+m)` 확정 |
| 다중 패턴 | 쉬움(해시 집합) | 아호-코라식 필요 |
| 2차원·부분문자열 비교 | 자연스러움(지문) | 어색 |
| 실패 위험 | 충돌(확률적) | 없음 |

## 구현 노트

**음수 mod** — 뺄셈 후 `((x % M) + M) % M` 로 양수화.

**밑·법 선택** — `B` 는 알파벳 크기보다 크게, `M` 은 큰 소수. **무작위 `B`** 로 적대적 충돌 방지.

**이중 해시** — 서로 다른 `(B,M)` 두 쌍으로 해시해 둘 다 같을 때만 후보 — 충돌 확률 곱으로 감소.
많은 실전 코드가 검증(`substr` 비교)을 생략하고 이중 해시로 대체한다(몬테카를로).

**오버플로** — `ht·B`, `t[i]·pw` 가 커진다. 64비트 + 곱마다 mod, 또는 `__int128`.

## 변형과 확장

### 다중 패턴 검색

같은 길이 패턴들의 해시를 **해시 집합**에 넣고, 텍스트 창 해시가 그 집합에 있는지 `O(1)` 로 확인.
서로 다른 길이면 길이별로 반복.

### 2차원 패턴 매칭

행별로 롤링 해시를 만든 뒤, 그 행 해시들에 다시 세로 롤링 해시를 얹어 2차원 부분격자를 지문 비교.

### 최장 중복 부분문자열 (해시 + 이분 탐색)

길이 `L` 을 이분 탐색하며, 길이 `L` 부분문자열들의 해시를 모아 중복이 있는지 검사 → `O(n log n)`.

### 접미사 비교·LCP

두 접미사의 앞 `k` 글자가 같은지 해시로 `O(1)` 비교 — 접미사 배열의 LCP 계산 등에 쓰인다.
