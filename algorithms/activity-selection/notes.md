## 한눈에

시작·끝 시각이 있는 활동들 중 **서로 겹치지 않게 최대 개수**를 고른다. **끝나는 시각 오름차순**으로
정렬해, 직전 선택과 안 겹치면(시작 ≥ lastEnd) 고르는 그리디. 교환 논법으로 최적임이 보장된다.

- **시간** `Θ(n log n)`(정렬 지배) + 한 번 훑기 `O(n)` · **공간** `O(1)`
- **끝 시각 기준**이 핵심 — 시작/길이 기준은 틀린다
- **개수 최대** 문제라 그리디가 통한다(**이익 합 최대**면 DP)
- 그리디가 최적임을 **증명**해야 쓴다 — 여기선 교환 논법

**언제 쓰나** — 회의실 하나에 최대 회의, 겹치지 않는 구간 최대 선택, 작업을 최대 개수 처리.

**언제 안 쓰나** — 활동에 **가중치**가 있어 이익 합을 최대화(가중 구간 스케줄링 → DP), 방이 여러 개
(최소 강의실 → 다른 그리디), 마감·처리시간 최적화(다른 스케줄링).

## 동작 원리

```
끝나는 시각 오름차순 정렬
lastEnd = -∞, count = 0
for 활동 act (정렬 순):
    if act.start >= lastEnd:     # 직전 선택과 안 겹침
        count++; lastEnd = act.end
```

### 왜 끝 시각인가

가장 빨리 끝나는 활동을 고르면 **남는 시간(자원)이 최대**가 되어, 이후 더 많은 활동을 넣을 여지가 생긴다.
이 "탐욕 선택" 이 전체 최적을 해치지 않음을 아래에서 증명한다.

## 정확성

> **그리디 선택 속성.** 가장 빨리 끝나는 활동 `g` 를 포함하는 최적해가 **적어도 하나** 존재한다.

*증명(교환 논법).* 임의의 최적해 `O` 를 끝 시각 순으로 정렬하고 첫 활동을 `x` 라 하자. `g` 는 전체에서
가장 빨리 끝나므로 `g.end ≤ x.end`. `O` 에서 `x` 를 `g` 로 바꾼 `O'` 를 보면, `g` 는 `x` 보다 일찍(또는
같이) 끝나 `O` 의 나머지 활동과도 겹치지 않는다. 따라서 `O'` 도 유효하고 크기가 같아 **최적**. 즉 `g`
를 포함하는 최적해가 존재한다. ∎

> **최적 부분 구조.** `g` 를 고른 뒤, `g` 와 겹치는 활동을 버린 나머지에서의 최적해에 `g` 를 더하면
> 전체 최적이다.

`g` 선택 후 남는 문제는 "시작 ≥ g.end 인 활동들 중 최대 개수" 로 같은 종류의 문제. 귀납으로 그리디가
그 부분도 최적으로 푼다. 두 성질로 그리디 전체가 최적. ∎

### 반례로 보는 틀린 규칙

- **시작 이른 순**: `[1,10)` 을 먼저 골라 `[1,2),[3,4),…` 전부를 막는다.
- **짧은 순**: `[3,5)` 가 `[1,4)`·`[4,7)` 사이에 끼어 둘을 다 배제.

끝 시각 순만이 교환 논법을 통과한다.

## 복잡도

| | 시간 | 공간 |
|---|---|---|
| 활동 선택 | `Θ(n log n)` | `O(1)` |

정렬이 `Θ(n log n)`, 선택 스캔이 `O(n)`. 이미 끝 시각 순이면 `O(n)`.

## 구현 노트

**부등호** — 반개구간 `[s,e)` 는 `start >= lastEnd`(경계 접촉 허용). 폐구간 `[s,e]` 는 `start > lastEnd`.

**정렬 키** — 끝 시각 오름차순. 같으면 시작 시각으로(안정적이면 무관).

**실제 선택 목록** — 개수뿐 아니라 어떤 활동인지 필요하면 선택 인덱스를 기록.

**가중치가 있으면** — 그리디 금지. 가중 구간 스케줄링 DP(`dp[i] = max(dp[i-1], w_i + dp[p(i)])`, `p(i)` = i 와
안 겹치는 마지막)로 `O(n log n)`.

## 변형과 확장

### 가중 구간 스케줄링 (DP)

각 활동에 이익이 있어 **이익 합 최대**를 원하면 DP. 끝 시각 정렬 + 이분 탐색으로 이전 호환 활동을 찾아
`dp[i] = max(dp[i-1], w_i + dp[p(i)])`.

### 최소 강의실 (interval partitioning)

모든 활동을 하되 **겹치는 것끼리 다른 방**에 — 최소 방 수 = 임의 시점의 최대 동시 활동 수.
시작/끝 이벤트를 정렬해 스위프.

### 마감 스케줄링

각 작업에 마감·처리시간이 있어 지각 최소화·이익 최대 — 다른 그리디(EDF, 마감 순 + 유니온 파인드)나 DP.

### 최대 겹침 없는 구간 (선분)

같은 문제의 기하 버전. 끝점 정렬 그리디가 그대로.
